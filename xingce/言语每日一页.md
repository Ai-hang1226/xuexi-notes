## 🌳 体系总览（大懒猫 · 完整8题型）

```
言语理解体系
├ ① 中心理解题（主战场）
│   ├ 转折类（转折后是重点）
│   ├ 递进类（递进后是重点）
│   ├ 因果类（结果为重点）
│   ├ 对策类 ★★     ← 题4/7/9  对策→核心；要有针对性；
│   │                 一串并列做法→选上位总对策
│   ├ 总分类 ★★★★  ← 题1/6/9/12  分句为总句服务；
```

## 🧭 每天做题前默念 7 条

1. **先定话题**，再对选项。整段讲什么记住关键词再排除。
2. **识别题型先于做题**。"接下来最可能讲"→接语；"关键在"→对策；"下列不符"→细节选非。
3. **中心句=作者结论/对策/观点**，不是背景、举例、论据、必要条件。
4. **正确选项是原文转述**（专业名词不替换），看"像是但换了词"要警惕。
5. **别追求"最全面"**，全面但夸大(绝对化)往往是干扰项。
6. **高频词定"话题"，结构定"落点"**——答案=话题词+落点词。**永远不问"哪个词出现得多"，只问"落点在哪一句"。**（尾句只是位置线索：它可能在举例、可能是比喻、可能只是并列做法里的一条）
7. **两个选项主语一样时，别比主语，比谓语**——把谓语拆开逐块回原文找出处，**有一块找不到出处的，优先排除**。（背景句里的"最集中的"这种强表述，也只是引子，不是落点）

## 🎯 你的薄弱节点（回炉对应体系节）

1. **分不清"哪儿是落点"**（题1、6、9、10、11、12）：题1/6分句当总句，题9分做法当总对策，题10**退回段首总起句**，题11**停在①的表层概念**，题12**停在②的背景句** → 回【总分类】【对策类】【语句填空·段尾】【实用技巧·关键词提取/同主语比谓语】
2. **对策·可行性**（题4）：必要性≠对策 → 回【对策类】
3. **论点论据**（题7）：选项话题要≥文段 → 回【快速模型】
4. **细节/接语/关键词·偷换字面**（题3、5、11）：三处回【细节·偷换】【接语·话题】【实用技巧·关键词提取】
5. **标题被首句局部意思带偏**（题8）：先问例子在证明什么 → 回【标题填入·契合中心】

> - C．科学家并非永远对自己的工作有自信
> - D．承认自己无知并不影响科学家的声誉

### 题 12 · 主旨·概括最恰当 · 答案 **B**（2021江苏A卷·原卷题24）

> ①在高等教育规模不断扩大的同时，竞争也在加剧。②高等院校之间的竞争是永恒的主题，而最集中的竞争是生源的竞争。③大学开设特色专业项目是竞争的战略，目前国内高校竞相开设丰富多样的主修、辅修专业和证书课程等。④在此基础上，个性化专业设置作为一种极具特色的本科人才培养方式，为高校实现独特人才培养的目标开启了新通道，有效提升了学校的吸引力和竞争力。下列对文字的概括最恰当的一项是：
> - A．高等教育竞争主要表现在如何帮助学生实现既定目标
> - B．专业设置个性化是增强高校吸引力竞争力的有效途径
> - C．个性化专业设置是高校之间生源竞争普遍采用的方式
> - D．独特人才培养计划是各个高校竞争中的有力武器
>
> 提示：B、C 主语相同，比**谓语**——B 的“增强吸引力竞争力／有效途径”在④句全有出处，C 的“生源竞争”在②句（背景）、“普遍采用”原文没有。

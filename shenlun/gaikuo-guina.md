# 概括归纳

概括归纳是申论最基础的题型，也是最容易拿分的题型。

> 🎯 **核心原则**：所有答案都在材料里，你不要创造，你只负责找和整理。

## 🔧 解题步骤

```
1. 审题 → 明确概括对象、范围、字数要求
2. 阅读 → 边读边划关键词句
3. 归类 → 同类项合并，形成 3-5 个大点
4. 书写 → 总括句 + 分述
```

## 📝 答题模板

### 标准格式

```
【总括句】X方面的情况/问题/原因如下：

1. [要点一概括]：具体内容...
2. [要点二概括]：具体内容...
3. [要点三概括]：具体内容...
```

### 常用总括句

| 题目类型 | 总括句模板 |
|---------|-----------|
| 概括问题 | "X（方面/领域）存在以下问题：" |
| 概括原因 | "造成X的原因是多方面的：" |
| 概括影响 | "X带来的影响主要体现在：" |
| 概括做法 | "X在Y方面采取了以下措施：" |
| 概括变化 | "X呈现以下变化趋势：" |

## ⚡ 常见问题与对策

### 问题1：照抄原材料
❌ 直接整句抄材料  
✅ 提取关键词，用自己的话重组

### 问题2：遗漏要点
❌ 写完了发现材料里还有没用到的信息  
✅ 边读边编号，确保每个要点都不漏

### 问题3：归类混乱
❌ 把不同类的东西放一起，前后交叉  
✅ 归纳时按"主体""领域""性质"分类

### 问题4：过度拔高
❌ 材料说的是具体问题，答案写成了大道理  
✅ 忠实于材料，不要上升高度

## 📋 常见归纳维度

| 维度 | 示例 |
|------|------|
| 按主体 | 政府、企业、社会、个人 |
| 按领域 | 经济、政治、文化、社会、生态 |
| 按流程 | 事前、事中、事后 |
| 按性质 | 主观原因/客观原因、内因/外因 |
| 按层面 | 思想层面、制度层面、技术层面、资金层面 |

# 📌 使用指南

> 与首页「使用指南」同源，原文保留；这里补充全站找路说明。

## 四步闭环

1. **学方法**：在每个模块的 `.md` 里用 Markdown 写笔记，体系与方法都在里面
2. **查知识**：顶部搜索栏支持全文搜索，任何知识点都能找到
3. **做错题**：做完题把错题按模块录进[错题本](/cuotiben/)，定期回顾
4. **走闭环**：每一题都归到位 + 记住错因，让小懒猫的知识真正长成体系

- 不知道从哪开始 → [🗺️ 全站地图](/guide/)

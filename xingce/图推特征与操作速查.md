# 图推特征与操作速查

**先找对象 → 看特征 → 列候选 → 执行操作 → 验证全组。**

## 候选入口

| 看见什么 | 可以考虑 | 实际操作 |
|---|---|---|
| 相同元素，局部朝向变 | 局部旋转／移动 | 对应每个元素，找变与不变；第2题 |
| 明显弧线与直线相交 | 曲直交点 | 数量相同再比部位与形态；第1题 |
| 两个轮廓图形相接 | 连接处 | 公共点、公共边及边界段数；第4题 |
| 出头、T点、闭环点接、日字变形 | 笔画数 | 查连通性和奇点；第5题 |
| 完整小正方体堆积造型 | 数块／层数／视图 | 固定方向压深度，比较投影；第6题 |
| 黑块对称且仍难区分 | 白面及两轴关系 | 先固定对象，再比轴数与方向；第7题 |
| 多个可辨认的小图形 | 元素个数与种类 | 分别问有几个／有哪些种类；第8题 |
| 背景杂乱但局部重复 | 相同相似对象及关系 | 从单色完整轮廓提取，验证跨图一致；第9题 |
| 九宫格一行有明显数量 | 各行同构关系 | 每行统计口径一致，跨行可换量；第10题 |
| 碎片组合目标展开图 | 守恒与矛盾排除 | 先认完整面型和数量，必要时拼合；第3题 |

入口只提出候选，不是“出现某特征必考某规律”。图形不能区分时再换有特征依据的方向，不固定按熟悉程度排序。

## 交点：分清比较维度


[四组交点图例（教学示意）](/figure-review-20261021/交点四组图例.html)

| 观察维度 | 区别与示例 |
|---|---|
| 相交对象 | 直直、曲直、曲曲；不因交点相同就把所有类型混数 |
| 交点部位 | 线条端点／非端点；非端点不等于几何中点 |
| 接口形态 | T形、Y形、X形／十字形；看各分支怎样接续 |
| 相交方式 | 端点相接／交叉穿过；完整圆与直线相切为1个切点，直线穿过完整圆与圆周交于2点 |
| 相对位置 | 指定交点在外框内／上／外，或位于特定方向；先明确统计对象 |
| 图形接触关系 | 点连接（共一个点）、线连接（共一段线）、面积重叠（共一块区域）；按题目统一关系与计数口径 |

- <strong>位置问“在哪里”，方式问“怎样接触”。</strong>分类可以重叠描述：一个点可同时为曲直交点、非端点交点、框内交点。
- “曲线端点／非端点”与“端点相接／中段交叉”在本题描述同一个观察，不重复背成两个独立考点。
- 直线与曲线有共同点，不自动说明相切；端点接触与相切也不等同。切点可以作为特殊交点单独统计，不能中途变口径。
- 示例“端点—非端点交替”“T—X—T—X—T，下一幅找X”为教学示意，不标作额外真题或本人新做对的题。
- 第4题连接公共边数量，第9题连接重复对象与是否共边，个人错因已归入逐题记录。


## 一笔画：特征与判定分开

**出头／闭环点接／分割闭环 → 提出笔画候选 → 判连通 → 数奇点。**

连通图奇点0或2时可一笔画；有2k个奇点且k≥1，最少k笔。零奇点的非空连通图仍需1笔。不连通时各连通部分分别计算再相加。

奇点按实际分支数判断：端点1支，T点3支；普通转角2支、十字4支为偶。特征图要记结构，不要求变形后还像“日”或圆。

## 连接、对称与元素：先统一对象

- 公共点／公共线段／重叠区域不同；公共折线在转折处分段，不能数整幅图全部线。
- 黑白均可能承载规律；先确定特定白面，再比与黑块的轴关系。不能逐图任意选对象。
- 个数与种类并列检查；大小、朝向能否忽略，以整组一致分类为依据，不设永久规则。
- 对象提取失败时，先找重复的完整轮廓；局部方法仍需验证六幅或整组。

## 立体：先排矛盾，再做重操作

展开图拼合可先查完整面型数量超额；符合数量仅是必要条件，不总能直接定答案。旋转后同型也算同一种面，相邻黑格与对角黑格要区分。

堆积图投影保持同一方向：压掉前后深度，保留左右、高低；沿深度的列高取最高值，不累加，不只看最前排。视图只是候选之一。

## 训练闭环

先简框架 → 做题暴露卡点 → 回查对应笔记 → 讲清操作 → 无提示同类新题 → 混合识别 → 延后复测。旧题听懂、复述与新题独立完成分别记录。

# 以后只做真题

本条覆盖此前允许AI自编、改编和参数变式的出题安排。适用于行测、申论、每日测验、专项练习及用户点名的阶段组卷；从下一次新发题开始执行。

- <strong>题源顺序：江苏省考真题为主，优先A类；可混合国考及其他省考真题。</strong>不设置用户未指定的固定混合比例，按题型、薄弱点和未做状态选择。
- <strong>只用真题原题。</strong>不再生成AI自编题、机构模拟题、改变数字条件或选项的变式，也不拼接、压缩材料后冒充原题。真题组卷只调整本卷顺序，保留原卷题号。
- 每题标明年份、考试、地区、卷型、原题号及可核验来源；网友回忆版明确标为回忆版，题库参考解析不冒充官方答案。题号未核实则标明缺口，不编造。
- 保留完整题干、全部选项、必要图表及单位。申论使用原始给定资料、问法、分值和字数要求，按原题小题安排；提纲或核心段等局部练习须由用户明确要求，不能改造为新题。
- 复测优先选同考点的另一道未做真题；原题重做、已看解析和陌生题独立验证分别记录。继续优先错题、不确定、猜选及有真实耗时记录的题，中等及中等偏难训练不靠改题制造。
- 来源、材料或配图不完整时换另一道完整真题，不用自编凑数。旧法律、时政题核对命题时与当前口径；不适合作当前训练的题暂不选，不悄改原题。
- 首答前不公布答案解析。来源核验、独立验算、真实用时、猜测状态及两端同步规则继续执行。混合缩编真题卷只作本卷诊断；完整实考水平应由未做过、严格限时的完整江苏A类原卷检验。
- 已发自编卷、首答、成绩和旧计划保留为历史，不暗改或重算；后续到期复测改选真题。每日最多一份正式卷的约定保持。

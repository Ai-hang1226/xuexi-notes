# ✨ 精选导读

> 站内大部分页面是**原始档案**：逐题判分、本人首答、真实用时、复盘流水。这里只放经过编辑、5 分钟能读完、有明确结论的**精选内容**——适合直接分享，也适合作为复习的入口。

## 已发布

| 文章 | 一句话结论 | 适合谁 |
|---|---|---|
| [资料分析 7 道错题：共同卡点在列式之前](/share/data-analysis-7-mistakes) | 具体错因不同，但都发生在「认对象 → 列目标式」这一步；不统一归因为粗心 | 资料分析总在分母、口径上失分的人 |
| [申论归纳概括：问什么，就归纳什么](/share/shenlun-summary-5-elements) | DAY5—DAY9 不是五种题型，是同一题型下的五种作答要素 | 申论分不清"做法 / 成效 / 特点 / 问题 / 原因"的人 |

每篇末尾都留了回到原始记录的链接：先看结论，需要证据再往下钻。

## 与原始档案的关系

```
📖 精选导读（本层）  →  结论 + 清单 + 可分享
      ↓ 附链接
🗄️ 原始档案          →  原题 / 首答 / 解析 / 评分 / 逐题复盘
```

原始档案一处未删；导读只是新增的一层索引，不改动任何笔记。

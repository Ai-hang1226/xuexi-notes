# 🗺️ 全站地图

> 一页看清「有什么、按什么逻辑分、从哪开始」。本页是索引层，**所有笔记原文都还在原来的位置**，路径、标题、日期和链接一律没动。

## 一、分类依据

分类按官方考试大纲与内容本身的逻辑关系，不是按时间或文件名堆砌：

| 板块 | 分类依据 | 层级 |
|---|---|---|
| 📗 行测 | 大纲五大模块 | 模块 → 体系 / 方法 / 速查；判断推理再分四种题型 |
| 📘 申论 | 大纲五大题型 | **总纲独立** → 题型 → 讲义方法 / 真题 / 评分 |
| 📝 每日测验 | 时间 + 性质 | 总览规则 → 专题测评 → 按月份 |
| 🧠 错题本 | 复盘动作 | 检索 → 方法 → 按模块 → 整卷 → 词库 → 归档 |
| 🧰 工具与指南 | 跨板块用途 | 速查 / 计算 / 归档 / 站点说明 |

## 四、申论：总纲 + 五大题型

**Kiwi 知识框架是总纲，覆盖五大题型，因此独立一级；它不放在「归纳概括」下面。** 五个题型并列，各自下挂讲义方法与真题。

```
📘 申论
├─ 📖 总纲 · Kiwi 申论知识框架（五大题型主线）
└─ 🎯 按题型练
   ├─ 📒 归纳概括  → DAY5—DAY9 真题 + 特点与方法
   ├─ 🔍 综合分析  → 讲义方法（暂无专项练习）
   ├─ 💡 问题对策  → 讲义方法（暂无专项练习）
   ├─ 📄 公文写作  → 讲义方法（暂无专项练习）
   └─ ✍️ 文章写作  → 讲义方法（暂无专项练习）
```

- [📊 评分与进步记录](/shenlun/scores) · [📂 原题与讲义](/shenlun/sources/day5-city-greening)

## 六、学习闭环

::: tip 五步走
**做题**（每日测验留首答）→ **对答案**（结果与解析）→ **归因**（错题本按错因归档）→ **沉淀**（方法库 / 速查表）→ **验证**（换同考点真题复测）
:::

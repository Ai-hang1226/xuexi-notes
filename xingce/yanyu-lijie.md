## 一、逻辑填空（选词填空）

### 解题步骤（大懒猫·两步走）

> 核心：**文段找对应 → 选项做辨析**，先定大方向，再抠准确度。

1. **文段找对应**：横线前后是什么逻辑关系？该填"大方向"是什么词？
2. **选项做辨析**：在这个方向下，哪个词最准确？（日常积累 + 择优思维）
3. 本质：**大方向意思正确再做细致对比 → 优中选优**

### 文段找对应（按逻辑关系触发）

| 逻辑关系 | 标志词 | 该填什么 |
|---|---|---|
| 转折 | 但是、然而、却 | 前后语义相反（不矛盾） |
| 递进 | 更、甚至 | 语义相近，程度前轻后重 |
| 并列·近义 | 逗号、顿号 | 前后语义相近 |
| 并列·反义 | 不是…而是… | 前后语义相反 |
| 并列·多并列 | 三个及以上词语 | 语义不同ABC / 相近A1A2A3 / 递进AA+A++ |
| 因果/解释 | 因为…所以、由于、导致、即、可谓、**、—— | 前后语句对横线处做词义解释 |
| 形象化 | 文段比喻、双引号 | 优选形象化表达 |

> 🚩 **逻辑中心化**：宏观角度理解文段整体意思，别只看单句。

### 选项作辨析

- **成语**：考察词义更多
- **实词**：考察搭配更多（固定搭配 / 主语人事物 / 一搭多 / 重复出现 A 的 A）
- **感情色彩**：褒义 / 中性 / 贬义，跟文段一致
- **程度轻重**：文段出现温和词语→选程度轻的；出现绝对词语→选程度重的

### 实用技巧（易错点）

- **直接对应**：直接呼应最优，不要往前推（eg 大米稀缺 → 选"少"，不选"贵"）
- **结构法**：结构一致，内容一一对应
- **择优思维**：选项都对时，选更全面、更精准的
- **生僻词**：先分析常见词确定答案；字面意思猜义（望文生义）

### 易错归档：别被局部画面词带走

**题干缩写：**“将中国文化____融入古典音乐……在乐符的____中仿佛听到蝴蝶翅膀的振动声，看到蜻蜓点水般的涟漪款款。”

**答案：B．意蕴／流淌。** “文化意蕴”指深层意味；“乐符流淌”写音乐连贯、舒缓地展开，并与“款款、涟漪”同属柔和连续的意境。

| 选项 | 排除理由 |
|---|---|
| A．韵味／共振 | “韵味”可通，但通常说“产生共振”，不说“在乐符的共振中”。 |
| C．精髓／飞扬 | “精髓”偏核心精华；“飞扬”偏高昂、向上，与“款款、涟漪”的舒缓意境不合。 |
| D．感受／跳跃 | 不是把“感受”融入演奏；“跳跃”又与水波般连续流动的画面相反。 |

> **我的易错点：**看见“蝴蝶振翅”就联想到“飞扬”，只抓了局部画面。考场快判：①先给两空定词性和方向；②默念代入，先排搭配别扭项；③用后文意象定胜负——“款款、涟漪”→“流淌”。时间紧也至少完成这 3 步，避免凭第一眼联想选词。

### 常见逻辑关系（旧版笔记，保留）

| 关系 | 标志词 | 解题要点 |
|------|--------|---------|
| 并列 | 和、与、同时、既...又... | 前后语义相近 |
| 转折 | 但、却、然而、不过 | 前后语义相反 |
| 递进 | 甚至、更、尤其 | 后比前更深一层 |
| 因果 | 因为、所以、因此 | 前后有因果关联 |
| 解释 | 也就是说、换言之 | 前后语义相同 |

### 逻辑填空拓展：法治表述词语搭配

**题干：**依法治国和依法行政的____，需要各级政府及其工作人员在法治____上行使权力，在宪法法律范围内活动。

**答案：**A．实现／轨道。

| 关键词 | 最佳搭配 | 易错辨析 |
|------|----------|----------|
| 实现 | 实现依法治国、依法行政 | “实施”多接具体法律、政策、方案；“履行”多接职责、义务、承诺。 |
| 轨道 | 在法治轨道上行使权力 | 突出权力按法律规则、程序和边界运行。 |
| 框架 | 在法治框架内行使权力 | 应搭配“内”，不能说“在法治框架上”。 |
| 基础 | 在法治基础上推进治理 | 突出支撑、前提，不突出对权力运行的约束。 |
| 道路 | 走中国特色社会主义法治道路 | 突出发展方向，常搭配“走、坚持、沿着”。 |

> 速记：**基础管支撑，道路管方向，轨道管运行与约束。**

**高频语块：**

- 权力在法治轨道上行使；工作在法治轨道上推进；社会生活在法治轨道上运行。
- 在法治框架内开展活动；在宪法法律范围内活动；以法律为依据。
- 法无授权不可为，法定职责必须为；让权力在阳光下运行。

## 二、阅读理解

### 主旨概括题（中心理解）

**核心方法（大懒猫）**：先识别文段结构 → 找出总句/重点句 → 匹配选项。

> 💡 **判断是"总"还是"分"，核心是判断"为谁服务"**：分句（背景/解释/举例）都是为总句（观点/对策/总结）服务的。

#### 按结构触发（先问"这段是什么结构？"）

| 结构 | 标志词 | 中心在哪 | 大懒猫要点 |
|---|---|---|---|
| **转折** | 但是、可是、不过、然而、事实上、其实、殊不知、不同的是 | **转折后是重点** | 反驳型：①转折只反驳→选前文反面；②反驳+新观点→必须体现新观点；③只反驳无新观点→选转折后。**双循环A但B/B但A=转折失效** |
| **递进** | 更、甚至、特别是、不仅…而且 | **递进后是重点** | 若递进后无合适答案→可选前面的大话题 |
| **因果** | 因为…所以、因此、从而、可见、使得、"这"、换句话说、**正是…使得…** | **结果是重点** | 答案呈现：因果阐明 > 果的因 > 果；有些因果文段无标志词，**内容为王**；**"正是……使得……"是因果强调句**（题13）：落点在"使得"**后面**的结果，做题时先翻成大白话（谁让谁怎么样了），**选项方向一律不能反** |
| **对策** | 要、应该、必须、建议、只有…才、前提、基础、重要的是 | **原文对策为核心** | 对策文段选对策；问题文段对策可行选对策、不可行选问题；**对策一定要有针对性、可行性**；**一个“需要”后跟一串并列做法→选能罩住全部的“上位总对策”，不选其中某一条分做法**（题9） |
| **总分** | 总句（观点/对策/总结），分句（背景/解释/举例） | **总句** | 分句为总句服务 |
| **并列** | 分号、也/又/同时/此外、一方面…另一方面、句式一致、时间并列、无论证关系 | **全面概括 / 宏观概括 / 提取共性** | 文段A+B→答案A+B；A+B→C；A1+A2→A（**用排除法做题**） |

**就这六种结构，够用。** 出题人再怎么变，都是这六种的排列组合。但你常听到一些"变体"，其实都被上面六种**吸收**了——不是新结构，只是换了个说法：

> 🚩 **反问不等于没有表态**（题15）：把“难道／何尝／是否……呢”放回上下文，若前文已经在批评或质疑，就要还原成带否定倾向的陈述。但注意程度对应：反问通常可还原为“未必／不等于”，不必一律强化成“完全没有”。

| 变体说法 | 归到哪 | 为什么 |
|---|---|---|
| 假设/让步（如果…就、即使…也） | 递进 / 对策 | 让步往往"退一步强调更要紧的"，落点仍在前/后重点 |
| 条件（只有…才、前提、基础） | 对策 | 必要条件 = 对策的**必要性** |
| 对比（A 与 B 相比、过去 vs 现在） | 并列 / 总分 | 要么"提取共性"（并列），要么"突出其一"（重点句） |
| 分总 / 总-分-总 | 总分 | 总分的倒装，中心句还是那个**总句**，只是位置不同 |
| 问题-对策 | 对策 | 先摆问题再给对策，中心 = **对策** |

**识别口诀**：先问"这段是**转折/递进/因果/对策/总分/并列**哪个"；遇到假设、条件、对比、分总、问题对策，别慌——都只是六种的变体，最后落点仍归六种之一。判断标准就一个：**作者这段话最终的"落点/重心"落在哪**。

#### 快速解题模型（实用）

- **旧+新**：过去X + 现在Y → **现在的新情况为重点**（“在此基础上”＝承接＋推进，重点在它**后面**，不是总结前面的；题12）
- **并列强调**：A，B也…后文围绕B展开 → **重点为B**
- **问+答**：提出问题 + 解释说明 → **答案多为对问题的回答**
- **论点论据**：论点为核心；**选项话题要 ≥ 文段**，只选论据（话题<论点）必错

#### 实用技巧（你的易错点）

- 🚩 **话题限定**：正确答案要体现核心话题；出题人爱做同义替换，**专业名词一般不替换**。
- 🚩 **两个选项主语相同时，别比主语，比谓语**（题12）。同主语＝中心词两边都拿对了，胜负全在**谓语（落点）**：把谓语拆成几块，逐块回原文找，**有成分在原文找不到出处的优先排除**（选项里只要混进一个无中生有的成分，就是白送的排除点）。例：B“个性化专业设置**是增强吸引力竞争力的有效途径**”＝尾句原话；C“是高校之间**生源竞争普遍采用**的方式”——“生源竞争”是②句背景、落点是上游，“普遍采用”原文根本没有。另：**“最集中的／最关键的”这类强表述出现在背景句里，也只是引子，不代表它是落点。**
- 🚩 **关键词提取题：不许数词频**（题11）。顺序是 ①哪几个词能**罩住每一句** → ②**落点在哪**（找“究其实质／说到底／更是一种”这类总结＋递进的标志）→ ③只在某一句出现、后文没再展开的词（背景、举例、某个作用）是**边角料**，不能当关键词。
- 🚩 **结合选项定中心**：文段脉络不明确时，用选项反推。
- 🚩 **假设代入反推**：假设某选项对，反推文段该怎么写，再核对。
- 🚩 **同构选项排除**：两个选项表达内容一致 → 一起排除。
- 🚩 **别追求"最全面"**：中心句 = 总句的直接转述即可，不是越全面越好。全面但夸大的（绝对化）往往是干扰项。
- 🚩 **笼统不等于保险，具体也不自动正确**（题15）：先保文意和语气，再比谁更贴最终落点。“有弊端／有影响／有问题”若没说清文段具体在质疑什么，通常竞争力弱；但具体项若把“未必”强化成“完全没有”，也不能机械优先。争议题按当前平台口径作答，不提炼成死规则。

### 标题选择题（贴合全文重心） {#title-selection}

**沿用站内方法**：[标题填入题](言语体系总览与真题归位.md#_2-标题填入题)——先契合中心，再考虑简洁与吸引力。

1. **先概括共同指向**：结合各句关系，判断作者在强调什么。首句出现观点，不代表它一定能统摄后文；举例要追问“具体在证明什么”。
2. **再对比选项重点**：与某一句对得上，只能说明有依据；还要看选项是否抓住全文重心，是否额外加入文段没有强调的意思。
3. **最后核对表达程度**：既不因标题听起来宏大就选，也不见“无限”等词就机械排除。结合语境辨别概括性修辞与无依据的事实断言，标题也不能随意夸张。

**本次易错**：把“创新持续释放价值”收窄成首句里的“助力高质量发展”，忽略后文抗疫与生产生活方式的改变；“又好又快”还带入了全文未着重讨论的速度维度。

**复习提醒**：先问例子在证明什么，再选能概括全文重心的标题；不能只与首句对得上。

→ [练习：题16 · 创新驱动（逐题复盘）](../cuotiben/xingce-cuoti.md#yanyu-20260912-16)

### 意图推断题（作者"意在强调/想表达"）

> 中心理解题的进阶：**不但要找中心句，还要问"作者真正要强调的是哪层？"**

- 紧接中心句，但要对"哪个才是作者真正落点"做判断。
- 警惕：**把"必要条件/前提"当成"作者的结论"**（如"只有…才"是条件，不是对策）。
- 警惕：**把"论据"当成"论点"**（支撑句不是作者最想强调的）。
- 陷阱：**"在于/关键"题** → 一定要找文段点明的**症结/针对性对策**，不是复述理想条件。
- 陷阱：**"对策优先"用过头**（题9）→ 认出"为此/需要"是对的，但要再问一句：**这个"需要"后面是一个对策，还是一串并列做法？** 一串并列做法时，正确答案是**上位总对策**（能罩住全部），不是排在第一条的那个分做法。

### 细节判断题

**逐项对照原文**，注意易错的几种改写：
- 无中生有、偷换概念、偷换时态、偷换逻辑、绝对化、强加对比、与文意不符
- **选非题**：绝对化的表达作为答案的概率更高；**选是题**：温和的表达概率更高
- **做题顺序**：选项短→先看选项画关键词→回文段对比；文段短→先读文段再做选项

### 推断题

基于原文合理推断，不选原文直接复述的选项

## 三、语句表达

### 接语选择题（接下来最可能讲的是？）

> 🚩 核心：**话题一致性 + 行文逻辑合理**。别被尾句某个词带走。

**分类与易错点：**
- **常规接语**：①尾句提出**新话题**→后文围绕新话题展开（前提：那个词真的是"新话题"）；②结构=提出问题+分析问题+**提出对策**；③文段宏观话题→下文具体展开。
- **看结构接**：总分→先接总再接分；并列→分1分2分3分1，接分2；尾句提示转折→按转折接。
- **下文选非**：与文段矛盾 / 话题不一致 / 前文已论述过。
- **你的易错**：把尾句的**比喻词**当成新话题。真正的判断标准是"**这个词是不是成了文段新的论述对象**"，不是"它在不在尾句"。

### 语句填空题

**核心**：话题一致 + 逻辑合理。按横线位置触发：

| 位置 | 作用 |
|---|---|
| 段首 | 总结全文 / 总结下一句(冒号引出表解释) / 引出下文(中心文段) / 话题引入(通过排除法选) |
| 段中 | 承上启下；前后一致→保持相同；前后不同→搭桥 |
| 段尾 | 总结全文 / 提出对策 / **总结前一句话**（承上——接紧邻前一句的落点，**不要退回段首的总起句**） |

**段尾填空：先过一遍这两条**：

1. **横线紧挨着谁，就接谁的落点**。段尾填空的“上句”是**紧邻的那一句**，不是段首的总起句。
2. **看逻辑链条的上下游（主判据）**。把全段排成一条链，横线处的内容**必须比前一句更靠“下游”**，往回流的一律排除。
   - 题10 的链条：`构建法治理论 → 深化立法理论研究 → 促进从“法”到“良法”` → **【横线】**
   - A“提升立法质量和法治水平”在最下游 ✅（“良法”＝立法质量，A 是它的兑现，还顺带兜住了第一句的“法治理论”）
   - B“提升基本理论研究水平” ≈ 和“深化研究”是**同一环**（同义反复）；C“提高法治理论水平”、D“构建经济法理论”都退回了**链条最左端** ❌
   - ⚠️ **判据是“上下游”，不是“做法/结果”**：四个选项**语法形式全是“动词+宾语”**，光看形式分不出来。**连接词也只是辅助信号**——A 的“从而”（结果）＋下游内容双对；**D 的“进而”（递进）连接词看着也对，但内容是上游的“构建理论”——连接词对、内容错，是最坑的一项**。

### 语句排序题

**从选项入手，边做边排除，不建议自己排序。** 四步：首句、捆绑、顺序、尾句。

1. **首句对比**：能当首句=下定义、背景引入；不能当首句=指代不明、关键词后半部分、举例子
2. **确定捆绑**：指代词 / 关联词 / 话题一致
3. **确定顺序**：问题+分析+对策 / 观点+解释说明 / A+B / 全称+简称 / 时间顺序（话题一致）/ 日常做事逻辑
4. **尾句对比**：总结全文 / 提出对策

## 📝 我的备考笔记

### 核心病症（15 题总结）

> **方法都背了，但一战就丢了。真正的问题不是"不知道方法"，而是"不知道这题该调用哪条方法"。** 以下是江苏言语真题暴露的 9 大病因。

| # | 病症 | 表现 | 该记住的对策 |
|---|---|---|---|
| 1 | **越全面越好** | 把"全面但夸大(绝对化)"的选项当正确项（题1、6） | 中心句=总句直接转述即可，**不是越全越好**；见"密不可分/第一方阵"这类绝对化词要警惕 |
| 2 | **被局部词/字面带走** | 见尾句"公共服务""无人区"就选（题2、3）；**按词频数“医疗/风险”选D**（题11）；**盯着修饰词"利润微薄""房价高昂"，选了个连中心词都没有的 B**（题13） | 先定文段**话题**，再看选项；判断"这个词是不是新话题/核心概念"。**关键词提取不许数词频，要看落点**；**修饰词不是关键词，答案里必须有全段的中心词** |
| 3 | **把条件/论据当结论** | "只有…才"→选D；"不确定性"→选B（题4、7） | 必要条件≠对策；论据话题<论点必错，**选项话题要≥文段** |
| 4 | **细节题看不出改写** | 题5把"原理相近(错)"当成对 | 选非题盯**偷换概念/绝对化**；问到"相似"要分清**相似发生在哪一层** |
| 5 | **"对策优先"用过头** | 认出"为此/需要"就顺势挑了第一条做法（题9选B） | 对策也要问"为谁服务"：**一串并列做法→选上位总对策**，不选单条分做法 |
| 6 | **落点抓成上游／背景** | 段尾填空把横线填成段首总起句的复述（题10选D"构建经济法理论"）；被②句"**最集中的**竞争是生源竞争"勾住、选带"生源竞争"的C（题12） | 段尾先看**紧邻前一句**要什么，再把全段排成一条链——**横线处必须比前一句更靠"下游"，往回流的一律排除**；**背景句里的强表述（"最集中的"）也只是引子，不是落点** |
| 7 | **把结论/箭头读反方向** | 尾句"正是……**使得**制造业**得以**生存"，B 读成"制造业**很难**生存"（题13）；①句"执法是维护民法典权威的**手段**"，B 读成"民法典能规范执法"（题14） | 见"**正是……使得……／正是因为……才……**"就是**因果强调句**：先翻成大白话（谁让谁怎么样了），再对选项——**方向一律不能反**。更广地说：**跟首句"神似"的选项，先把箭头画出来**——"A 是维护 B 的手段"常被倒置成"B 能 A"。这与前6条不同：前6条是"找错位置"，这条是**内容找对了却读反了**，属于最可惜的一种错 |
| 8 | **用"扫词"代替读结构** | 排除 A 的理由是"A 的'切实保障群众权益'**文段并未提到**"，可尾句原文就有"依法严肃处理侵犯**群众合法权益**的行为和人员"（题14） | 判据是**结构＋落点**，**不是"原文有没有这个词"**。扫词做对了是**侥幸**：出题人只要把 A 改写成"实施民法典能够依法处理侵犯群众权益的行为"，扫词就排除不掉。排除任何一项都要能说出它**错在哪**——偷换？主体错位？还是非重点？ |
| 9 | **把问号当成没观点，把笼统当成保险** | 题15认为“是否……呢”只是发问，排除 C；再因 D“至少不是错话”而选择 D | **反问要结合语境还原倾向**；单选不是找“能说通”的话，而是在正确项中比谁更贴落点。同时检查语气强度，不能机械套“越具体越好” |

> ⚠️ 病症1、5、6是**同一个根**（分不清"哪儿是落点"），只是发作方向不同：病症1是"什么都想要"，病症5是"抓到一条就以为抓到全部"，病症6是"退回起点/停在背景"。**题11（关键词提取）是病症2的新变种：停在①的表层概念"患者自决权"，没走到⑥"究其实质"的落点**；**题14是病症6的新变种：停在①的引子句，被"尤其"后面的重心甩下**。题1、6、9、10、11、12、14连着栽七回，**"落点判断"是你唯一的、也是压倒性的第一回炉项**。
>
> 🔻 **病症7（方向读反）已连栽两回，升格为通病**：题13是尾句"正是……**使得**制造业**得以**生存"读成"很难生存"；题14是 B 项把①句"执法是维护民法典权威的**手段**"倒置成"民法典能规范执法"——**同一套卷（2021江苏A卷）连着两题**。前 6 条是"没找到地方"，这条是"找到了地方、**看反了字/箭头**"——最可惜，也最容易补：见"正是……使得……"就翻成大白话；见跟首句神似的选项就**先把箭头画出来**。
>
> 📌 **病症8（扫词）是唯一的"侥幸型"错误**：它不是让你选错，而是让你**用一种错误的理由选对**——这次侥幸排除掉了 A，方法本身却站不住。它不致命，但会掩盖病症6（你其实是没抓到"尤其"后的重心，只是碰巧 A 有破绽）。**改法：每排除一项，都写得出它错在哪一类。**
>
> 📌 **题12还留了一个新工具**：当两个选项**主语相同**时，胜负全在**谓语**——把谓语拆开逐块回原文找出处，**有成分找不到出处的优先排除**（C 的"普遍采用"原文根本没有，是白送的排除点）。

### 🎯 两步定位法（先定话题，再找中心）

> 中心题/意图题卡住时，十有八九是这两步没做。先定**话题**，再找**中心句**，两者不是一回事。

**第一步 · 定话题（这段围绕谁）**
话题 = 一个**名词短语**，整段都在围绕它说。怎么找：
- **高频词**：反复出现的**实词/专业名词**（如"产业链""资源分配""数字游戏与诗歌"）
- **选项共同覆盖**：4 个选项都围绕的那个词，基本就是话题（出题人照话题出选项）
- 判断标准：**整篇都在说它**，不是某一句的边角料（"公共服务"只是修饰，不算话题）

**第二步 · 找中心句（作者要说什么）**
- 中心句 = 有**立场**的结论/对策/观点，不是背景、举例、论据、必要条件
- 用上面「按结构触发」表定位：识别结构 → 按结构找中心句

| 结构 | 中心句位置 |
|---|---|
| 转折 | 转折后 |
| 递进 | 递进后 |
| 因果 | 结果 |
| 对策 | 原文对策 |
| 总分 | 总句 |
| 并列 | 全面概括 / 提取共性 |

**打个轮子**：先定"话题"（围绕谁）→ 再找"中心句"（作者立场）→ 中心句转述 = 答案。

> 🚩 **"高频词"和"尾句"哪个重要？都不是判据，两个是不同问题的线索**：
> - **高频词 → 定话题**（这段在说谁）。它永远告诉不了你"作者想说什么"。
> - **结构标志词 → 定落点**（作者要说什么）。**尾句只是位置线索，不是判据**——尾句可能是并列做法之一（题9）、可能是比喻（题3"无人区"）、可能是"具体来说"的解释（题2"公共服务"）。
> - **答案 = 话题词 ＋ 落点词**（有时加个背景词）。例：题11 = 知情同意（话题）＋风险承担（落点）＋医疗领域（背景）。
> - ⚠️ **关键词提取题禁止数词频**。落点常常**只出现一次**（题11"风险的承担"），而高频的往往只是**话题**。
> - **判"尾句算不算落点"三问**：①在"具体来说/例如/即"的解释里？②是一堆并列做法里的**一条**？③有比喻/双引号/偏正修饰？——中任意一条，先剥掉再看中心词。

### 技巧心得（每次做题前默念）

1. **先定话题**，再对选项。整段在讲什么？记住关键词再排除。
2. **识别题型**先于做题。看到"接下来最可能讲"→接语；"作者认为关键在"→对策；"下列不符"→细节选非。
3. **中心句=作者的结论/对策/观点**，不是背景、举例、论据、必要条件。
4. 正确选项是**原文转述**（尤其专业名词不替换），见"看起来很对但换了词"高度警惕。

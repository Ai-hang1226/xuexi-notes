# 文章写作：先定论点，再搭骨架

**一句话**：大作文的分差，一半在论点准不准，一半在结构清不清。文采是加分项，不是及格线。

::: tip 本页怎么用
按「审题定论点 → 搭骨架定字数 → 逐段填充」的顺序用。开头不会写，往往不是语言问题，是论点没想清。

来源：《申论作文》DAY01（卷面与框架）、DAY02—03（论点提取与润色）、DAY04（开头）、DAY05—06（议论与策论填充）、DAY07（结尾），PDF 第 1—59 页。
:::

## 一、先看"表面功夫"：阅卷只有几十秒

讲义把这部分放在第一天，因为阅卷是「时间短、任务重」，形式决定第一印象。

| 要素 | 具体要求 | 常见扣分 |
|---|---|---|
| 字迹 | 清晰可辨，不求美观；每笔独立成型，占格子 2/3 | 连笔过多、笔画粘连、字超出格子 |
| 用笔 | 0.5mm 黑色中性笔 | 笔尖过细（0.38mm 以下），扫描后发虚 |
| 卷面 | 写错用**单横线**划掉，后面继续写 | 涂墨团、用修正带、刀片刮擦（扫描出黑块） |
| 段落 | 单段不超过 300 字；每段首行空两格 | 整段一大坨，阅卷找不到分论点 |
| 标题 | 居中，不加书名号；命题作文照抄题目 | 自拟标题跑题、加标点、分两行不对称 |

## 二、结构：三种骨架按题型选

### 1. 经典「五段三分」

```
开头段：现象/背景 → 问题 → 核心论点
分论点一：论点句 + 论据 + 分析
分论点二：论点句 + 论据 + 分析
分论点三：论点句 + 论据 + 分析
结尾段：升华 + 呼应
```

三个分论点最好落在不同维度（制度／服务／文化，或主体／行为／保障），避免同义反复。

### 2. 问题对策型（策论文）

```
开头 → 问题分析 → 对策一 → 对策二 → 对策三 → 结尾
```

对策要占全文 60% 以上，且具体可操作。

### 3. 辩证关系型（A 与 B）

```
开头 → A 的重要性 → B 的重要性 → A 与 B 的关系 → 结合实际的做法 → 结尾
```

适用于「科技与人文」「传统与现代」这类关系型话题。

### 字数分配（以 1000 字为例）

| 部分 | 字数 | 要点 |
|---|---|---|
| 开头 | 约 100 字 | 背景引入＋问题/现象＋核心论点，三层即可 |
| 分论点段 | 每段 200—250 字，共 3 段 | 观点句＋案例/数据＋分析句 |
| 结尾 | 100—150 字 | 呼吁式、展望式或引用式 |

分论点段明显偏短（不足 150 字）通常意味着只有观点没有论证。

## 三、文体辨析：别把策论文写成议论文

| 文体 | 核心 | 结构 | 判断 |
|---|---|---|---|
| **策论文** | 侧重「怎么办」 | 问题界定＋对策论证＋对策实施 | 对策占 60% 以上 |
| **议论文**（狭义） | 侧重「为什么」 | 论点＋论据＋论证 | 以说理为主 |
| **广义议论文** | 议论为主的文章统称 | 视题目而定 | 申论大作文多属此类 |

题干说「提出对策」「就……提出建议」→ 策论文；说「结合对这句话的理解」「谈谈你的思考」→ 议论文。

## 四、总论点：三种题干，三种定法

| 题干形态 | 方法 | 例 |
|---|---|---|
| **给定标题**（「以《A》为题」） | **直接照抄**，居中，不加书名号 | 《试谈"有"与"无"》《以水为师》 |
| **给一句话**，要求自拟 | 短句**缩句**保主干；长句**扩充**加修辞 | 「跟着时代大潮走，做好自己的事」→《紧跟时代大潮，做好自己的事》 |
| **给主题/话题** | 主题完整就直接复用并明确主张；主题零散就补句式构成判断 | 主题「好的政策」→《让好政策书写斑斓画卷》 |

总论点必须是**判断句或陈述句**，不能是一个词组。标题即总论点。

## 五、分论点：四种找法

1. **拆题法**：题干含并列关系（也、和、既……又、一方面……另一方面）时，把并列词拆成几个维度。
   > 例：「生于虑，成于务，失于傲」→ 深谋远虑（思维）／踏实务实（行动）／戒骄戒躁（态度）。
2. **就近法**：回到题干句子在材料中的出处段落，上下文的观点直接作分论点。
3. **概括法**：把材料的几组做法或几个层面分别概括，提炼成同层级的分论点。
4. **补充法**：材料与主题支持的前提下，补充材料没展开但必要的角度。

**硬要求**：三个分论点必须共同支撑总论点，不能各说各话；层级要一致（都是做法，或都是意义），不能一个讲制度、一个讲情怀、一个讲数据。

## 六、逐段怎么写

### 开头（DAY04）

三层就够：**背景/现象 → 问题 → 核心论点**。约 100 字。

不要用大段排比铺垫，也不要把分论点的内容提前说完。

### 议论段（DAY05）

```
观点句 → 必要阐释 → 贴合的论据 → 分析论据如何支持观点 → 回扣
```

论据三要求：真实、贴题、不编造数据和引文。

**分析句是分水岭**：只写「华为研发投入超千亿」是罗列；补上「这说明唯有把创新作为第一动力，才能打破技术壁垒」，才叫论证。

### 策论段（DAY06）

```
观点 → 解释必要性 → 具体可行的对策 → 总结其作用
```

对策要落到「谁来做、做什么、怎么做」，与[问题对策](wenti-duice)的四问一致。

### 结尾（DAY07）

三种收法：呼吁式、展望式、引用式。

要求：收束论点、联系主题；**升华要贴合论证**，不要突然喊口号。引用要准，宁可不用。

## 七、写完自检

- [ ] 标题是不是判断句，有没有跑题
- [ ] 三个分论点是否同层级、是否都支撑总论点
- [ ] 每段有没有「观点＋论据＋分析」三件
- [ ] 开头是否在 100 字左右切入，有没有头重脚轻
- [ ] 结尾有没有回到总论点
- [ ] 字数分配是否接近 100 : 600 : 150

# 图形推理

> 判断推理 · 四大题型之一。[← 返回判断推理总览](panduan-tuili.md)

## 概述

图形推理题量约 10-15 题，找规律，多练就熟了。

## 📊 常见规律类型

| 规律 | 特征 | 示例思路 |
|------|------|---------|
| 位置类 | 图形平移、旋转、翻转 | 看元素移动方向 |
| 样式类 | 叠加、求同、求异 | 看图形间运算 |
| 数量类 | 点、线、面、角、笔画数 | 数完之后找规律 |
| 属性类 | 对称、曲直、封闭开放 | 看整体特征 |
| 空间类 | 折纸盒、三视图 | 空间想象力；四面体用箭头法/移面法 |

## 解题步骤

```
1. 判断图形组成 → 元素相同？（位置类）
                 → 元素相似？（样式类）
                 → 元素不同？（先数数量，再看属性）
2. 数量类数什么？→ 先数面 → 再数线 → 再数点 → 再数笔画
```

## 空间类：四面体折叠（箭头法 / 双箭头法 / 移面法）

**先立地基**：正四面体有 **4 个面、6 条棱、4 个顶点**，且**没有相对面**——任意两面都相邻。所以六面体最常用的"相对面排除法"在四面体处**失效**，只能靠**相邻面关系**判断。每面都是正三角形、任意两面共棱，**任何一面都能转到想看的方位**，这正是箭头法和移面法成立的根本。

四面体展开图只有 **2 种**：**正三角形外框**（一面居中、三面环绕）和**平行四边形外框**（两行两列排布）。

> **两条通用规则（移面法依据）**
> - **规则 A（180° 平角可旋转）**：同一直线上夹 180° 的两条边，折叠后是相邻面的公共边，面可绕它旋转 180° 挪到相邻处。
> - **规则 B（平行边可平移）**：平行四边形左右两条平行边折叠后重合，面可平移到另一边。

### ① 箭头法（定方向 + 邻位）

**原理**：在带方向性的特殊面上画一个单向箭头，考查箭头**上、下、左、右**四个方位对应的相邻面是否与展开图一致。**折叠不会让箭头镜像翻转**，只会整体旋转。

**步骤**：
1. **选参照面**：挑图案有明显指向的面（带尖角 / 带一条明显线）。
2. **画单箭头**：展开图与选项上，用**完全相同起点、路径**画箭头（箭头=上，箭尾=下，箭头左侧=左，右侧=右）。
3. **固定画法**：同一面的箭头画法必须一致，不能换着画。
4. **对比方位**：箭头四方位对应相邻面与题干不一致，就排除。

> **速记口诀**：箭头指上、两侧为左右、箭尾为下。选指向性最强的面来画最省事。⚠️ 若四面体全是空白三角，箭头法使不上，换双箭头法 / 移面法 / 公共棱法。

---

### ② 双箭头法（面内方向 + 相邻左右一起判）

当单箭头分不清相邻面的**左右位置**时，画两支箭头：

| 箭头 | 画法 | 作用 |
|------|------|------|
| 第一支 | 从参照面起点指向面的**特征顶点**（尖角 / 图案端点） | 定**面内图案方向** |
| 第二支 | 从**两相邻面的公共边中点**出发，指向第二面的特征顶点 | 判**相邻面左右位置** |

**判定**：第一支定"脸朝哪"，第二支定"邻面在左手边还是右手边"。选项中箭头左右侧特征与题干对不上 → 排除。

---

### ③ 移面法（把不相邻面搬近）

**为什么需要它**：目标面在平面上**离得很远**，不好想象折叠后挨不挨着。移面法把不相邻面**搬到相邻位置**再看——**不动折叠结果，只变平面摆法**。

**两种操作**：
- **旋转移面（规则 A）**：把目标面绕它与邻面的公共边**旋转 180°** 拼到相邻处；互相垂直的两边之间的面可旋转 **90°**。
- **平移移面（规则 B）**：把目标面**平移到**相邻位置，常用于平行四边形展开图左右平行边，或同一行 / 列连续面的两端。

**移面后配合**：移面只解决"谁和谁相邻"，救不了方向和左右。所以移完面**还要接箭头法或双箭头法判方向**。**移面 + 箭头几乎成对出现。**

> 一句话：「移面法负责把面挪近，箭头法负责判断方向。」

---

**完整流程（按顺序走）**

```
1. 先找特殊面（唯一图案 / 黑块 / 明显棱线）→ 没有就用公共棱法
2. 套箭头法 / 双箭头法定方向 + 邻位
3. 两地面太远想象不出来？→ 移面法搬近
4. 移完再回箭头法 / 双箭头法判断
5. 用公共棱法 / 时针法收尾，排除选出
```

**核心心法**：先特殊面 → 后箭头验证 → 卡不牢就移面 → 再箭头 → 公共棱法收尾，循环到只剩一个。

**辅助方法**

| 方法 | 一句话用法 | 适用 |
|------|-----------|------|
| 公共棱法 | 看两相邻面公共棱中点引出的是虚线/实线、线在哪，须与题干一致 | 最简，万能兜底 |
| 时针法 | 绕一个顶点三个面按方向环视，折叠后顺序不变 | 方向易乱 |
| 标点描棱法 | 标公共顶点，看每顶点引出线条数/图案是否对应 | 复杂图案 |
| 特殊面优先 | 从唯一图案（单点、特殊线、黑块）入手 | 所有题优先 |

# 📗 行测 · 行政职业能力测验

行测是公务员考试的笔试科目之一，考察逻辑思维、语言表达、数理分析和常识储备。

## ⏱ 考试概况

| 项目 | 说明 |
|------|------|
| 题量 | 120-135 题（国考） |
| 时间 | 120 分钟 |
| 分值 | 100 分（大部分岗位） |
| 平均每题时间 | 约 55 秒 |

## 📐 五大模块

### 1. [言语理解与表达](./yanyu-lijie)
- 阅读理解、逻辑填空、语句表达
- 约 40 题，建议用时 30-35 分钟

### 2. [数量关系](./shuliang-guanxi)
- 数学运算、数字推理
- 约 10-15 题，建议用时 10-15 分钟

### 3. [判断推理](./panduan-tuili)
- 图形推理、定义判断、类比推理、逻辑判断
- 约 35-40 题，建议用时 35 分钟

### 4. [资料分析](./ziliao-fenxi)
- 图表分析、数据计算、综合判断
- 约 20 题，建议用时 25-30 分钟

### 5. [常识判断](./changshi-panduan)
- 政治、法律、经济、科技、文史
- 约 20 题，建议用时 10 分钟

## 🎯 做题顺序建议

```
资料分析 → 言语理解 → 判断推理 → 常识判断 → 数量关系
（先抓确定性高分，后做耗时题型）
```

## 📝 备考策略

1. **资料分析先突破**：公式固定、提分最快，争取 90%+ 正确率
2. **言语理解保基本**：阅读量积累是王道，多读多练
3. **判断推理找规律**：逻辑判断题有固定推理框架
4. **数量关系不纠结**：10 题做对 6-7 题就是胜利
5. **常识判断靠积累**：碎片时间刷常识，平时多看新闻

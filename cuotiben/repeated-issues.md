# 反复遇到的问题｜对象、分母与目标式

**先定对象 → 写分子、分母 → 写题目要的目标 → 再取数计算。**

这些题涉及可一起检查的读题动作，但具体错误并不相同；不据此推断同一个心理原因，也不把几题直接判成稳定弱项。选一道回忆即可，不新增试卷。

### 1｜[135题卷第116题](/cuotiben/135题混合真题批改-2026-11-07#q116)：认清分母范围

原提交B，参考A；单题时间和猜测未知。分子正确，分母误用新能源范围，题目需要全部汽车；本人反馈明白。

<strong>下一步：</strong>先遮住解析写“部分／整体”；方法试用及陌生真题验证待进行。

### 2｜[资料专项第12题](/cuotiben/资料分析专项复盘-2026-11-02#q12)：基期与现期

C→D，41秒。知道除以基期，但看错数据代入现期。

<strong>下一步：</strong>写出对应季度再定位；后续验证待进行。

### 3｜[资料专项第17题](/cuotiben/资料分析专项复盘-2026-11-02#q17)：写对目标式

C→C，144秒，答对但返工。先算基期比重，发现选项不符后回查，题目要求两期差。

<strong>下一步：</strong>先写“现期比重－基期比重”；后续验证待进行。

### 4｜[每日真题第6题](/cuotiben/每日测验复盘-2026-11-06#q6)：区分问法

首答D正确但不确定，单题时间未知。本人正确比较金额与数量增速；自述混淆平均数与比重公式而犹豫。

<strong>下一步：</strong>回看[平均数与比重图解](/xingce/平均数与比重-先辨问法再选公式)，找另一道完整真题独立检验。

### 5｜[第一套第12题](/cuotiben/资料分析专项复盘-2026-11-23#a-q12)：再次核对汽车总量

D→A，65秒。本人把新能源汽车销量当汽车总销量；完整原算式未知。与上方135题第116题是同题不同次记录，两次首答分别保留。

<strong>下一步：</strong>先写“其他新能源／全部汽车”，再用渗透率确定分母；独立运用待验证。

### 7｜[第一套第3题](/cuotiben/资料分析专项复盘-2026-11-23#a-q3)与[第15题](/cuotiben/资料分析专项复盘-2026-11-23#a-q15)：平均数增长率与差值

第3题A→C、52秒，a和b对应反了；第15题B→C、142秒，本人将下降率符号弄错。两题问法不同，各自保留原始错误与用时。

<strong>下一步：</strong>先标分子、分母及增速正负，再判断问增长率还是增长量；独立运用待验证。

## 回忆后怎么处理

1. 合上解析，先说题目要比较谁、哪个时期、分子和分母各是什么。
2. 再对照原题及讨论；看懂、同题重做和陌生真题首答分别记录。
3. 在原有练习中选择同考点另一道完整真题，不改编原题、不多加一套正式卷。
4. 记录实际答案、把握和已知用时；没有反馈不记录完成。首次闭卷检查后约2／7天的复查只是建议，未执行不补造日期。

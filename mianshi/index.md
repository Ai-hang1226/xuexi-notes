# 📙 面试

公务员面试考察综合素质：逻辑思维、语言表达、应变能力、举止仪态。

> 💡 笔试是敲门砖，面试是决胜局。面试 1 分 ≈ 笔试 2 分！

## 📊 面试形式

| 形式 | 说明 | 国考/省考 |
|------|------|----------|
| 结构化面试 | 固定题目，固定流程，最常见 | 90%+ |
| 无领导小组讨论 | 多人讨论，考官观察评分 | 少数岗位 |
| 结构化小组 | 结构化 + 互相点评 | 税务系统常用 |

---

## 🎯 结构化面试题型

### 1. 综合分析题
"对于...现象/观点，你怎么看？"
→ 考察：分析能力、思维深度、价值观

### 2. 组织管理题
"领导让你组织...活动，你怎么做？"
→ 考察：计划能力、执行能力、细节把控

### 3. 应急应变题
"遇到...突发情况，你怎么办？"
→ 考察：应变能力、处理问题的条理性

### 4. 人际关系题
"同事/领导...你会怎么处理？"
→ 考察：情商、沟通能力、团队协作

### 5. 岗位认知题
"你为什么报考公务员/这个岗位？"
→ 考察：动机、自我认知、职业规划

---

## 📝 答题通用框架

### 综合分析题：是什么 → 为什么 → 怎么办

```
1. 表态（观点明确）
2. 分析（多角度展开）
3. 建议（简要对策）
4. 升华（联系实际/联系自身）
```

### 组织管理题：准备 → 实施 → 总结

```
1. 明确目标，制定方案
2. 组织实施（人员、物资、流程）
3. 过程把控，应急准备
4. 总结汇报，形成长效
```

### 应急应变题

```
1. 稳定局面（第一时间处理）
2. 了解情况（查明原因）
3. 解决问题（分类处理）
4. 总结反思（避免再次发生）
```

### 人际关系题

```
1. 摆正心态（不抱怨、不冲动）
2. 换位思考（理解对方立场）
3. 沟通解决（主动交流）
4. 反思提升（做好自己的事）
```

---

## ⚡ 面试高分要点

1. **声音洪亮**：考官听一天了，小声说话直接扣分
2. **眼神交流**：左右各位考官都要看到
3. **逻辑词**：第一第二第三 / 首先其次最后
4. **控制语速**：稍慢，给自己思考时间
5. **答满时间**：3 分钟题至少说 2 分半

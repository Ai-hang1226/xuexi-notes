# 大作文

申论大作文 1000-1200 字，占分重（40分左右），是拉开差距的关键。

## 📐 基本框架：总 → 分 → 总

```
开头（150字）  → 亮出总论点
分论点1（250字）→ 论证角度一
分论点2（250字）→ 论证角度二
分论点3（250字）→ 论证角度三
结尾（150字）  → 升华总结
```

---

## 一、开头写法

### 5种高分开头

**1. 引用式开头**
> "治国有常，而利民为本。" 民之所望，政之所向。当前...

**2. 时代背景式**
> 站在"十四五"规划收官之年的关键节点上，...问题日益凸显...

**3. 现象+转折式**
> 近年来，...取得了长足进步。然而，...问题仍不容忽视。

**4. 设问式**
> 如何让...既能...又能...？这成为当前必须回答的时代命题。

**5. 案例式**
> 从浙江"最多跑一次"到北京"接诉即办"，各地探索表明...

---

## 二、分论点论证

### 论证结构

```
分论点（一句话）→ 说理解释（为什么）→ 举例论证 → 回归分论点
```

### 论证方法

| 方法 | 用法 | 示例 |
|------|------|------|
| 举例论证 | 举具体案例 | "比如，某地通过...实现了..." |
| 正反论证 | 做/不做对比 | "如果...,那么...；反之，如果...，那么..." |
| 因果论证 | 分析因果关系 | "正是因为...,才导致..." |
| 数据论证 | 用数据说话 | "据统计，...增长了X%" |
| 引用论证 | 引政策/名言/原理 | "习近平总书记指出..." |

### 常见分论点角度

| 角度 | 分论点模板 |
|------|-----------|
| 主体 | 政府→企业→个人 |
| 领域 | 经济→社会→生态 |
| 环节 | 思想→制度→执行→监督 |
| 发展 | 过去成就→当下挑战→未来方向 |
| 辩证 | 怎么看→怎么办→怎么好 |

---

## 三、结尾写法

### 3种经典结尾

**1. 呼应式**
> 开头提了"民生"，结尾回到"民生" → 形成闭环

**2. 展望式**
> 用对未来可期的描述收束全文

**3. 号召式**
> 呼吁各方行动起来

### 结尾高频句式

- "道虽迩，不行不至；事虽小，不为不成。"
- "一分部署，九分落实。"
- "功成不必在我，功成必定有我。"

## 看到问法先选工具

| 题目在问 | 用哪个 | 最容易错在哪 |
|---|---|---|
| 「增长了百分之几」 | 增长率 | 拿现期当分母，忘记用基期 |
| 「上一年是多少」 | 求基期 | 增长用 `÷(1+r)`，下降用 `÷(1−r)` |
| 「占……的比重」 | 比重 | 分母找错整体，混淆同比与环比 |
| 「贡献率 / 拉动增长」 | 贡献率 | 把两个**增量**换成两个现期量 |
| 「累计转当季」 | 先两次还原 | 直接拿累计值相减 |

## 三步检查

1. **先认量**：分子分母分别是什么，是存量还是增量。
2. **再定式**：写下 `A ÷ B` 或 `(B−A) ÷ A`，不要先按计算器。
3. **后估算**：用百化分或截位直除定数量级，再决定是否精算。

## 01｜词性与兼类词 {#g1}

**具体对应**：实现目标→方案现实；适合岗位→安排合适。

**怎样验证**：动词→形容词；现实也可作名词。

[回到第1题](/cuotiben/类比推理专项复盘-2026-10-30#q1)

| 短句（自拟） | 本句用法 |
|---|---|
| 面对现实 | 现实为名词，指客观情况 |
| 方案很现实 | 现实为形容词，描述符合实际 |
| 适合这个岗位 | 适合为动词，后接对象 |
| 这个安排合适 | 合适为形容词，描述状态 |

“能加很”不是唯一判断标准；积累、累积也须放回句子，不强行规定每个词只有一种词性。

## 02｜释义近义与伴随 {#g2}

**具体对应**：随波逐流→盲从；临渊羡鱼→空想。

**怎样验证**：压缩核心义；伴随反驳不等于释义近义。

[回到第2题](/cuotiben/类比推理专项复盘-2026-10-30#q2)

| 词语 | 核心义 | 本题关系 |
|---|---|---|
| 随波逐流／盲从 | 缺乏主见地跟随 | 释义近义 |
| 临渊羡鱼／空想 | 有愿望而缺实际行动 | 释义近义 |
| 据理力争 | 凭道理竭力争辩、争取 | 可能伴随反驳，非本题最佳释义匹配 |
| 反驳 | 提出理由否定对方意见 | 与维护主张有交集，重点不同 |
| 杯水车薪 | 力量太小，无济于事 | 与坚持不近义 |
| 心不在焉／专注 | 不专心／专心注意 | 相反 |

## 03｜职业与创作成果 {#g3}

**具体对应**：画家→画作；绣娘→衣裳。

**怎样验证**：从业者创作作品，核对角色和方向。

[回到第3题](/cuotiben/类比推理专项复盘-2026-10-30#q3)

验证句：画家创作画作；绣娘制作衣裳。对应的是从业者→成果，不能把画家与绣娘之间“都是职业”的纵向关系，替代各组内部的横向关系。

## 04｜创作与展示场所 {#g4}

**具体对应**：画室→创作画作；舞台→展示服装。

**怎样验证**：同属场所，还需比较具体动作。

[回到第3题](/cuotiben/类比推理专项复盘-2026-10-30#q3)

验证句：画室是创作画作的地方；舞台是展示服装的地方。两边都叫“场所对应”还不足以判一致，继续核对“创作／展示”。

## 05｜工具与原材料 {#g5}

**具体对应**：笔墨→创作书画；布料→制成衣裳。

**怎样验证**：按题目常规语境比较，不只说“用来”。

[回到第3题](/cuotiben/类比推理专项复盘-2026-10-30#q3)

验证句：用笔墨创作书画；把布料加工成衣裳。本题按常规主要角色辨析；“工具不消耗、材料一定消耗”等口诀不作绝对标准，墨也会进入作品。

## 06｜雅称指代与种属 {#g6}

**具体对应**：丹青借指绘画；霓裳羽衣属于服饰。

**怎样验证**：换个称呼与“一种”分开，先核词义。

[回到第3题](/cuotiben/类比推理专项复盘-2026-10-30#q3)

验证句：丹青可以借指绘画；霓裳羽衣属于服饰。这里按题目词义取舍，不把所有雅称都当作无条件全同，也不忽略词语多义。

## 07｜比率与三个位置 {#g7}

**具体对应**：生师比＝学生÷教师；合格率＝合格÷总数。

**怎样验证**：先标分子分母，再比较第一／第三项。

[回到第5题](/cuotiben/类比推理专项复盘-2026-10-30#q5)

$$
\text{生师比}=\frac{\text{学生人数}}{\text{教师人数}}
$$

$$
\text{合格率}=\frac{\text{合格产品数}}{\text{产品总数}}
$$

$$
\text{质量浓度}=\frac{\text{溶质质量}}{\text{溶质质量}+\text{溶剂质量}}
$$

“甲与乙之比”是甲÷乙；专有指标名按定义。生师比＝生÷师，租售比＝租金÷售价；**存贷比＝贷款余额÷存款余额**，是名称顺序不能硬套的例子。利润率区分成本利润率与营业收入利润率；本题无需额外金融推断。

## 08｜方式效果与实现手段 {#g8}

**具体对应**：移动支付→便捷交易；共享单车→优化利用。

**怎样验证**：手段、效果、种属分开；不强称必要。

[回到第7题](/cuotiben/类比推理专项复盘-2026-10-30#q7)

验证句：移动支付有助于交易便捷；同一辆共享单车可服务不同时段的人，有助于提高利用率。另一关系：移动支付是电子支付的一种。**“是……一种”“通过……完成”“有助于……”各自验证，不能只笼统说有关联。**

平台把部分选项称作“条件对应”，本页按实现／应用上的联系解释，不推广成严格必要条件；远程购物可使用其他支付方式。

## 09｜描写时段的同反 {#g9}

**具体对应**：大天白日—更深露重；日上三竿—月黑风高。

**怎样验证**：两边均为白天—夜晚，不只看字面。

[回到第9题](/cuotiben/类比推理专项复盘-2026-10-30#q9)

| 词语 | 白话义 |
|---|---|
| 大天白日 | 大白天。 |
| 昼伏夜行 | 白天隐藏，夜间活动。 |
| 光天化日 | 明亮白昼；也常指众目睽睽的公开场合。 |
| 更深露重 | 夜已深，露水浓重；更读gēng。 |
| 日上三竿 | 太阳已升得较高、天已大亮，不定固定钟点。 |
| 月明星稀 | 月光明亮，星星显得稀疏。 |
| 夜深人静 | 深夜人声寂静。 |
| 白日当空 | 太阳高悬天空。 |
| 夙兴夜寐 | 早起晚睡，形容勤劳；夙早、兴起、寐睡。 |
| 月黑风高 | 月色昏暗、风很大的夜晚。 |

B两边均为白天—夜晚；C左侧相反而右侧同属夜晚。夙兴夜寐侧重勤劳，不能只抓“夜”字。本人只确认“几个词不理解”，未把表内全部词都记为不会。

## 10｜因果方向与并列 {#g10}

**具体对应**：算法偏见→可能不公平；血栓脱落→可能堵塞。

**怎样验证**：逐边画箭头；可能性、适用条件保留。

[回到第10题](/cuotiben/类比推理专项复盘-2026-10-30#q10)

| 联系 | 验证句与方向 | 边界 |
|---|---|---|
| 算法偏见→不公平／歧视 | 系统性偏差可能对群体产生不利结果 | 算法不必有主观恶意，偏差来源不限于数据 |
| 数据污染→算法偏见 | 错误标注、失真等可能使模型学到偏差 | 并非所有错误数据都造成不公平偏见 |
| 算法偏见→信息茧房 | 某些推荐筛选偏向可能强化单一信息接触 | 平台关系较宽泛，不作普遍必然规律；排B可看右边倒置 |
| 冠状动脉堵塞→心梗 | 心肌供血受阻可能发生梗死 | 非所有动脉堵塞都引起心梗 |
| 血栓脱落→动脉堵塞 | 血栓脱落形成栓子，可能随血流堵塞相应动脉 | 需匹配来源及循环路径，不把所有血栓一概而论 |
| 静脉堵塞／动脉堵塞 | 按堵塞所在血管区分的并列概念 | 并列不能匹配原因→结果 |

## 怎么复习

遮住“怎样验证”，对同一组词自己造句；再比较角色、动作、方向和限定。关系名称想不起时先说句子，不能用额外情节强行凑联系。后续用陌生题检验调用，暂不记掌握或另加试卷。

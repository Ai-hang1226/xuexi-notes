# 一、倍数特性

> 识别：题干给**分数、比例、百分数、倍数**，且对象是**不可分割整体**（人、车、年龄…）。

## 1. 整除型（口诀法 / 拆分法 / 因式分解）

A = B × C（B、C 均为整数）→ A 能被 B 和 C 整除。**因式分解成两个互质的数**，同时满足即整除（如 24 = 3×8）。

**整除口诀**（常用于 3、4、5、9）：
- 3 / 9 —— 看**各位数字之和**（弃 3 法、弃 9 法）
- 2 / 5 —— 看**末一位**
- 4 / 25 —— 看**末两位**
- 8 / 125 —— 看**末三位**
- 7 / 11 / 13 —— 没口诀，用**拆分法**

**拆分法**：把数拆成"接近且明显能被整除的数 + 零头"，只看零头。例：623/7，把 632（？）拆成 7 的倍数 + 零头，只看零头能否被 7 整除。

## 2. 余数型（均分思想，多退少补）

总数 = a×x + b（a、x 均为整数）→ **（总数 − b）能被 a 整除**。

例：每队 3 人余 2，每队 4 人也余 2 → 总数−2 = 12n → 总数 = 12n + 2。

## 3. 比例型（核心：问题和分母、分子的关系）

分子：甲 → 7 份；分母：其他 → 3 份；子母和：总 → 10 份；子母差：甲−其他 → 4 份。
> 甲为 7 的倍数 / 其他为 3 的倍数 / 总数 10 的倍数 / 差为 4 的倍数。

考法变体（**A 与非 A**）：甲/其他 = 7/3；"甲−2 / 其他 = 7/3"→ 总−2 → 10 份。

### ✅ [深挖] 比例交叉·整除问题（统一比例 + 2×2表）⭐高频

> 📌 关键词：**"两组比例针对同一批人"（男:女 / 研:本）+ "某数 = 另一数×倍" + 求"至少/至多"**

**本质**：同一批人按两种维度交叉分类（性别×学历、科目×成绩…）。先统一比例尺，再用 2×2 表 + 整除约束锁"单位量"。

**考场 5 步（60 秒内）**：
1. **统一比例尺** ⭐最关键 —— 各比例都化成"总和相同"（男:女=7:3 和10；研:本=1:4 和5 → ×2 = 2:8 和10）。
2. **画 2×2 表** —— 行放一个维度，列放另一个维度，边界填合计。
3. **设小变量 x** —— 取倍数关系里**较小**的那个。
4. **全表用 x、单位量 a 表达** —— 其余格子靠"行合计/列合计"反推。
5. **整除定单位** —— 人数必须正整数 → 由分母定每份 a 的最小值；"至少"= 取最小单位。

---

**✅ 例题**：男:女 = 7:3，研:本 = 1:4，男本科生 = 4 × 女研究生，则女本科生至少比男研究生多？

**统一比例尺**：研:本 1:4（和5）×2 → **2:8**（和10），与男:女 7:3 对齐。总人数 10 份，每份 = a。

**列表**（女研究生 = x，男本科生 = 4x）：

| | 研究生 | 本科生 | 合计 |
|---|---|---|---|
| **男** | c | 4x | 7a |
| **女** | x | b | 3a |
| **合计** | 2a | 8a | 10a |

**反推**：
- 男研究生 c = 研究生合计 − x = 2a − x
- 男生行：c + 4x = 7a → (2a−x) + 4x = 7a → **x = 5a/3**
- 女本科生 b = 女生合计 − x = 3a − 5a/3 = **4a/3**；男研究生 c = 2a − 5a/3 = **a/3**

**求值**：女本科生 − 男研究生 = b − c = 4a/3 − a/3 = **a**

**整除**：x=5a/3、b=4a/3、c=a/3 都得是整数 → **a 必须是 3 的倍数**，最小 a = 3。

**答案**：差 = a = **3 人（A）** ✅
验证（a=3，总30人）：男本20 / 女本4 / 男研1 / 女研5，男本 = 4×女研 ✓，女本−男研 = 4−1 = 3 ✓

---

**🚫 别踩坑**：
- 比例尺不统一就列表，格子全乱。**先统一再画表**。
- "至少/至多"对应**每份取最小/最大**，答案往往是"单位量"或其整数倍。
- 别硬算具体人数，用"单位量 + 整除"直接锁最小，更快。

**🔑 核心概念**：两个比例针对**同一批人**，所以"总和"能对齐（都凑成 10）。单位量 a 只决定比例、**不决定绝对人数**——所以"有多少人"从来不用真算。

**一句话口诀**：同批人两组比 → 先统一比例尺 → 2×2表设小变量 x → 反推全格 → 分母整除定单位 → "至少"取最小单位。

# 二、方程问题

## 1. 普通方程
- 一个未知数：**设 x → 找等量关系 → 解（约分）**。
- 多个未知数：**设 x、y、z → 抓住问题消元求解**。

## 2. 不定方程（ax + by = M）
**方法：奇偶 / 倍数 / 尾数 / 代入**。
- **奇偶特性**：奇+偶=奇；奇+奇=偶；偶+偶=偶。
- **倍数特性**：当 a 或 b 与 M 有公因子时，先考虑整除。
- **尾数法**：当 a 或 b 尾数是 0（或 5）时，看尾数。

例：37x + 20y = 271 → 20y 尾数 0 → 37x 尾数必为 1 → 试 x 的个位。

## 3. 多个未知数的不定方程（ax + by + cz = M）
- **设小不设大**
- **出现比例设分数**
- **设中间量**

例：28x+32y+33z=400，且 28/32 都是 4 的倍数 → 33z 也得是 4 的倍数 → z 是 4 的倍数。

## 4. 不定方程组
- **整数型**：消元 + 整除。
- **非整数型**（给的量可小数）：**赋零**（令某个为 0，解另一组，差出一个"整组价"）。

例：x+3y+5z=260，x+4y+7z=320 → 赋 z=0 → x+3y=260 / x+4y=320 → x+y+z=140。

# 三、等差数列（含等比）

## 1. 通项 / 性质 / 求和
- **通项**：$a_n = a_1 + (n-1)d$
- **性质**：$a_n = a_m + (n-m)d$，即 $a_n - a_m = (n-m)d$
- **求和**：$S_n = \dfrac{(a_1+a_n)\times n}{2} = a_{中}\times n = 平均数\times n$
  > ⚠️ 奇数项时 $a_{中}$ 存在；偶数项看作中间两项的平均。

## 2. 时段和也成等差（倍数猜题）
**各项成等差 → 每个"时间段"的和也成等差**。常考：一个星期 7 天、五年规划 5 年。用"第一/第三周的产量"列等比式。

例（阶差）：第 2 天起每天比前一天多 200 件 → 第三周产量 = 2×第一周 → 求第几天达 1 万件 → 用 $\text{周和} = a_{中}\times7$。

## 3. 巧求两组数差
两组份数乘积和 = 总数：列 2 元方程（做差更快）。

## 4. 64 的秘密（去奇数）
1~100 从 1 开始每次去掉奇数再重新编号 → 剩下的永远是偶数 → 最终 = **100 以内 2 的最大幂 = 64**。
> 用于"反复去某类、最后剩下几号"的题，直接写结论。

## 5. 等比数列
公比、求和。常与"每次减半""每次×倍"结合（如水质浓度 24 小时下降一半 → 手写 a1…a10 序列找达标档）。

# 四、周期问题

## 1. 周期余数
**特征**：出现循环或周期，问第 n 个是什么。
**三步**：① 找周期（确定起点、长度）→ ② 算余数（总数/周期）→ ③ 做等价（**余几数几**，无余数取周期最后一个）。

例：2 蜀桧、3 刺柏、5 小叶女贞、3 大叶黄杨（周期 13）→ 2019 棵 → 2019/13 = 155…4 → 第 4 棵 = 刺柏。

## 2. 周期相遇
**特征**：多个小周期，求再次相遇 → **最小公倍数相遇**。
例：30 秒 / 36 秒同时闪 → lcm = 180s = 3 分钟 → 第 7 次同闪 = 10 点 + 6×3 分钟 = 10:18。
> ⚠️ **每隔 n 天 = 每 n+1 天**。

## 3. 星期日期推断
**结论**：
- **大月 31 天**：1、3、5、7、8、10、12（一三五七八十腊，三十一天永不差）
- **小月 30 天**：4、6、9、11；2 月 28(29) 天
- **平年 365 天（+1）**，闰年 366 天（+2）；整百年份需被 400 整除
- 跨月：**大月+3，小月+2，平年+1，闰年+2**
- 每连续 7 天必有周一到周日各 1 天；**每连续 28 天各有 4 天**（每月必然 4 周）

**思路**：给定"某月有 x 个周几"→ 用 31/7 = 4…3，根据余数对应的"头三天"推断 1 号。

# 五、工程问题

**核心公式**：$工作量 = 工作效率 \times 工作时间$。⭐

## 1. 具体单位型
有具体效率或总量 → **列方程**。

## 2. 完工时间型（赋值总量公倍数）
**三步**：① 赋值总量（各人完工时间的公倍数）② 求各效率 ③ 列表或列方程。
**方法**：学会抓问题——问"乙单独还需几天"就直接求乙效率。

## 3. 工程费用（包工头思维）
费用最小 → **让便宜的工作最久**。先算各人单价（费用/效率），再排。

## 4. 周期循环工程
确定"一轮"周期，看余数落在周期哪一段，推完成时间。

## 5. 复杂方程完工时间型
不会解、不想解 → **代入**。

## 6. 多个工程的完工时间型
A、B 两个工程+多队 → 分开列两个工程，各赋好算的公倍数。

## 7. 效率比例型
- 直接给：甲:乙=3:4 / 甲的效率是乙的 2.5 倍 **/ 给人数、机器数 → 赋值每效率 = 1**。
- 间接给：工作量相等推效率（甲 4 天工作量 = 乙 3 天 → 效率比 3:4）；合作 36 天后再合做 30 天。
- 变形：**总量比 / 时间比 → 效率比**（效率 = 总量/时间，赋值直接代入比例）。

## 8. 牛吃草问题 💡
**基本公式**：$y = (N - x) \times T$
- y = 原有存量；N = 消耗的变量（牛数）；x = 自然增长速度（草长）；T = 时间
- 变形：**牛吃草**（y=(N−x)T）、**泄漏/枯萎**（此存量也在减少，y=(N+x)T）、**牛羊转换**（1 牛=2 羊 折算）、**求可持续**（N≥x 才能永远吃）。

**定模板**：用（N₁−x）T₁ =（N₂−x）T₂ 解出 x、y，再代第三问。

### ✅ [深挖] 周期循环工程·干几天休几天（最后一步别多算休息日）⭐高频

> 📌 关键词：**"甲每工作3天休息1天 / 乙每工作5天休息2天" + "先干×天另一人加入 + 再用×天完工" + 求某人单独完成要几天**

**本质**：总量方程不难列，**难在数清楚每个人在总跨度里到底干了几天**。两条铁律：

1. **总跨度 = 先干的天数 + 再用的天数**（不是只算"加入后"那段）。
2. **休息周期从各自"第一次开工那天"起算**——乙第 3 天才加入，那第 3 天就是乙的第 1 个工作日。

**考场 4 步（90 秒内）**：
1. 数总跨度 T = 先干天数 + 后用天数。
2. **只排休息日**（比数工作日快）：甲第 4、8、12… 天休；乙每 7 天休第 6、7 天（从加入日算起）。
3. 工作日 = T − 休息天数 → 列两条总量方程 → 解效率。
4. **求某人单独完工**：先得"工作日数 W"，再套周期换算（⚠️ 坑在这里，见下）。

**💡 周期换算通用式**（W 个工作日，每周期"干 k 天 + 休 r 天"，周期长 L = k+r）：
- W ÷ k = 商 q …… 余 rem
- **rem > 0**：天数 = q×L + rem
- **rem = 0**：天数 = q×L − **r** ← 最后一轮干完就收工，**末尾的休息日不算**

---

**✅ 例题**：甲每工作3天休息1天，乙每工作5天休息2天。甲先工作2天后乙加入，再用21天完工；乙先工作12天后甲加入，再用15天完工。甲单独完成需几天？

**① 情形一**（跨度 2+21 = **23 天**）
- 甲：23 天内休第 4、8、12、16、20 天 → 工作 **18 天**
- 乙：第 3 天加入，第 3~23 天共 21 天 = **3 个整周期**（7×3）→ 工作 5×3 = **15 天**
- → $18甲 + 15乙 = 1$

**② 情形二**（跨度 12+15 = **27 天**）
- 乙：27 天内休第 6、7、13、14、20、21、27 天 → 工作 **20 天**
  > ⚠️ 是**全程 27 天**的 20 天，不是只算甲加入后那 15 天！这里最容易漏掉乙先干的 10 天。
- 甲：第 13 天加入，第 13~27 天共 15 天 = 3 个整周期(12 天) + 3 天 → 工作 **12 天**
- → $12甲 + 20乙 = 1$

**③ 联立**（消乙）：①×4 − ②×3 → $(72-36)甲 = 4-3$ → $36甲 = 1$ → **甲 = 1/36**，代回得 **乙 = 1/30**
> 验算：12/36 + 20/30 = 1/3 + 2/3 = 1 ✓

**④ 求甲单独**：需 **36 个工作日** → 36 ÷ 3 = **12 个周期**，余数 0
→ 天数 = 12×4 − 1 = **47 天（C）** ✅

---

**🚫 别踩坑（我的原错）**：
- **算出 12 个周期就写 12×4 = 48，选了 D** —— 第 45、46、47 天连干 3 天就完工，**第 48 天的休息日根本等不到**。余数为 0 时，末尾的休息日必须**减掉**。
- **只算"加入后"那一段**：情形二的乙要算**全程 27 天**里的 20 天。
- **周期起点搞错**：乙第 3 天加入 → 第 3 天才算乙的第 1 个工作日，不能从第 1 天起算。

**🔑 核心概念**：这类题是"工程问题"和"周期问题"的混血——**列方程用工程思维，收尾用周期思维**。前半段算得再准，最后一步"完工那天不用再休息"没扣掉，照样丢分。

**一句话口诀**：**总跨度 = 先干 + 后用；休息日从开工那天数；最后一步余数为 0，天数要减掉那个休息日。**

# 六、几何问题

## 1. 几何公式
圆柱 V = S底×h；同高时体积比 = 底面积比。调水量列方程。

## 2. 三角形
- **普通三角形**：两边之和 > 第三边；两边之差 < 第三边。
- **同底或同高**：底相同，面积之比 = 高之比（多面积题）。
- **正六边形** = 6 个等边三角形（对称性，大六边形 = 两三角形面积）。

## 3. 特殊直角三角形
- **45° 等腰直角**：斜边 = 直角边 × √2（√2 ≈ 1.414）。
- **3-4-5、5-12-13**：勾股数熟记。

## 4. 圆中的直角
- 不在同一直线三点确定一个圆；**直径所对的角 = 90°**（圆上最远两点连任意点成直角）。

## 5. 最短路径
- 两点之间线段最短。
- **两点异侧：直接连线**；**两点同侧：镜面对称后再连线**（反射）。
- 圆柱表面爬行：把侧面展开，找两点直线距离（πr、高度组合成直角边）。

## 6. 几何最值理论
- 立体：**表面积一定，越接近球体积越大**（垃圾袋原理）；体积一定，越接近球表面积越小（饺子皮原理）。
- 平面：**周长一定，越接近圆面积越大**（耳机原理）；面积一定，越接近圆周长越小（剪纸原理）。
- 特殊矩形：**周长一定 → 正方形面积最大**；面积一定 → 正方形周长最小。

## 7. 同比例放缩
边长大 a 倍 → 面积大 a² 倍 → 体积大 a³ 倍。用"大图/小图"面积比直接求价。

### ✅ [深挖] 球体观测·从高处看地球（切一刀变圆）⭐高频

> 📌 一句话识别：**"航天器/卫星在（地球）正上方某高度 + 恰好能观测到北纬××°以内的区域 + 求离地面/离北极多高"**

**直观想象：** 把地球沿"过北极的竖直线"切一刀，就变成一个**圆**（半径 R）。"看地球" = "看这个圆"。

**全题的钥匙：** "恰好看到 45° 纬线" = 视线**正好擦着圆边（切线）**，切点和心连线与切线成 **90°** → 整题变直角三角形。

**✨ 三句话出答案：**
1. **该用哪个角**：给的纬度是从赤道往上量的，图上那个角要从北极往下量 → **图上角 = 90° − 纬度**。
2. **45° 三角规律**：斜边 = 邻边 × √2（邻边 = R）→ **地心到航天器 = R×√2**。
3. **减一个 R**：高度 = R√2 − R = **（√2−1）×R ≈ 0.41R**。

| 题干 | 图上角 | 地心到航天器 | 离北极高度 |
|------|------|-------------|-----------|
| 北纬 45° | 45° | R√2 | 0.41R |
| 北纬 30° | 60° | 2R | **R** |
| 北纬 60° | 30° | 1.15R | 0.15R |

**口诀**：高度 = R ×（倍数 − 1）；角 45°→√2，角 60°→2，角 30°→1.15。

**🚫 别踩坑**：
- 问的是**离北极**，别把"地心到航天器"当答案，要减一个 R。
- 有限高度**永远看不到整个地球**（到赤道 = 图上角 90° = 要无限高）。

# 七、容斥原理

## 1. 两集合
$A + B - A\cap B = 总 - 都不$

## 2. 三集合
- **标准型**（给各两两交集）：$A+B+C - A∩B - B∩C - C∩A + A∩B∩C = 总 - 都不$
  **尾数法**：左是左、右是右，想快先消负。例：125+126+135−57−73−X+31=240−17 → 7−X=3。
- **非标准型**（给"只满足两项"）：$A+B+C - 满足两项 - 满足三项\times2 = 总 - 都不$
  > 判定：**标准型** = 分别给出两两交集；**非标准型** = 给出"只满足两项"。

## 3. 画图法（三步走）
① 画圈圈 → ② 标数字（从里到外，注意去重）→ ③ 列算式。
- 适用：出现"只满足一个"、或公式法不好用。给比例求比例 → **赋值**更直观。

## 4. 结合不定方程（求最值）
问"至少" → 用"此消彼长"，把 A∩B、总数、都不 串成含未知数的等式，靠整除定最小。

## 5. 结合周期
A = 3 的倍数、B = 7 的倍数 → $A∩B$ = 21 的倍数。先算 A、B、A∩B 人数，再套公式。

# 八、最值问题

## 1. 最不利构造（抽屉原理）
**识别**：至少（最少）…保证…（无论如何至少）。
**方法**：**答案 = 最不利 + 1**。判断口诀：**够：少给 1；不够：全给你**。
例：6 种搭配，要保证 5 人完全相同 → 每 6 种各 4 人 + 1 = 4×6 + 1 = 25。
与排列组合结合时，先数出**共多少种"情况"**（选一科 = 5；选两科 = C(5,2)=10；选一或两科 = 15）→ 每种情况（目标−1）+ 1。

## 2. 构造数列
**识别**：某主体…最…（最…最…；排名第几…最…）。
**方法**：① 构造一个名次 → ② **求谁设谁** → ③ 反向推其它（"立正"）→ ④ 加和求解。
- **问少，从少入手；问多，从多入手**（排第二至少 → 让一、三、四、五尽量低）。
- **总量未知时**：求某个最多 → 总量尽量多；求某个最少 → 总量尽量少。

## 3. 多集合反向构造
**识别**：都满足的最少/至少。
**方法一**：**反向 → 加和 → 作差**（求"都不"最多，总 − 都不 = 都满足最少）。
**方法二（公式）**：$(A_1 + A_2 + \cdots + A_n) - (n-1)\times总量$
例：100 人，学言语 90 / 判断 88 / 资料 92 / 常识 80 / 数量 60 → 都不学最多 = 10+12+8+20+40=90 → 都学最少 = 10。
尾数法：870+750+690−2000 = 310。

# 十、溶液问题

## 1. 浓度公式
$浓度 = \dfrac{溶质}{溶液}\times100\%$；$溶液 = 溶质 + 溶剂$。⭐

## 2. 线段法（混合）
十字交叉/线段法：混合浓度将高浓度的"距离"与量成**反比**。例配比：量之比 = 对方线段长之比。
> 多者混合：**两两混合**，一次解一个。

## 3. 等量变化（蒸发 / 稀释、加盐）
**识别**：溶质不变（或加盐是溶质变但盐全进）。
**方法**：① 列表（溶质 = 溶液×浓度）② 赋值溶质（浓度的公倍数）③ 求加入/蒸发水量。
> ⚠️ 加盐不要线段法，直接：新浓度 =（原盐+加盐）/（原水+加盐−蒸发水）。

## 4. 反复操作（倒出加满）
**浓度会按比例衰减**：最后浓度 = $n\% \times (1-a)\times(1-b)\times(1-c)$（a、b、c 为每次倒出比例）。

## 5. 等量交换（两瓶互换）
整体溶液量不变，倒出=补进 → 甲瓶少的水 = 乙瓶补的酒精（等量）。识别写"等量"直接判相等。

# 十一、植树和方阵问题

## 1. 植树三式（识别先看端点）
- **两端都种**：棵数 = $\dfrac{S}{间隔} + 1$
- **单端 / 环形**：棵数 = $\dfrac{S}{间隔}$
- **两端都不种**：棵数 = $\dfrac{S}{间隔} - 1$
  > ⚠️ 间隔距离取"长度的公约数"（保证拐点都种上）；问"最多/最少"→ 间隔取最小/最大公约数。

## 2. 不移动植树（间隔取最小公倍数）
原间隔 a、新间隔 b → 不移动的间距 = **lcm(a,b)** → 不移动的棵数 = S / lcm + 1。
> 环形不移动棵数直接 = S / lcm。

## 3. 方阵问题
- **N×N 实心方阵**：总数 = $N^2$（**猜平方数**）。
- **相邻两圈差 8，隔一圈差 16**（最外层每边 N → 该层 4N−4）。
- 最外一层原味 44 罐 → 下一层海鲜味 = 44−8=36 → 交替加总。
- 两个实心方阵拼成新实心方阵：**总数 + 缺口 = 平方数** 倒推。

# 十二、经济利润问题

## 1. 基础公式（资料分析解决经济）
- 进价（成本）+ 利润 = 售价
- 利润率 = 利润 / 成本（**分母是成本**）
- 进价 ×（1+利润率）= 售价
- 总价 = 单价 × 数量
- 定价 × 折扣 = 售价

**难点：给比例求比例 → 赋值**（变化谁，赋值谁；给折扣就赋值定价 = 100）
**乘积增长率**：$r_A = r_B + r_C + r_B\times r_C$（用于"进价+售价→利润率"等 A=B×C 型）
例：利润率 20%，进货价降 20% → 赋值定价 100 → 原来成本 100 售价 120 → 现在成本 80 售价 120 → 利润率 = 40/80 = **50%**。

## 2. 方程法（有具体钱数）
列表 → 设未知数 → 根据等量列式子。若只有单价商品，优先切入**进价**；多件商品，优先切入**数量**。

例：进价 40，售价 44 每天卖 300 个，涨 1 元少 10 个 → $y=(4+x)(300-10x)$ → 涨价 x 平均 = (x₁+x₂)/2。

## 3. 分段计费（梯度收费）
**先分段，再汇总**（先定位分段点，讨论费用涉及哪几段，不重不漏）。
例：2km 内 8 元、2–5km 2 元/km、5–8km 3 元/km、8km 以上 4 元/km、不足 1km 按 1km → 花 20 元最多跑 7km。

## 4. 函数最值（利润最大化）
**总利润 = 单利 × 数量**。设涨价/降价 x 次，得 $y=(a+x)(b-x)$ 型二次函数 → $x$ 取两根平均。
例：$y=(4+x)(300-10x)$ x₁=−4、x₂=30 → x=13 → 售价 44+13=57。
> 找出两个根（令 y=0），取平均值即为最值点。

# 十三、行程问题

**核心公式**：$路程 = 速度 \times 时间$。⭐

## 1. 基础行程
$S = V\times T$：画图展现过程，列式求解。只给时间/速度比 → **赋值**（类似工程）。
> 单位换算：1 米/秒 = 3.6 千米/时。

## 2. 火车过桥
- 进洞到完全出去：$S_{洞} + S_{车} = v\times t_{进}$
- 完全在洞里：$S_{洞} - S_{车} = v\times t_{全}$
两式相减解车长。

## 3. 匀加速
平均速度 = $\dfrac{v_{初} + v_{末}}{2}$；分段算每段 S、再看总。

## 4. 等距离平均速度
$v = \dfrac{2 v_1 v_2}{v_1+v_2}$。适用：直线等距离、往返、上下坡往返。
> 上下坡 + 平路：用等距离求"坡来回"平均速度，再与平路混合算总时间。

## 5. 相对行程
- **相遇**：$S = (v_1+v_2)\times t$（速度和）
- **追及**：$S = (v_1-v_2)\times t$（速度差）

## 6. 环形
- 同向：追及 $n\times C = (v_1-v_2)\times t$
- 相向：相遇 $n\times C = (v_1+v_2)\times t$

## 7. 多次相遇
- 两端出发：第 n 次相遇共走 $(2n-1)S$；第 2 次共 3S。
- 同端出发：第 n 次共走 $2n\times S$；时间一致 → 路程比 = 速度比。

## 8. 流水行船
- $V_{顺} = V_{船} + V_{水}$；$V_{逆} = V_{船} - V_{水}$
- $V_{船} = \dfrac{V_{顺}+V_{逆}}{2}$；$V_{水} = \dfrac{V_{顺}-V_{逆}}{2}$
- **漂流瓶 = 只有水速**：漂流时间 = 船往返时间之积 / 差。

## 9. 比例行程（资料思想）
**找相等量、看比例、找份数**：
- S 相等 → V、T 成**反比**
- V 相等 → S、T 成**正比**
- T 相等 → S、V 成**正比**

# 十四、排列组合问题

**排列**（有顺序）：$A_n^m = \dfrac{n!}{(n-m)!}$　**组合**（无顺序）：$C_n^m = \dfrac{n!}{m!(n-m)!}$。⭐

## 1. 基础
- **分类用加、分步用乘**。
- **凑 12 法**：把阶乘拆成 12 的幂次，快速约分。
- 等式型：$C(n,4) = 10\times C(n,3)$ → 展开求 n。

## 2. 分类思想
**识别**：至少…　**方法**：正/反哪种情况少用哪种。正向枚举 or 总 − 不满足。

## 3. 枚举
限制多、选项小 → 一一枚举，不重不漏。

## 4. 捆绑法（相邻）
**特征**：要求在一起 → **先排内部小元素，再当一个大主体排**。$A_{内}\times A_{大}$。

## 5. 插空法（不相邻）
**特征**：要求不挨着 → **先排可相邻的，形成空位，再把不相邻的元素插到空位**。$C_{空}^{不相邻}\times $ 或 $A$。
> 捆绑反向用（"不能相邻"就用插空）。

## 6. 插板法（同素分堆）
**特征**：每人至少一个。**方法：空里插刀**（n 个元素排中间 n−1 空，插 m−1 板）。
- 考法二：不同素分数量（名额分配）。
- 考法三：**每人至少分 k 个 → 先每人减 (k−1) 个，再套标准插板**。

## 7. 错位排列（避嫌原则）
**特征**：没人回归原位。
**记忆**：$D_2=1, D_3=2, D_4=9, D_5=44$；递推 $(D_{n-1}+D_{n-2})\times(n-1)=D_n$。
> 例：8 人第 2 天 3 个不变、2 人互换 → 组合 + 错位。

## 8. 环形排列（相对做法）
n 个围一圈：$(n-1)!$（不分主次，去掉旋转）。有相邻要求 → 先把"块"圈好再排。

## 9. 平均分组
**要除以组数的排列**：分成 m 组且组不标序 → 结果要 $\div m!$。
例：8 人挑 4 人平均分两组（分去射击/格斗是**标序**，挑完直接排）。

### ✅ [深挖] 约束排列·"谁和谁不能相邻"（软肋定端点）⭐高频

> 📌 关键词：**"每人不能连续两天 / 不挨着 + 排顺序，求不同安排数"**

**本质**：给 N 个元素排成一列，某些元素不能相邻，数合法排法。

**考场 4 步（60 秒内）**：
1. **拆约束**：把每个人内部两两配对 → "谁跟谁不能相邻"。
2. **建允许相邻表**：把"谁不能挨谁"翻成"能挨谁"，找"**只挨一个**"的软肋（被禁最多、只剩 1 个可挨）。
3. **钉端点**：软肋只挨那 1 个 → 它**必站队首/队尾**，紧挨该对象。
4. **顺推**：从钉住的头沿表推，锁死就锁死，真分叉再 1~2 步解决。

**💡 关键心法**："连续六天"是幌子——先算"一个窗口排几种"，再 **× 日期窗口数**。7 天取连续 6 天只有 2 种。

**🚫 口诀**：被禁最多的那个，只挨一个，必钉在端点。

**⏱ 考场 2 分钟原则**：
- **双软肋**（2 个只挨一个、两端口锁死）→ 30 秒秒杀，**必做**。
- **单软肋 + 分叉**（锁一头、中间分叉）→ 真做 2 分钟，"能做但先放"。
- 速判：写完"允许相邻表"数**几个只挨一个** → ≥2 快做；=1 且可 3 叉 → 跳过回头填。

# 十五、概率问题

**概率**：$P = \dfrac{有利情况数}{总情况数}$。⭐

## 1. 给情况求概率
- **正向**：$P = \frac{满足}{总}$。
- **反向**：$1 - 不满足$。猜题：分母规整、A+D=100% 互补 → 反向快速排除。
> "至少有 1 个"→ 反向 1 − C(其他, n)/C(总, n) 最快。

## 2. 给概率求概率
**"且 / 先…后…"** → 独立事件相乘。例：A 通过 40%、CD 通过… → 至少通过 1 家且 B 也要过 → P₁×P₂ 分步。
> 残次品概率：**赋值总量**，求各等级数量，再求各等级残次数。

## 3. 跟屁虫问题（先放一个，再放另一个）💡
**识别**：两人坐一起/一排/同一辆车 求概率。
**方法**：先放第 1 个（概率=1），再放第 2 个看能坐的位置。

### ✅ [深挖] 圆桌/环形相邻概率（同类题秒杀）⭐高频

> 📌 关键词：**圆桌、围成一圈、"某几组必须相邻" + "又问另外两人相邻"**

**先记一句话：** 既然规定同部门两人必须挨着，那大家其实被排成了 **4 个"块"**，围着圆桌坐。

**✅ 两种解法（从"最简单"到"用公式"）：**

##### 方法一：邻座法（最简单，考场首选，10 秒出答案）
只看小李一个人。
- 因为同部门必须挨着，所以**小李旁边一定坐着同事** → 小李的 2 个邻座里，**有 1 个是同事**。
- 另一个邻座是"隔壁块"挨着他的人，等概率等于剩下 6 人里的任一个（8 − 小李和同事 = 6）。
- 小王正好在这 6 人里。
- 所以：**概率 = 1 ÷ 6 = 1/6** ✅

##### 方法二：块圈法（爱用公式的人用这个）
**概率 = 两块挨着的概率 × 两人各站对边的概率**
- 一块挨着：2 ÷（块数 − 1）= 2/3；站对边：1/2 × 1/2 = 1/4
- 相乘：**2/3 × 1/4 = 1/6** ✅

**🔑 核心概念**：写"同一部门"必相邻 = 概率 1；写"不同部门"才要装模作样算。

**一句话口诀**：小李两个邻座，一个必是同事，另一个在剩下 6 人里随便抽 → **六分之一**。

**同类题**：
- 圆桌 6 座 3 部门：1/(6−2) = **1/4**
- 圆桌 10 座 5 部门：1/(10−2) = **1/8**
- 同部门：直接 **1**（必然）
- 已知两块相邻：只算站对边 = **1/4**

## 4. 比赛类概率
分局面加总；**更快：反向 1 − 对手连续赢**。
例：甲先胜 2 局胜率 60% → 甲赢 = 1 −（乙连赢 3 局 40%³）= 1 − 6.4% = **93.6%**。

## 5. 抓阄 / 密码类
**等可能性**：每次概率相同。例：按位选奇数 → 总情况 ÷ 权位重排。
> "不超过两次输对" = 第 1 次中 + 第 2 次中（第 1 次不中×第 2 次中）。

## 6. 骰子问题
**6×6 枚举记心间**（和 = 7 有 6 种最多；和为 8 有 5 种 → 5/36）。熟记几个常见和的种数。

# 十六、数量易拿分小题型

> 这章全是"套路固定、背了就有分"的小题，性价比最高。

## 1. 标 1 法（网格走法）🆕
**识别**：给定网格/几何图，规定方向（只能向东/北或向南/西），求最短路线走法。
**方法**：**标 1，路口加和**。起点标 1，每个口 = 上方 + 左方（或下 + 左）累计。
> 最短 = 不走回头路。例：2×3 网格 → 10 种走法。

## 2. 空瓶换酒公式 🆕
**公式**：n 个空瓶换 1 瓶 → 喝掉的 = 买的 + $\lfloor \dfrac{买的}{n-1}\rfloor$。
> 4 空瓶换 1 瓶 → 15 空瓶喝 15/(4−1) = 5 瓶。
> 例：109 瓶、6 换 1 → 109 + ⌊109/5⌋ = 109 + 21 = 130。

## 3. 货物集中（统筹运输）🆕
**识别**：货物集中到哪，运费最低。
**方法**：**不看长度，只比重量；偏向思维，轻的流向重的**（划线→求和→轻到重）。
> 两侧比重量，重的那边集中。例：5 集散地 10/25/45 人 → 集中到人最多的。

## 4. 线切面问题 🆕
**识别**：用直线切割平面，后一条与前每条都产生新交点。
**结论**：1 条 2、2 条 4、3 条 7、4 条 **11**、5 条 **16**、6 条 **22**（规律：增量 +2、+3、+4…）。
> 记 5 线 16 面、6 线 22 面。例：分 46 块要 9 条直线。

## 5. 时间统筹：见缝插针 🆕
**识别**：多项目、部分可合并（多个交费/取药合并、等结果时可做别的）。
**方法**：等结果时做其他科室；可合并的交费/取药合并一次。找"最长链"。

## 6. 爬楼问题 🆕
**思维误区**：从 1 楼爬到 N 楼 → **实际爬 N−1 楼**，休息 N−2 次。
> 每层耗时、每多一层加速度，分开算爬楼和休息，用等差数列求和。

## 7. 网状图（最短路径）🆕
**识别**：楼与楼连通求最短线。方法：**找最短（生活思维）**。n 栋楼要 n−1 条边，贪心选最小边不形成环。

## 8. 天平问题（脑筋急转弯）🆕
**识别**：天平称重 / 找假币。
- **找假币**：用天平 n 次，最多可判 $3^n$ 个球（9 个 → 2 次，有 1 个略重）。**猜题：天平 → 3**。
- **称重**：先用砝码拆出"一半"，再逐份拆到目标。

### ✅ [深挖] 统筹优化·指派问题（最优分配）⭐高频

> 📌 关键词：**"×人做×件事/×道工序，每人负责一个，求总时间最少"**

**本质**：给一个 N×N 表，要求 **每行选一个 + 每列选一个，使总和最小**。

**考场 3 步（30 秒~1 分钟）**：
1. **每列圈最小**（谁做这件事最快）——因为"每件事必须有人做"
2. **锁定"最独一无二的最小"**：某列最小只此一人 → 几乎锁定
3. **剩余行列手动拼最小** → 得一组可行解；再用**互换微调**检查能否更低

**微调口诀**：交换两人工序，若"换进来的两数之和 < 换出去的两数之和"就换，换不动为止。

**⚠️ 别做**：别硬上匈牙利算法。人数 ≤ 5 用"列最小 + 拼组 + 互换"最稳。

### ✅ [深挖] 买赠优惠·买几送几（套餐 + 余数法）⭐高频

> 📌 关键词：**"单价 + 买几送几 + 合计买了 N 个 + 共花 M 元 + 求其中一种数量"**

**本质**：促销**送的也算进"总数"**，但 M 元**只花在实付的那部分**。先把两种商品都凑成**相同价格的一个整组**，用"总金额 ÷ 整组价"拆出整数组 + 余数。

**🔑 第一个大坑**："合计买了 56 个"指**拿到手的（含赠送）**。别把 56 直接当"花钱买的个数"。

**解法一：套餐 + 余数法（50 秒）**：凑成 36 元整组 → 606 ÷ 36 = 16 组…余 30 → 余数 = 各贵一件 → 列组数方程。
万能用：**实付钱 = 单价 ×（总个数 − 送的个数）**；送的 = ⌊总个数 ÷ 每组套数⌋。

**🚫 别踩坑**：算出答案一定**代回验证**；整组价不等 / 金额整除时可能多解 → 代入法兜底。口诀：**代回验证，一个不能多**。

### ✅ [深挖] 物资调运·运费最省（运输问题）⭐高频

> 📌 关键词：**"×地有货 ×吨、×地有货 ×吨，都要送到两个工厂/仓库，求运费最少"**

**本质**：2 产地 + 2 销地，供给 = 需求时只剩 1 个自由度 → **答案必在端点**（某条路线运量为 0）。

**考场 3 步（40 秒）**：
1. **列运费表**（行产地、列销地，右下填供给/需求）。
2. **对角差分** ⭐：比较对角① A→甲+B→乙 和 对角② A→乙+B→甲，**哪条便宜，货就走那条**。
3. 从最便宜线填满 → 缺口另一家补 → 算总价。

**💡 口算版**：比完对角直接判哪格被挤成 0（对角①大 → A→甲=0）。
> ⚠️ 前提：两产地都要够撑起另一条对角，否则出现"硬下界"（某产地供给 < 某销地需求 → 贵的线被迫分摊）。做供给不对称的题先看缺口。

**原理**：设 x = A→甲，费用 = 常数 +（对角① − 对角②）×x，最值在端点。

### ✅ [深挖] 首尾双向取号·号码互不重叠（每隔几个号取一个）⭐高频

> 📌 关键词：**"从1号开始每隔×个号拿一个 + 从最后一个往前每隔×个号拿一个 + 没人同时拿到两种 + 最多/至少几人"**

**本质**：两条等差队列（A 从 1 递增，B 从 N 递减），"没人同时拿" = 两列**没有公共号**。

**⚠️ 第一个大坑**：「**每隔 k 个号**」= **步长 k+1**（隔 6 → 步长 7）。

**🔑 核心**：两列必有碰头点（两数列每隔 lcm 撞一次，躲不掉）。能做的是**选最大的碰头点，让 N 缩到它前面**。

**解法（周期法 60 秒）**：① 换算步长 ② 每列记"除以几余几"（A ≡ 余步长A；B ≡ 余 N 的余数）③ 最大碰头点 = 1~（步长A×步长B）里"÷步长A余1"的最大号 ④ N 对余数、贴它底下取最大 → **答案 = 最大碰头点 − 步长B**。

**🚫 别踩坑**：步长 +1；B 列递减；真把 B 列排开检查一遍。

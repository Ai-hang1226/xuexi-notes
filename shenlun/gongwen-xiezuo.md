# 公文写作

公文写作题考察对机关常用公文格式和语言的掌握程度。

## 📋 常见文种

| 文种 | 用途 | 国考出现频率 |
|------|------|------------|
| 通知 | 传达要求、告知事项 | ⭐⭐⭐ |
| 报告 | 向上级汇报工作 | ⭐⭐⭐ |
| 倡议书 | 发起号召、动员行动 | ⭐⭐⭐ |
| 讲话稿 | 会议/活动发言 | ⭐⭐⭐ |
| 调研报告 | 汇报调研结果 | ⭐⭐ |
| 方案/建议书 | 提出工作方案 | ⭐⭐ |
| 简报 | 简要汇报情况 | ⭐⭐ |

---

## 一、公文基本格式

### 通用结构

```
标题
  ↓
称谓（写给谁）
  ↓
正文（开头 + 主体 + 结尾）
  ↓
落款（发文单位 + 日期）
```

### 标题格式

| 类型 | 格式 | 示例 |
|------|------|------|
| 标准式 | 关于+事由+的+文种 | 《关于开展安全生产专项检查的通知》 |
| 简式 | 直接写文种 | 《通知》《倡议书》 |

---

## 二、各文种模板

### 通知

```
【标题】关于...的通知

【称谓】各有关单位：

【开头】为...（目的），根据...（依据），现将有关事项通知如下：

【主体】
一、...
二、...
三、...

【结尾】以上通知请认真贯彻执行。如有问题请及时与...联系。

【落款】
XX单位
2026年X月X日
```

### 报告

```
【标题】关于...情况的报告

【称谓】XX领导/XX上级部门：

【开头】根据...（背景），现将有关情况报告如下：

【主体】
一、基本情况/工作进展
二、主要做法/存在问题
三、下一步打算

【结尾】特此报告。

【落款】
XX单位
2026年X月X日
```

### 倡议书

```
【标题】[主题]倡议书

【称谓】广大...朋友/同志们：

【开头】[背景描述+发起倡议的理由]

【主体】
为此，我们倡议：
一、做...的表率
二、当...的先锋
三、争...的模范

【结尾】让我们携起手来，共同...！

【落款】
XX单位/组织
2026年X月X日
```

### 讲话稿

```
【标题】在...会议上的讲话

【称谓】各位领导、同志们：

【开场白】大家好！很高兴...

【主体】
一、[回顾/意义/成绩]
二、[问题/挑战/形势]
三、[希望/要求/号召]

【结尾】谢谢大家！
```

## ✍️ 公文语言要求

| 要求 | 说明 | 反面示例 |
|------|------|---------|
| 简洁 | 不要啰嗦 | "在当前这个新的历史时期下" → "当前" |
| 准确 | 语义无歧义 | "大概""可能""应该" → 尽量不用 |
| 规范 | 用正式书面语 | "搞定" → "完成""落实" |
| 得体 | 对上对下语气不同 | 报告用"恳请"，通知用"务必" |

### 常用动词（收藏！）

| 场景 | 动词 |
|------|------|
| 表达做法 | 实施、推进、落实、开展、加强、完善、健全、深化 |
| 表达成果 | 取得、达到、实现、完成、建立、形成 |
| 表达决心 | 坚决、务必、切实、全力、扎实 |
| 表达要求 | 要、须、应、可、不得、严禁 |

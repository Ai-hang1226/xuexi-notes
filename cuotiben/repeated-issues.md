# 反复遇到的问题｜对象、分母与目标式

**先定对象 → 写分子、分母 → 写题目要的目标 → 再取数计算。**

这些题涉及可一起检查的读题动作，但具体错误并不相同；不据此推断同一个心理原因，也不把几题直接判成稳定弱项。选一道回忆即可，不新增试卷。

## 回忆后怎么处理

1. 合上解析，先说题目要比较谁、哪个时期、分子和分母各是什么。
2. 再对照原题及讨论；看懂、同题重做和陌生真题首答分别记录。
3. 在原有练习中选择同考点另一道完整真题，不改编原题、不多加一套正式卷。
4. 记录实际答案、把握和已知用时；没有反馈不记录完成。首次闭卷检查后约2／7天的复查只是建议，未执行不补造日期。

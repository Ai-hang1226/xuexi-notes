# 判断推理

## 概述

判断推理考察逻辑思维能力，是行测中第二大模块（约 35-40 题）。

## 📊 四大题型

| 题型 | 题量 | 特点 |
|------|------|------|
| 图形推理 | 10 | 找规律，多练就熟了 |
| 定义判断 | 10 | 最稳，逐项对照即可 |
| 类比推理 | 10 | 速度快，1分钟3题 |
| 逻辑判断 | 10 | 最难，需要推理框架 |

---

## 一、图形推理

### 常见规律类型

| 规律 | 特征 | 示例思路 |
|------|------|---------|
| 位置类 | 图形平移、旋转、翻转 | 看元素移动方向 |
| 样式类 | 叠加、求同、求异 | 看图形间运算 |
| 数量类 | 点、线、面、角、笔画数 | 数完之后找规律 |
| 属性类 | 对称、曲直、封闭开放 | 看整体特征 |
| 空间类 | 折纸盒、三视图 | 空间想象力；四面体用箭头法/移面法 |

### 解题步骤

```
1. 判断图形组成 → 元素相同？（位置类）
                 → 元素相似？（样式类）
                 → 元素不同？（先数数量，再看属性）
2. 数量类数什么？→ 先数面 → 再数线 → 再数点 → 再数笔画
```

### 空间类：四面体折叠（箭头法 / 双箭头法 / 移面法）

**先立地基**：正四面体有 **4 个面、6 条棱、4 个顶点**，且**没有相对面**——任意两面都相邻。所以六面体最常用的"相对面排除法"在四面体处**失效**，只能靠**相邻面关系**判断。每面都是正三角形、任意两面共棱，**任何一面都能转到想看的方位**，这正是箭头法和移面法成立的根本。

四面体展开图只有 **2 种**：**正三角形外框**（一面居中、三面环绕）和**平行四边形外框**（两行两列排布）。

> **两条通用规则（移面法依据）**
> - **规则 A（180° 平角可旋转）**：同一直线上夹 180° 的两条边，折叠后是相邻面的公共边，面可绕它旋转 180° 挪到相邻处。
> - **规则 B（平行边可平移）**：平行四边形左右两条平行边折叠后重合，面可平移到另一边。

#### ① 箭头法（定方向 + 邻位）

**原理**：在带方向性的特殊面上画一个单向箭头，考查箭头**上、下、左、右**四个方位对应的相邻面是否与展开图一致。**折叠不会让箭头镜像翻转**，只会整体旋转。

**步骤**：
1. **选参照面**：挑图案有明显指向的面（带尖角 / 带一条明显线）。
2. **画单箭头**：展开图与选项上，用**完全相同起点、路径**画箭头（箭头=上，箭尾=下，箭头左侧=左，右侧=右）。
3. **固定画法**：同一面的箭头画法必须一致，不能换着画。
4. **对比方位**：箭头四方位对应相邻面与题干不一致，就排除。

> **速记口诀**：箭头指上、两侧为左右、箭尾为下。选指向性最强的面来画最省事。⚠️ 若四面体全是空白三角，箭头法使不上，换双箭头法 / 移面法 / 公共棱法。

---

#### ② 双箭头法（面内方向 + 相邻左右一起判）

当单箭头分不清相邻面的**左右位置**时，画两支箭头：

| 箭头 | 画法 | 作用 |
|------|------|------|
| 第一支 | 从参照面起点指向面的**特征顶点**（尖角 / 图案端点） | 定**面内图案方向** |
| 第二支 | 从**两相邻面的公共边中点**出发，指向第二面的特征顶点 | 判**相邻面左右位置** |

**判定**：第一支定"脸朝哪"，第二支定"邻面在左手边还是右手边"。选项中箭头左右侧特征与题干对不上 → 排除。

---

#### ③ 移面法（把不相邻面搬近）

**为什么需要它**：目标面在平面上**离得很远**，不好想象折叠后挨不挨着。移面法把不相邻面**搬到相邻位置**再看——**不动折叠结果，只变平面摆法**。

**两种操作**：
- **旋转移面（规则 A）**：把目标面绕它与邻面的公共边**旋转 180°** 拼到相邻处；互相垂直的两边之间的面可旋转 **90°**。
- **平移移面（规则 B）**：把目标面**平移到**相邻位置，常用于平行四边形展开图左右平行边，或同一行 / 列连续面的两端。

**移面后配合**：移面只解决"谁和谁相邻"，救不了方向和左右。所以移完面**还要接箭头法或双箭头法判方向**。**移面 + 箭头几乎成对出现。**

> 一句话：「移面法负责把面挪近，箭头法负责判断方向。」

---

**完整流程（按顺序走）**

```
1. 先找特殊面（唯一图案 / 黑块 / 明显棱线）→ 没有就用公共棱法
2. 套箭头法 / 双箭头法定方向 + 邻位
3. 两地面太远想象不出来？→ 移面法搬近
4. 移完再回箭头法 / 双箭头法判断
5. 用公共棱法 / 时针法收尾，排除选出
```

**核心心法**：先特殊面 → 后箭头验证 → 卡不牢就移面 → 再箭头 → 公共棱法收尾，循环到只剩一个。

**辅助方法**

| 方法 | 一句话用法 | 适用 |
|------|-----------|------|
| 公共棱法 | 看两相邻面公共棱中点引出的是虚线/实线、线在哪，须与题干一致 | 最简，万能兜底 |
| 时针法 | 绕一个顶点三个面按方向环视，折叠后顺序不变 | 方向易乱 |
| 标点描棱法 | 标公共顶点，看每顶点引出线条数/图案是否对应 | 复杂图案 |
| 特殊面优先 | 从唯一图案（单点、特殊线、黑块）入手 | 所有题优先 |

## 二、定义判断

### 🎯 核心心法

> 定义判断是 **「信息匹配游戏」** 。**题眼** = 定义里那几个「掐住生死」的关键要件词。
> 找到题眼，选项是杀；找不到，四个选项长得都一样。
>
> 它考的不是"读不读得懂"，而是 **你和命题人抓的是不是同一批关键词**。定义可以读不懂，题眼必须抓得准。
> **题干定义是唯一标准**，不要用生活常识代替定义！

---

### 一、题眼藏在哪：六要素拆解图

任何定义，读一遍就把下面六个位置全部圈出来（找不到就跳过，**不一定都有**）：

| 要件 | 是什么 | 常见触发词 | 优先级 |
|------|--------|-----------|--------|
| **主体** | 谁在做 | 政府/个人/组织/企业 | ⭐ 排第一 |
| **客体** | 对谁做 | 针对/对/向 | ⭐ 排第一 |
| **方式/条件** | 怎么做、什么前提 | 通过/利用/采用/以……方式/当……时/在……情况下 | ⭐⭐ 重灾区 |
| **原因** | 为什么做 | 为了/由于/基于/因为 | ⭐⭐ |
| **目的** | 想得到什么 | 为了/以期/以达到/意图 | ⭐⭐ |
| **结果** | 最后造成啥 | 导致/使得/形成/进而/引发 | ⭐ |

**看优先级的口诀**：`主客体不对必排除 → 方式条件对不上再排 → 最后看目的结果 → 择优取符合最多的`。

> 🚩 记住：**范围越小、越明确的词，越容易成为考点**。看到"自然界""行政机关""家庭成员""两个以上"这种带限定的词，就是命题人埋的题眼。

---

### 二、三类「要命」的高频题眼（最易踩的坑）

这三类词一出，必是选项差异所在，一个字都不能漏。

| 类型 | 例子 | 坑在哪 |
|------|------|--------|
| **状语类** | 在……之前/期间/同时；在……范围内/境内；当……时/如果 | 选项违反时空/条件限制，直接杀 |
| **否定/排除词** | 不是/并非/不得/禁止；除了/不包括/以外 | 命题人特意排除的情况，选项一碰就淘汰 |
| **列举词** | 例如/包括/如/等 | ⚠️ "等"=未穷尽，选项不在例子里**不代表**不符合，别乱杀 |

---

### 三、做题标准四步法

1. **看问法**：先分清是「属于/符合」还是「不属于/不符合」，选非题最易翻车。
2. **拆要件**：按六要素把定义切片、圈出题眼，**一次读完不回头重扫**。
3. **三排**：主客体 → 方式条件 → 目的结果，逐一核对，缺一项就淘汰。
4. **择优**：没有一个选项全符合时，选**符合关键词最多**的那个，接受"不完美但最像"。

---

### 四、选项怎么骗你：常见干扰项一览

| 陷阱类型 | 特征 | 识别 |
|---------|------|------|
| **主体冒充** | 拿物业/商业银行/非政府机构冒充"行政主体" | 核对主体 |
| **客体错位** | 老板打员工冒充"虐待罪"（客体应为家庭成员） | 核对客体 |
| **方式目的不符** | 无"故意"冒充碰瓷、无"融入"行为冒充隐性广告 | 核对状语 |
| **单方冒充合作** | 一家企业自己搞联名，无另一方参与 | 核对是否多方 |
| **同行业伪装跨行业** | 两家餐饮互推冒充当"跨行业合作" | 核对行业是否不同 |

---

### 五、4 个提速小技巧

1. **拆词法**：定义名字拆成字面意思预判关键词 —— "诉前财产保全"→起诉前+钱+保护，诉讼过程中就出局。
2. **排同构**：两个选项意思相似、结构相似 → 都不选。
3. **先看选项**：定义晦涩难懂时，先扫选项（选项是对定义的诠释），常能反推。
4. **常识/感情倾向**：正能量选项果断留；但**以题干定义为准，不怀疑定义、不用常识去反驳**。

---

### 六、一页口诀

> **先看问法，圈六件；**
> **主体第一状语严；**
> **否定词是雷区点；**
> **择优取最符合。**

---

### 例题（感受题眼）

> 定义：**地方性法规**，由地方立法机关依法制定，在本地域内具有法律效力的规范性文件。
> - A. 村委会 · 县政府办公室 · 市政府 → **主体不是立法机关**，全排
> - D. 市人大常委会 → 主体（立法机关）✓ 地域（本地）✓ → **选它**

## 三、类比推理

### 常见关系类型

| 关系 | 示例 |
|------|------|
| 种属关系 | 苹果 : 水果（苹果是水果的一种） |
| 组成关系 | 轮胎 : 汽车（轮胎是汽车的组成部分） |
| 功能关系 | 笔 : 书写 |
| 因果关系 | 下雨 : 地湿 |
| 近义/反义 | 美丽 : 漂亮 / 前进 : 后退 |
| 顺序关系 | 申请 : 审批 : 执行 |

### 解题技巧

```
先造句子 → "A 是 B 的一种" → 看选项谁最像
         → "A 用来做 B"    → 横向/纵向对比
```

## 四、逻辑判断

### 翻译推理（形式逻辑）

| 逻辑关系 | 翻译 | 逆否等价 |
|---------|------|---------|
| 如果 A 那么 B | A → B | ¬B → ¬A |
| 只有 A 才 B | B → A | ¬A → ¬B |
| A 且 B | A ∧ B | 否定为 ¬A ∨ ¬B |
| A 或 B | A ∨ B | 否定为 ¬A ∧ ¬B |

::: warning ⚠️ 常考点
- "如果就" = 前推后（充分条件）
- "只有才" = 后推前（必要条件）
- 逆否命题一定等价于原命题
- 否命题和逆命题都不等价！
:::

### 加强/削弱题

**加强**（让结论更可信）：
- 补充正面证据
- 排除他因
- 搭桥（建立前提和结论的联系）

**削弱**（让结论不可信）：
- 因果倒置
- 他因削弱
- 切断联系
- 否定前提

### 结论型

逐个选项对照题干信息，排除无中生有的选项。

# 项目：公务员备考知识库

## What

基于 VitePress 的个人知识库网站，系统化管理公务员考试备考笔记。

- 本地：`C:\Users\Administrator\Projects\gongkao-notes`
- 线上：`https://Ai-hang1226.github.io/xuexi-notes/`
- GitHub：`Ai-hang1226/xuexi-notes`
- 技术：VitePress 1.6.4 + GitHub Pages

## Why

用户是备考公务员考试的知识博主，没有编程基础。需要在学习过程中系统化记录笔记，最终形成可分享的知识体系。

## 内容结构

行测（言语理解、数量关系、判断推理、资料分析、常识判断）→ 申论（概括归纳、综合分析、对策建议、公文写作、大作文）→ 面试（结构化、无领导小组）→ 错题本 → 学习日志 → 分享区

## 当前状态

网站已上线，内容持续填充中。最近添加了每日速记功能（每日速记.md）。

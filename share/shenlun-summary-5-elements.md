# 申论归纳概括：问什么，就归纳什么

> 一句话结论：DAY5—DAY9 看起来是五道不同的题，其实都属**归纳概括**这一种题型。变的不是做法，是题目要求你概括的**作答要素**。先看清问的是哪一个要素，再回材料找点。

## 五道题，五种要素

| 作答要素 | 对应练习 | 最容易错在哪 |
|---|---|---|
| 做法 | [DAY5 · 城市绿化](/shenlun/day5-city-greening) | 只按段落抄一遍，总括句覆盖不住下面的行动 |
| 措施＋成效 | [DAY6 · 营商环境](/shenlun/day6-business-environment) | 行动和结果配错组；"谁到哪里做什么"写不准 |
| 特点与作用 | [DAY7 · 背包银行](/shenlun/day7-backpack-bank) | 把做法当成特点；特点提炼与作用结果混在一栏 |
| 问题与不足 | [DAY8 · 创新公共服务](/shenlun/day8-public-services) | 停在设施现象，没归纳出调研、数据与资源问题 |
| 原因 | [DAY9 · 加数前行](/shenlun/day9-digital-city) | 只列平台清单，漏掉组织线索与场景建设 |

讲义里还列了理念、变化、过程等要素。**要素不同，找点的方向就不同**，但底层动作始终是同一套。

## 同一套动作

**审题干 → 逐段找点 → 同类归并 → 总括句＋必要细节 → 回查材料。**

三条边界：

- 总括句要能**覆盖**下面所有条目，不能用"多方面"这类空话代替具体差异。
- 按主体、领域、时间或流程分组，材料本身没有对应关系时不要硬套。
- 压缩时优先删重复，保留题目需要的区分；具体信息不能只剩形容词。

# 对策建议

对策建议题要求你针对材料中的问题，提出具体可行的解决方案。

## 🔧 解题流程

```
找问题 → 分析原因 → 提对策 → 验证可行性
```

## 📝 答题框架

```
针对[问题]，提出以下建议：

1. [总括句]。具体而言，...
2. [总括句]。具体而言，...
3. [总括句]。具体而言，...
```

---

## 🧭 对策提出来自哪里？

### 1. 材料中直接给出（最优先）
材料里有关键词："要...""应...""必须...""建议..."
→ 直接提炼

### 2. 从问题反推
材料说"缺乏监管" → 对策："加强监管"
材料说"意识不强" → 对策："加强宣传教育"

### 3. 从原因反推
材料说"因为资金不足导致..." → 对策："增加财政投入"

### 4. 从经验借鉴
材料介绍了其他地方的好做法 → 对策："借鉴...经验"

---

## 🎯 对策的"五维"框架

| 维度 | 常见对策 |
|------|---------|
| **思想层面** | 加强宣传教育、提高认识、转变观念 |
| **制度层面** | 完善法律法规、健全制度机制、出台政策 |
| **执行层面** | 加强监督检查、加大执法力度、落实责任 |
| **技术层面** | 技术创新、数字化建设、人才培养 |
| **资金层面** | 加大财政投入、引导社会资本、优化资源配置 |

---

## ⚠️ 对策三要素

一个好的对策必须满足：

| 要素 | 要求 | 反例 |
|------|------|------|
| **针对性** | 对准问题 | 问题是"基层人手不够"，对策却是"加强顶层设计" ❌ |
| **可行性** | 能落地执行 | "三个月建成智慧城市" ❌ |
| **具体性** | 有具体做法 | "加强管理"太笼统 ✅ "建立定期巡查制度" |

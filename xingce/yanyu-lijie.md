## 一、逻辑填空

**本人方法积累**：[逻辑填空先找语境依据再比词](逻辑填空先找语境依据再比词.md)——读语境、找线索、比差别、回代整组；线索也可能来自整句或全文。

> 📖 大宝小宝 **第三部分 · 逻辑填空（7 章）**：四大契合／三大注重／三大内部关系／三大谬误／三大一致／特殊技巧／语句填入。

### 解题路线

> 核心没变：**先定大方向，再抠准确度**。但大宝小宝把"大方向"拆得比"文段找对应"更细——详见下表。

| 步骤 | 干什么 | 大宝小宝对应章 |
|---|---|---|
| ① 定方向 | 横线前后是什么关系？该填什么方向的词？ | **三章 三大内部关系**（递进／同义并列／反义）＋**一章 四大契合**（解释说明／具体展开／主谓宾性质／比喻） |
| ② 抠准确 | 在这个方向下，哪个词最准确？ | **二章 三大注重**（主谓宾／程度轻重／情感色彩）＋**六章 特殊技巧** |
| ③ 排干扰 | 这个词有没有硬伤？ | **四章 三大谬误**（局部谬误／搭配不当／分割谬误）＋**五章 三大一致**（因果一致／成分一致／句式一致） |

> 🚩 **一句话**：大方向意思正确再做细致对比 → 优中选优。
> 🚩 **题16 的教训**：别从第一空硬抠——**先从手上最强的那个空锁定答案**，再回头验证别的空（【六章·五 锁定目标，要什么找什么】）。

### 文段找对应（按逻辑关系触发 · 标志词速查）

| 逻辑关系 | 标志词 | 该填什么 | 大宝小宝节点 |
|---|---|---|---|
| 转折 | 但是、然而、却 | 前后语义相反 | 三章·三 前后文反义 |
| 递进 | 更、甚至 | 语义相近，程度前轻后重 | 三章·一 前后文递进 |
| 并列·近义 | 逗号、顿号 | 前后语义相近 | 三章·二 顿号的同义并列 |
| 并列·反义 | 不是…而是… | 前后语义相反 | 三章·三 前后文反义 |
| 并列·多并列 | 三个及以上词语 | 语义不同ABC / 相近A1A2A3 / 递进AA+A++ | 三章·二 补充：多者并列 |
| 因果/解释 | 因为…所以、由于、导致、即、可谓、—— | 前后语句对横线处做词义解释 | 一章·一 契合解释说明；五章·一 因果一致 |
| 形象化 | 文段比喻、双引号 | 优选形象化表达 | 一章·四 契合比喻 |

> 🚩 **逻辑中心化**：宏观角度理解文段整体意思，别只看单句。

### 选项作辨析

- **成语**：考察词义更多
- **实词**：考察搭配更多（固定搭配 / 主语人事物 / 一搭多 / 重复出现 A 的 A）→【六章·一 敏感于固定搭配】＋【二章·一 注重抓准谁是主谓宾】
- **感情色彩**：褒义 / 中性 / 贬义，跟文段一致 →【二章·三 注重情感色彩】
- **程度轻重**：文段出现温和词语→选程度轻的；出现绝对词语→选程度重的 →【二章·二 注重程度轻重】

### 实用技巧（易错点）

- **直接对应**：直接呼应最优，不要往前推（eg 大米稀缺 → 选"少"，不选"贵"）→【六章·四 看透出题人的小心思】
- **结构法**：结构一致，内容一一对应 →【五章·三 句式一致】
- **择优思维**：选项都对时，选更全面、更精准的
- **生僻词**：先分析常见词确定答案；字面意思猜义（望文生义）
- 🚩 **首句很关键**：逻辑填空的**第一句**往往是全段语境的定调句 →【六章·六 注重逻辑填空首句（重点）】

### 逻辑填空拓展：法治表述词语搭配

<strong>题干：</strong>依法治国和依法行政的____，需要各级政府及其工作人员在法治____上行使权力，在宪法法律范围内活动。

<strong>答案：</strong>A．实现／轨道。

| 关键词 | 最佳搭配 | 易错辨析 |
|------|----------|----------|
| 实现 | 实现依法治国、依法行政 | “实施”多接具体法律、政策、方案；“履行”多接职责、义务、承诺。 |
| 轨道 | 在法治轨道上行使权力 | 突出权力按法律规则、程序和边界运行。 |
| 框架 | 在法治框架内行使权力 | 应搭配“内”，不能说“在法治框架上”。 |
| 基础 | 在法治基础上推进治理 | 突出支撑、前提，不突出对权力运行的约束。 |
| 道路 | 走中国特色社会主义法治道路 | 突出发展方向，常搭配“走、坚持、沿着”。 |

> 速记：**基础管支撑，道路管方向，轨道管运行与约束。**

**高频语块：**

- 权力在法治轨道上行使；工作在法治轨道上推进；社会生活在法治轨道上运行。
- 在法治框架内开展活动；在宪法法律范围内活动；以法律为依据。
- 法无授权不可为，法定职责必须为；让权力在阳光下运行。

### 高频易混词辨析

|------|------|---------|

## 二、阅读理解

> 📖 大宝小宝 **第一部分 · 中心理解（5 章）**：基础知识铺垫／以人为本／脉络剖析／四大文段／重点内容补充。
> 下面这张"结构表"是**速查版**，和上一版的六种结构**不是冲突关系**——大宝小宝把它们**拆得更细、并给了新名字**，对应关系见最右列。

### 主旨概括 / 意图推断（中心理解） {#主旨概括题-中心理解}

**核心方法**：先识别文段**脉络** → 找出**观点句/落点** → 匹配选项。
（大宝小宝的原话是「**以人为本**」——先找**作者的观点**在哪、用什么方式提出来的。）

> 💡 **判断"总"还是"分"，核心是判断"为谁服务"**：分句（背景/解释/举例）都是为总句（观点/对策/总结）服务的。

#### 按结构触发（先问"这段是什么脉络？"）

| 结构 | 标志词 | 中心在哪 | 大宝小宝对应节点 |
|---|---|---|---|
| **转折** | 但是、可是、不过、然而、事实上、其实、殊不知、不同的是 | **转折后是重点** | **三章·三 转折的剖析·强转折五类**（好但问／问但好／观但问／问但观／前后表达相反）。反驳型三招见下 |
| **递进** | 更、甚至、特别是、不仅…而且 | **递进后是重点** | **三章·二·2 多层次展开**（重点精讲的展开）＋**三章·一 偏正大杀器** |
| **因果** | 因为…所以、因此、从而、可见、使得、"这"、换句话说、**正是…使得…** | **结果是重点** | **四章·一 原因类文段·四大设计**：1）**因果阐明（最佳答案）** ＞ 2）果的因 ＞ 3）因果并列 ＞ 4）果因单论。**"正是……使得……"是因果强调句**（题13）：落点在"使得"**后面**的结果，做题时先翻成大白话（谁让谁怎么样了），**选项方向一律不能反** |
| **对策** | 要、应该、必须、建议、只有…才、前提、基础、重要的是 | **原文对策为核心** | **二章·三 观点提出的六大方式·其三 三大提对策给观点**（开门见山／做法+危害意义／否定型）；**四章·二 纯问题类文段**（问题文段对策可行选对策、不可行选问题）；**四章·三·3 对策的合理性**。**一个"需要"后跟一串并列做法→选能罩住全部的"上位总对策"**（题9） |
| **总分** | 总句（观点/对策/总结），分句（背景/解释/举例） | **总句** | **三章·二·1 单层次展开两式**（1）总分式：前宏观引入后具体阐述**圈圈法**；2）定义式）＋ **三章·二·2 多层次展开四大设计（Cab并列系列）**：**设计一·有文段总括→直接选总括（标准格式）**／设计二·a＋b／设计三·提取共性／设计四·自行总括 |
| **并列** | 分号、也/又/同时/此外、一方面…另一方面、句式一致、时间并列、无论证关系 | **全面概括 / 宏观概括 / 提取共性** | **三章·二·2 设计二～设计四**＋**三章·四 地位的感知**（两者地位相当，反复联系） |
| **对比** | 过去 vs 现在、A 与 B 相比 | 提取共性 或 突出其一 | **三章·五 对比的剖析**（古今时间对比两式／多点时间并列顺承／古今时间并列／新旧事物对比／差异主体对比） |

> 🚩 **反问不等于没有表态**（题15）：把"难道／何尝／是否……呢"放回上下文，若前文已经在批评或质疑，就要还原成带否定倾向的陈述。但注意程度对应：反问通常可还原为"未必／不等于"，不必一律强化成"完全没有"。→【**三章·三·1 强转折五类·1）好但问**】

**变体说法**（大宝小宝里都有正式位置，不再叫"变体"）：

| 说法 | 大宝小宝归到哪 | 为什么 |
|---|---|---|
| 假设/让步（如果…就、即使…也） | 二章·四·6 观点偏向性·2）偏向问题 / 三章·一 偏正 | 让步往往"退一步强调更要紧的"，落点仍在重心那一侧 |
| 条件（只有…才、前提、基础） | 二章·三·其一 **必要性提出观点** | 必要条件 = 观点的**必要性**，**不是**对策（题4的坑） |
| 分总 / 总-分-总 | 三章·二·1 总分式／设计一 | 总分的倒装，中心还是那个**总句/总括**，只是位置不同 |
| 问题-对策 | 四章·二 纯问题类文段 | 先摆问题再给对策，中心 = **对策**（且要**针对症结**） |

**识别口诀**：先问"这段的**脉络**是什么"；判断标准就一个——**作者这段话最终的"落点/重心"落在哪**。遇到假设、条件、对比、分总、问题对策，别慌，去上表右列找位置。

#### 观点是怎么提出来的（大宝小宝【二章·三 六大方式】）

做题时反过来用：**先认出"作者在用哪种方式给观点"，答案就往那个观点上落。**

| 方式 | 特征 |
|---|---|
| 其一 必要性提出观点 | 只有…才／前提／基础 —— **给的是必要条件，别当选对策** |
| 其二 设问提出观点 | 自问自答，答案在回答里 |
| 其三 三大提对策给观点 | 开门见山／做法+危害意义／否定型 —— **对策题的主战场** |
| 其四 利用他者经验态度 | "XX 认为"——**自身观点大于他者观点** |
| 其五 重要性提观点 | 有助于／有利于 —— **注意"跳板思维"：重要性常是跳板，不是落点** |
| 其六 本身观点性 | 直接下判断 |

#### 观点的深刻剖析（大宝小宝【二章·四】· 选答案时的对照表）

- **1 优先性** / **2 对比性** / **3 统一性** / **4 具体性两式**（经典传递搭桥／隐藏传递搭桥）/ **5 转换性**
- **6 偏向性四式**：①偏向具体展开 ②偏向问题 ③**偏向论证**（题7：选了论据＝话题＜论点，必错）④偏向统一
- **7 主语及宏观限定的秒杀**：**两个选项主语相同 → 别比主语，比谓语**（题12、题14）

#### 实用技巧（你的易错点）

- 🚩 **话题限定**：正确答案要体现核心话题；出题人爱做同义替换，**专业名词一般不替换**。
- 🚩 **两个选项主语相同时，别比主语，比谓语**（题12）。同主语＝中心词两边都拿对了，胜负全在**谓语（落点）**：把谓语拆成几块，逐块回原文找，**有成分在原文找不到出处的优先排除**（选项里只要混进一个无中生有的成分，就是白送的排除点）。例：B"个性化专业设置**是增强吸引力竞争力的有效途径**"＝尾句原话；C"是高校之间**生源竞争普遍采用**的方式"——"生源竞争"是②句背景、落点是上游，"普遍采用"原文根本没有。另：**"最集中的／最关键的"这类强表述出现在背景句里，也只是引子，不代表它是落点。** →【二章·四·7 主语及宏观限定的秒杀】＋【一章·二·1 顺承后的内容重要】
- 🚩 **关键词提取题：不许数词频**（题11）。顺序是 ①哪几个词能**罩住每一句** → ②**落点在哪**（找"究其实质／说到底／更是一种"这类总结＋递进的标志）→ ③只在某一句出现、后文没再展开的词（背景、举例、某个作用）是**边角料**，不能当关键词。→【二部分·四章 关键词提取】⚠️ 正文标注该节是「推断、把握低」，听课时核对。
- 🚩 **偏正大杀器**：一句话里"偏"的部分（修饰、引子）是为"正"的部分（重心）服务的——**别停在引子句上**（题14）。→【三章·一】
- 🚩 **别被举例带偏**：认出"这是例子"只是第一步，**必须再追问"例子在证明什么"**。→【五章·一·2 例子的论证作用】（题8）
- 🚩 **结合选项定中心**：文段脉络不明确时，用选项反推。
- 🚩 **假设代入反推**：假设某选项对，反推文段该怎么写，再核对。
- 🚩 **同构选项排除**：两个选项表达内容一致 → 一起排除。
- 🚩 **别追求"最全面"**：中心句 = 总句的直接转述即可，不是越全面越好。全面但夸大的（绝对化）往往是干扰项。→【二部分·三章·二·6 绝对化】
- 🚩 **笼统不等于保险，具体也不自动正确**（题15）：先保文意和语气，再比谁更贴最终落点。“有弊端／有影响／有问题”若没说清文段具体在质疑什么，通常竞争力弱；但具体项若把“未必”强化成“完全没有”，也不能机械优先。争议题按当前平台口径作答，不提炼成死规则。

### 标题选择题（贴合全文重心） {#title-selection}

> ⚠️ **大宝小宝 16 章里没有标题填入专章**——他把它吸收进了中心理解。所以这一节**以站内方法为准**，用宝哥哥的节点做**辅助判据**。

1. **先概括共同指向**：结合各句关系，判断作者在强调什么。首句出现观点，不代表它一定能统摄后文；举例要追问“具体在证明什么”。→【五章·一·2 例子的论证作用】
2. **再对比选项重点**：与某一句对得上，只能说明有依据；还要看选项是否抓住全文重心，是否额外加入文段没有强调的意思。→【四章·四 概括类文段】
3. **最后核对表达程度**：既不因标题听起来宏大就选，也不见“无限”等词就机械排除。结合语境辨别概括性修辞与无依据的事实断言，标题也不能随意夸张。→【二部分·三章·二·6 绝对化】

**本次易错**：把“创新持续释放价值”收窄成首句里的“助力高质量发展”，忽略后文抗疫与生产生活方式的改变；“又好又快”还带入了全文未着重讨论的速度维度。

**复习提醒**：先问例子在证明什么，再选能概括全文重心的标题；不能只与首句对得上。


### 意图推断题（作者"意在强调/想表达"）

> 中心理解题的进阶：**不但要找中心句，还要问"作者真正要强调的是哪层？"**

- 紧接中心句，但要对"哪个才是作者真正落点"做判断。
- 警惕：**把"必要条件/前提"当成"作者的结论"**（如"只有…才"是条件，不是对策）→【二章·三·其一 必要性提出观点】
- 警惕：**把"论据"当成"论点"**（支撑句不是作者最想强调的）→【二章·四·6·3）偏向论证】
- 陷阱：**"在于/关键"题** → 一定要找文段点明的**症结/针对性对策**，不是复述理想条件。→【四章·二 纯问题类文段】
- 陷阱：**"对策优先"用过头**（题9）→ 认出"为此/需要"是对的，但要再问一句：**这个"需要"后面是一个对策，还是一串并列做法？** 一串并列做法时，正确答案是**上位总对策**（能罩住全部），不是排在第一条的那个分做法。→【二章·三·其三】＋【三章·二·2·设计一】

### 细节判断题

> 📖 大宝小宝 **二部分·三章 细节判断**：一、正确答案特征 ｜ 二、常见错误（8 类）｜ 三、特殊题型。

**逐项对照原文**，注意易错的几种改写：
- 无中生有、偷换概念、偷换时态、偷换逻辑、偷换范围、绝对化、强加对比、语义相悖
- **选非题**：绝对化的表达作为答案的概率更高；**选是题**：温和的表达概率更高
- **做题顺序**：选项短→先看选项画关键词→回文段对比；文段短→先读文段再做选项
- **"根本原因/本质上"这类题** → 先理解文段整体在说什么，再回原文找**同级提示词**，不比谁听起来更大 →【三·3 细节中心化】（题18）

### 推断题

基于原文合理推断，不选原文直接复述的选项

## 三、语句表达

### 接语选择题（接下来最可能讲的是？）

> 🚩 核心：**话题一致性 + 行文逻辑合理**。别被尾句某个词带走。
> 📖 大宝小宝 **二部分·二章 下文推断**。

**分类与易错点：**
- **常规接语**：①尾句提出**新话题**→后文围绕新话题展开（前提：那个词真的是"新话题"）；②结构=提出问题+分析问题+**提出对策**；③文段宏观话题→下文具体展开。
- **看结构接**：总分→先接总再接分；并列→分1分2分3分1，接分2；尾句提示转折→按转折接。
- **下文选非**：与文段矛盾 / 话题不一致 / 前文已论述过。→【五、最不可能讲述】
- **你的易错**：把尾句的**比喻词**当成新话题。真正的判断标准是"**这个词是不是成了文段新的论述对象**"，不是"它在不在尾句"。→【一、尾句引出新主体】＋【二·3 问题结尾】（题3）

### 语句填空题

> 📖 大宝小宝 **三部分·七章 语句填入**：一、横线在开头 ｜ 二、横线在中间 ｜ 三、横线在结尾 ｜ 四、逻辑填空同源。

**核心**：话题一致 + 逻辑合理。按横线位置触发：

| 位置 | 作用 |
|---|---|
| 段首 | 总结全文 / 总结下一句(冒号引出表解释) / 引出下文(中心文段) / 话题引入(通过排除法选) |
| 段中 | 承上启下；前后一致→保持相同；前后不同→搭桥。**先判"这句话需要什么层级的概括"，别拿全文主旨去填**（题17） |
| 段尾 | 总结全文 / 提出对策 / **总结前一句话**（承上——接紧邻前一句的落点，**不要退回段首的总起句**） |

**段尾填空：先过一遍这两条**：

1. **横线紧挨着谁，就接谁的落点**。段尾填空的“上句”是**紧邻的那一句**，不是段首的总起句。
2. **看逻辑链条的上下游（主判据）**。把全段排成一条链，横线处的内容**必须比前一句更靠“下游”**，往回流的一律排除。
   - 题10 的链条：`构建法治理论 → 深化立法理论研究 → 促进从“法”到“良法”` → **【横线】**
   - A“提升立法质量和法治水平”在最下游 ✅（“良法”＝立法质量，A 是它的兑现，还顺带兜住了第一句的“法治理论”）
   - B“提升基本理论研究水平” ≈ 和“深化研究”是**同一环**（同义反复）；C“提高法治理论水平”、D“构建经济法理论”都退回了**链条最左端** ❌
   - ⚠️ **判据是“上下游”，不是“做法/结果”**：四个选项**语法形式全是“动词+宾语”**，光看形式分不出来。**连接词也只是辅助信号**——A 的“从而”（结果）＋下游内容双对；**D 的“进而”（递进）连接词看着也对，但内容是上游的“构建理论”——连接词对、内容错，是最坑的一项**。

### 语句排序题

> 📖 大宝小宝 **二部分·一章 语句排序**：一、22 布局（确定首句／内容衔接）｜ 二、43 布局 ｜ 三、定义与特征的两大定理。

**从选项入手，边做边排除，不建议自己排序。** 四步：首句、捆绑、顺序、尾句。

1. **首句对比**：能当首句=下定义、背景引入；不能当首句=指代不明、关键词后半部分、举例子
2. **确定捆绑**：指代词 / 关联词 / 话题一致
3. **确定顺序**：问题+分析+对策 / 观点+解释说明 / A+B / 全称+简称 / 时间顺序（话题一致）/ 日常做事逻辑
4. **尾句对比**：总结全文 / 提出对策

> 🚩 **大宝小宝的两大定理**（本站旧版四步没覆盖的部分）：
> - **完全相同主体 → 先定义（引入）后特征**
> - **某一主体可拆分为多个部分 → 先部分定义，再整体定义**
> - **除此以外任何，都无绝对关系**（别硬排）

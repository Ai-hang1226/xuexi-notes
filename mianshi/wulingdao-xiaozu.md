# 无领导小组讨论

少数岗位采用，8-10 人一组，围绕给定问题讨论，考官全程观察评分。

## 🔄 流程

```
材料阅读（5-10分钟）→ 个人陈述（每人2-3分钟）→ 自由讨论（20-30分钟）→ 总结汇报（3-5分钟）
```

## 🎭 常见角色

| 角色 | 职责 | 适合谁 |
|------|------|--------|
| 领导者 | 推动讨论节奏，明确讨论框架 | 逻辑清晰、敢于主导 |
| 时间控制者 | 把控各阶段时间，提醒跑题 | 细心、愿意服务 |
| 记录者 | 记录各人观点，总结形成共识 | 善于抓重点、写字快 |
| 观点贡献者 | 提出有质量的看法和建议 | 思维活跃 |
| 总结汇报者 | 向考官汇报讨论结果 | 表达清晰、逻辑强 |

> 💡 不用强求某个角色，自然发挥。讨论有贡献比角色重要！

---

## 🎯 评分维度

| 维度 | 考官看什么 |
|------|-----------|
| 参与度 | 是否积极发言？但不说废话 |
| 逻辑性 | 发言是否有条理？ |
| 协作性 | 是否尊重他人？是否推动共识？ |
| 影响力 | 观点是否被小组采纳？ |
| 表达力 | 清晰度、流畅度 |

---

## ⚠️ 注意事项

### ✅ 加分行为
- 第一个发言，提出讨论框架
- 在争论时能调和矛盾
- 能把跑题拉回来
- 主动邀请没发言的组员说话
- 总结共识、推动进度

### ❌ 扣分行为
- 一言不发（一定被淘汰）
- 强行打断别人
- 固执己见，无法妥协
- 人身攻击
- 话太多但无实质内容

---

## 📐 常见讨论题型

| 类型 | 示例 | 思路 |
|------|------|------|
| 排序题 | 从 10 项措施中选出最重要的 3 项 | 定标准 → 逐项评估 → 投票 |
| 方案题 | 设计一个工作方案 | 明确目标 → 列出步骤 → 分工 |
| 辩论题 | 城市管理应以疏为主还是以堵为主 | 先各自陈述 → 找共识点 → 综合 |
| 两难题 | 资源有限，项目 A 和 B 选哪个 | 设评价标准 → 量化对比 → 决策 |

# 言语理解与表达

## 概述

言语理解与表达是行测中题量最大的模块，考察对语言文字的理解和运用能力。

## 📊 题型分布（国考）

| 题型 | 题量 | 建议用时 |
|------|------|---------|
| 逻辑填空 | 15-20 | 12-15 分钟 |
| 阅读理解 | 15-20 | 12-15 分钟 |
| 语句表达 | 5-8 | 5-8 分钟 |

## 一、逻辑填空（选词填空）

### 解题步骤（大懒猫·两步走）

> 核心：**文段找对应 → 选项做辨析**，先定大方向，再抠准确度。

1. **文段找对应**：横线前后是什么逻辑关系？该填"大方向"是什么词？
2. **选项做辨析**：在这个方向下，哪个词最准确？（日常积累 + 择优思维）
3. 本质：**大方向意思正确再做细致对比 → 优中选优**

### 文段找对应（按逻辑关系触发）

| 逻辑关系 | 标志词 | 该填什么 |
|---|---|---|
| 转折 | 但是、然而、却 | 前后语义相反（不矛盾） |
| 递进 | 更、甚至 | 语义相近，程度前轻后重 |
| 并列·近义 | 逗号、顿号 | 前后语义相近 |
| 并列·反义 | 不是…而是… | 前后语义相反 |
| 并列·多并列 | 三个及以上词语 | 语义不同ABC / 相近A1A2A3 / 递进AA+A++ |
| 因果/解释 | 因为…所以、由于、导致、即、可谓、**、—— | 前后语句对横线处做词义解释 |
| 形象化 | 文段比喻、双引号 | 优选形象化表达 |

> 🚩 **逻辑中心化**：宏观角度理解文段整体意思，别只看单句。

### 选项作辨析

- **成语**：考察词义更多
- **实词**：考察搭配更多（固定搭配 / 主语人事物 / 一搭多 / 重复出现 A 的 A）
- **感情色彩**：褒义 / 中性 / 贬义，跟文段一致
- **程度轻重**：文段出现温和词语→选程度轻的；出现绝对词语→选程度重的

### 实用技巧（易错点）

- **直接对应**：直接呼应最优，不要往前推（eg 大米稀缺 → 选"少"，不选"贵"）
- **结构法**：结构一致，内容一一对应
- **择优思维**：选项都对时，选更全面、更精准的
- **生僻词**：先分析常见词确定答案；字面意思猜义（望文生义）

### 常见逻辑关系（旧版笔记，保留）

| 关系 | 标志词 | 解题要点 |
|------|--------|---------|
| 并列 | 和、与、同时、既...又... | 前后语义相近 |
| 转折 | 但、却、然而、不过 | 前后语义相反 |
| 递进 | 甚至、更、尤其 | 后比前更深一层 |
| 因果 | 因为、所以、因此 | 前后有因果关联 |
| 解释 | 也就是说、换言之 | 前后语义相同 |

### 高频易混词辨析

| 词语 | 含义 | 适用场景 |

## 二、阅读理解

### 主旨概括题（中心理解）

**核心方法（大懒猫）**：先识别文段结构 → 找出总句/重点句 → 匹配选项。

> 💡 **判断是"总"还是"分"，核心是判断"为谁服务"**：分句（背景/解释/举例）都是为总句（观点/对策/总结）服务的。

#### 按结构触发（先问"这段是什么结构？"）

| 结构 | 标志词 | 中心在哪 | 大懒猫要点 |
|---|---|---|---|
| **转折** | 但是、可是、不过、然而、事实上、其实、殊不知、不同的是 | **转折后是重点** | 反驳型：①转折只反驳→选前文反面；②反驳+新观点→必须体现新观点；③只反驳无新观点→选转折后。**双循环A但B/B但A=转折失效** |
| **递进** | 更、甚至、特别是、不仅…而且 | **递进后是重点** | 若递进后无合适答案→可选前面的大话题 |
| **因果** | 因为…所以、因此、从而、可见、使得、"这"、换句话说 | **结果是重点** | 答案呈现：因果阐明 > 果的因 > 果；有些因果文段无标志词，**内容为王** |
| **对策** | 要、应该、必须、建议、只有…才、前提、基础、重要的是 | **原文对策为核心** | 对策文段选对策；问题文段对策可行选对策、不可行选问题；**对策一定要有针对性、可行性** |
| **总分** | 总句（观点/对策/总结），分句（背景/解释/举例） | **总句** | 分句为总句服务 |
| **并列** | 分号、也/又/同时/此外、一方面…另一方面、句式一致、时间并列、无论证关系 | **全面概括 / 宏观概括 / 提取共性** | 文段A+B→答案A+B；A+B→C；A1+A2→A（**用排除法做题**） |

#### 快速解题模型（实用）

- **旧+新**：过去X + 现在Y → **现在的新情况为重点**
- **并列强调**：A，B也…后文围绕B展开 → **重点为B**
- **问+答**：提出问题 + 解释说明 → **答案多为对问题的回答**
- **论点论据**：论点为核心；**选项话题要 ≥ 文段**，只选论据（话题<论点）必错

#### 实用技巧（你的易错点）

- 🚩 **话题限定**：正确答案要体现核心话题；出题人爱做同义替换，**专业名词一般不替换**。
- 🚩 **结合选项定中心**：文段脉络不明确时，用选项反推。
- 🚩 **假设代入反推**：假设某选项对，反推文段该怎么写，再核对。
- 🚩 **同构选项排除**：两个选项表达内容一致 → 一起排除。
- 🚩 **别追求"最全面"**：中心句 = 总句的直接转述即可，不是越全面越好。全面但夸大的（绝对化）往往是干扰项。

### 意图推断题（作者"意在强调/想表达"）

> 中心理解题的进阶：**不但要找中心句，还要问"作者真正要强调的是哪层？"**

- 紧接中心句，但要对"哪个才是作者真正落点"做判断。
- 警惕：**把"必要条件/前提"当成"作者的结论"**（如"只有…才"是条件，不是对策）。
- 警惕：**把"论据"当成"论点"**（支撑句不是作者最想强调的）。
- 陷阱：**"在于/关键"题** → 一定要找文段点明的**症结/针对性对策**，不是复述理想条件。

### 细节判断题

**逐项对照原文**，注意易错的几种改写：
- 无中生有、偷换概念、偷换时态、偷换逻辑、绝对化、强加对比、与文意不符
- **选非题**：绝对化的表达作为答案的概率更高；**选是题**：温和的表达概率更高
- **做题顺序**：选项短→先看选项画关键词→回文段对比；文段短→先读文段再做选项

### 推断题

基于原文合理推断，不选原文直接复述的选项

## 三、语句表达

### 接语选择题（接下来最可能讲的是？）

> 🚩 核心：**话题一致性 + 行文逻辑合理**。别被尾句某个词带走。

**分类与易错点：**
- **常规接语**：①尾句提出**新话题**→后文围绕新话题展开（前提：那个词真的是"新话题"）；②结构=提出问题+分析问题+**提出对策**；③文段宏观话题→下文具体展开。
- **看结构接**：总分→先接总再接分；并列→分1分2分3分1，接分2；尾句提示转折→按转折接。
- **下文选非**：与文段矛盾 / 话题不一致 / 前文已论述过。
- **你的易错**：把尾句的**比喻词**当成新话题。真正的判断标准是"**这个词是不是成了文段新的论述对象**"，不是"它在不在尾句"。

### 语句填空题

**核心**：话题一致 + 逻辑合理。按横线位置触发：

| 位置 | 作用 |
|---|---|
| 段首 | 总结全文 / 总结下一句(冒号引出表解释) / 引出下文(中心文段) / 话题引入(通过排除法选) |
| 段中 | 承上启下；前后一致→保持相同；前后不同→搭桥 |
| 段尾 | 总结全文 / 提出对策 / 总结前一句话 |

### 语句排序题

**从选项入手，边做边排除，不建议自己排序。** 四步：首句、捆绑、顺序、尾句。

1. **首句对比**：能当首句=下定义、背景引入；不能当首句=指代不明、关键词后半部分、举例子
2. **确定捆绑**：指代词 / 关联词 / 话题一致
3. **确定顺序**：问题+分析+对策 / 观点+解释说明 / A+B / 全称+简称 / 时间顺序（话题一致）/ 日常做事逻辑
4. **尾句对比**：总结全文 / 提出对策

## 📝 我的备考笔记

### 核心病症（7 题全错总结）

> **方法都背了，但一战就丢了。真正的问题不是"不知道方法"，而是"不知道这题该调用哪条方法"。** 以下是 2023 江苏言语真题暴露的 4 大病因。

| # | 病症 | 表现 | 该记住的对策 |
|---|---|---|---|
| 1 | **越全面越好** | 把"全面但夸大(绝对化)"的选项当正确项（题1、6） | 中心句=总句直接转述即可，**不是越全越好**；见"密不可分/第一方阵"这类绝对化词要警惕 |
| 2 | **被局部词/字面带走** | 见尾句"公共服务""无人区"就选（题2、3） | 先定文段**话题**，再看选项；判断"这个词是不是新话题/核心概念" |
| 3 | **把条件/论据当结论** | "只有…才"→选D；"不确定性"→选B（题4、7） | 必要条件≠对策；论据话题<论点必错，**选项话题要≥文段** |
| 4 | **细节题看不出改写** | 题5把"原理相近(错)"当成对 | 选非题盯**偷换概念/绝对化**；问到"相似"要分清**相似发生在哪一层** |

### 技巧心得（每次做题前默念）

1. **先定话题**，再对选项。整段在讲什么？记住关键词再排除。
2. **识别题型**先于做题。看到"接下来最可能讲"→接语；"作者认为关键在"→对策；"下列不符"→细节选非。
3. **中心句=作者的结论/对策/观点**，不是背景、举例、论据、必要条件。
4. 正确选项是**原文转述**（尤其专业名词不替换），见"看起来很对但换了词"高度警惕。

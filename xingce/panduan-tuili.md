# 判断推理

## 概述

判断推理考察逻辑思维能力，是行测中第二大模块（约 35-40 题）。

## 📊 四大题型

| 题型 | 题量 | 特点 |
|------|------|------|
| 图形推理 | 10 | 找规律，多练就熟了 |
| 定义判断 | 10 | 最稳，逐项对照即可 |
| 类比推理 | 10 | 速度快，1分钟3题 |
| 逻辑判断 | 10 | 最难，需要推理框架 |

---

## 一、图形推理

### 常见规律类型

| 规律 | 特征 | 示例思路 |
|------|------|---------|
| 位置类 | 图形平移、旋转、翻转 | 看元素移动方向 |
| 样式类 | 叠加、求同、求异 | 看图形间运算 |
| 数量类 | 点、线、面、角、笔画数 | 数完之后找规律 |
| 属性类 | 对称、曲直、封闭开放 | 看整体特征 |
| 空间类 | 折纸盒、三视图 | 空间想象力 |

### 解题步骤

```
1. 判断图形组成 → 元素相同？（位置类）
                 → 元素相似？（样式类）
                 → 元素不同？（先数数量，再看属性）

2. 数量类数什么？→ 先数面 → 再数线 → 再数点 → 再数笔画
```

---

## 二、定义判断

### 解题方法

> **关键**：题干定义是唯一标准，不要用生活常识代替定义！

**步骤**：
1. 提取定义的关键要素（主体、对象、条件、结果）
2. 逐一对照选项，排除不符合的
3. 选最符合的那个

**常见陷阱**：
- 主体偷换（定义说的是"企业"，选项说"个人"）
- 条件缺失（定义要求同时满足 A 和 B，选项只满足 A）
- 结果偏差（定义的结果是积极的，选项结果是消极的）

## 三、类比推理

### 常见关系类型

| 关系 | 示例 |
|------|------|
| 种属关系 | 苹果 : 水果（苹果是水果的一种） |
| 组成关系 | 轮胎 : 汽车（轮胎是汽车的组成部分） |
| 功能关系 | 笔 : 书写 |
| 因果关系 | 下雨 : 地湿 |
| 近义/反义 | 美丽 : 漂亮 / 前进 : 后退 |
| 顺序关系 | 申请 : 审批 : 执行 |

### 解题技巧

```
先造句子 → "A 是 B 的一种" → 看选项谁最像
         → "A 用来做 B"    → 横向/纵向对比
```

## 四、逻辑判断

### 翻译推理（形式逻辑）

| 逻辑关系 | 翻译 | 逆否等价 |
|---------|------|---------|
| 如果 A 那么 B | A → B | ¬B → ¬A |
| 只有 A 才 B | B → A | ¬A → ¬B |
| A 且 B | A ∧ B | 否定为 ¬A ∨ ¬B |
| A 或 B | A ∨ B | 否定为 ¬A ∧ ¬B |

::: warning ⚠️ 常考点
- "如果就" = 前推后（充分条件）
- "只有才" = 后推前（必要条件）
- 逆否命题一定等价于原命题
- 否命题和逆命题都不等价！
:::

### 加强/削弱题

**加强**（让结论更可信）：
- 补充正面证据
- 排除他因
- 搭桥（建立前提和结论的联系）

**削弱**（让结论不可信）：
- 因果倒置
- 他因削弱
- 切断联系
- 否定前提

### 结论型

逐个选项对照题干信息，排除无中生有的选项。

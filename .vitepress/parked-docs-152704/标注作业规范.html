题目三色高亮标注作业规范 ​

目标 ​

给指定 Markdown 文件里每道题的题干原文加三色高亮，用于复习时快速定位关键信息。

三色语义（严格遵循，不得扩展） ​

  • <mark class="rv-object">…</mark> 蓝色＝对象／范围：题干讨论的主体、限定对象、比较对象、范围限定词。
  • <mark class="rv-period">…</mark> 橙色＝时间／条件／陷阱词：时间点、数量条件、转折词（但、然而）、条件词（如果、只有）、程度与范围陷阱词（唯一、全部、可能、至少）。
  • <mark class="rv-target">…</mark> 绿色＝问题／要求：整句问法，如「下列说法正确的是」「依次填入最恰当的一项是」「将以上6个句子重新排列」「求…之比」。

硬性纪律（违反即返工） ​

  1. 原文一字不动：只允许在原文两侧插入 <mark class="..."> 和 </mark>，不得删除、增加、改写、调整任何字符（包括标点、空格、序号 ①②③）。
  2. 不得标注选项行（- **A**. / A． 开头的行）。
  3. 不得标注元信息行：来源、题源链接、复盘类型、原答/答案/用时、本人思路、最终解析、易错提醒、图解说明、<details> 标签等。
  4. 问法句必标绿：每道题必须有一处绿色，覆盖完整问法句（含末尾冒号或问号）。
  5. 宁少勿滥：不确定的不标。单字虚词（都、却、也、就、还）不单独标。构词成分不标（如「所有制」里的「所有」不是范围词）。
  6. 每道题至少 2 处、至多 8 处高亮；同一条信息不重复标。

输出要求 ​

  • 只用 Edit 工具逐处修改目标文件，不要重写整个文件。
  • 修改后自检：把该文件的 <mark class="rv-*"> 与 </mark> 全部去掉，文本必须与修改前完全一致。可用 git diff 对比确认只有插入、没有删除。
  • 不要修改任何其他文件。

各题型标注要点 ​

  • 语句排序：标出每个句子里的指代词（这、其、该）、关联词（因此、所以、然而）、时间/顺序词；问法句「将以上N个句子重新排列」整句标绿。
  • 逻辑填空：标出并列/转折/因果的关联词、空格前后的搭配提示词、引号强调的成语；问法句整句标绿。
  • 中心理解/标题填入：标出转折词后的重点句、总结词（总之、可见、换言之）、反复出现的主体；问法句整句标绿。
  • 细节判断：标出范围词（部分、全部、主要）、程度词（可能、一定、唯一）、时间词；问法句（含「正确/错误」）整句标绿。
  • 数量关系：标出已知条件（数字+单位）、限定词（均为、至少、不超过）、所求量（标绿）。
  • 资料分析：标出年份/时期、指标名、比较对象；问法（求什么）标绿。
  • 判断推理：逻辑题标出结论句、论据关键词、限定词；定义判断标出定义主体；类比标出词项。
  • 常识/政治：标出政策名称/会议名称、时间节点、绝对化表述（全部、唯一、必须）；问法整句标绿。

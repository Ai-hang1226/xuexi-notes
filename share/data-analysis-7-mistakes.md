# 资料分析 7 道错题：共同卡点在列式之前

> 一句话结论：这 7 道题的具体错因并不相同，但都发生在「先认对象、时期、单位 → 再列目标式 → 最后计算核对」这条顺序被打乱的时候。**不把它们统一归因为粗心，也不据此推断同一个心理原因。**

## 先看三个样本

| 题号 | 错在哪一步 | 关键修正 |
|---|---|---|
| 116 | 分子对了，分母的**对象范围**错了 | 分母要从「新能源」切换到「全部汽车」；长名称易混时保留区别词、先写对象式再找数 |
| 118 | 取数与还原的**路线成立**，数值估算待核 | 合并基期比值、按选项估算；看选项 → 截两位 → 约分 → 回乘试商 |
| 120 | **信息链边界**没判断清楚 | 缺汽车总出口量就该停；也可以还原两期后相减求储能同比，两种路径的边界要写清 |

其余 4 道资料错题同样按本人反馈分成口径、读数、计算与时间问题分别归档，没有合并成一句"粗心"。

## 可复用的检查顺序

1. **认对象**：这一问的是谁的什么？分母覆盖的是全部还是子集？
2. **认时期与单位**：同比、环比、累计转当季，别把口径混着用。
3. **先写目标式**：把要求的量写成 `A ÷ B`，再去找数。
4. **估算定方向**：用百化分或截位先定数量级，再决定是否精算。
5. **回查**：范围、关系、单位、字数，逐项对回题干。

::: tip 一句口诀
先把式子写对，再把数字代对。顺序反了，算得再快也是错。
:::

# 复测题库维护流程

## 行测：真题技能接入

行测复测题接入本机 `xingcezhenti-trainer` 技能提供的 ERRRC 固定版题源，网站抽题范围限定为 **2020 年及以后**。当前固定版本为 `278984401124db40da5163a31275b8deb9c282f4`；六个模块索引合计 2020—2026 年 33,107 道题、1,712 份原题文件；目录共有 2,964 条记录（含模块索引文档）。数量按固定版本的六个模块索引逐年加总。既有复测题中 122 道保留了 ERRRC 来源链接。

点击“开始20题复测”时，页面从固定版本目录按模块随机选择来源文件，按需加载题目，不把约百兆原文和图片整体复制进网页。读取后会校验 Git blob 哈希；题图按上游固定版本地址显示。最近答错题优先进入本轮，其余按模块题量比例从技能题源抽取，并保留网站原有题目。正常抽题需要网络连接到 `raw.githubusercontent.com`。

自动判分只取题目文件中明确的单选 A—D 答案和完整四个选项。此类技能题参考答案来自上游固定版题目文件，尚未逐题与粉笔核对；题面缺失、选项不全、答案格式不明确的题会跳过。用户发现题面或答案疑问时，按完全相同的题面版本去粉笔核对；待核结果不得冒充已核答案。

### 公开题库交叉核对记录（2026-11-23）

`retest/public-source-crosscheck.json` 记录了 138 道带公开来源链接的题目，其站点参考答案与 ERRRC 固定版原题文件中的公开答案（含官方解析）逐题比对的结果：137 题一致，1 题不一致（该题为用户已确认、按个人复测口径判 D 的图推争议题，详见其 gradingNote）。核对以题面上的 qid / 题干文本定位原题块，来源链接与核对日期记在报告内。

这份核对属于**公开资料交叉核对**，仅用于确认站点答案与所依据的公开题源一致、**没有抽取错位**；它不等于粉笔逐题核对，也不等于考试机关公布的官方答案，判分口径不变。`fenbi-verified.json` 只收录按粉笔题面版本逐题核对的题目，两者不要混用。

手工筛选和读取原题：

```powershell
node scripts/xingcezhenti-source.mjs list --module language --year 2024 --region 江苏 --query A类
node scripts/xingcezhenti-source.mjs fetch --path "从目录结果复制完整路径" --images
```

读取只落在 `work/xingcezhenti-cache/`，并校验固定版本的 Git blob 哈希；配图只允许从上游 `90-图片/` 目录读取。静态整理记录需保留年份、地区、卷型、原题号、qid、完整选项和图片。若要把单题标为“粉笔已核”，还须确认对应题面版本并记录粉笔题目链接和核对日期；未核或题面不一致的记录不得标成已核。

把整理好的结构化记录添加到 `xingcezhenti-imports.json` 后，重新运行：

```powershell
node scripts/build-retest-bank.mjs
```

每条新增记录沿用下面的字段形状；`paperPath`、`sourceSha` 要从固定目录复制，`sourceCommit` 固定为索引版本。没有粉笔核对结果时，将 `fenbi` 留空，构建器会排除该题并说明待核原因。

```json
{
  "id": "errrc-qid-题库qid",
  "paperPath": "03-言语理解与表达/原试卷文件名.md",
  "sourceSha": "固定目录中的 Git blob 哈希",
  "sourceCommit": "278984401124db40da5163a31275b8deb9c282f4",
  "module": "language",
  "title": "原试卷标题",
  "number": 1,
  "qid": "题库原始qid",
  "upstreamAnswer": "A",
  "stem": "未经改写的原题题干",
  "options": [
    { "label": "A", "text": "原选项A" },
    { "label": "B", "text": "原选项B" },
    { "label": "C", "text": "原选项C" },
    { "label": "D", "text": "原选项D" }
  ],
  "fenbi": {
    "questionUrl": "https://www.fenbi.com/对应题目链接",
    "answer": "A",
    "confirmedSameQuestion": true,
    "checkedAt": "2026-11-17"
  }
}
```

新题作为原题进入题库，不改写题干或选项；若没有可用图片、完整选项或可靠答案，就继续待核，不用自编题补空缺。知识点例题和历史错题的来源标记在生成题库时保留。

## 行测复测档案

每次 20 题交卷后，成绩摘要保留在复测记录中；每道题的选项、正确答案、日期、整卷/单题复测类型和结果单独累计。错过至少一次的题会一直留在“我的行测错题复测库”，可以搜索模块、题目或来源并单题重做。记录仅保存在当前浏览器，不会自动同步到其他设备；清理浏览器网站数据会一并清除这些本机记录。

## 申论复测范围

`build-essay-review-bank.mjs` 只从有首答依据的清单生成申论复测页，不以题库目录中出现过就认定用户做过。新增条目必须能对应首答文件；复测只保留多次作答和草稿，不自动评分、不覆盖首答或既有评分。

## 复盘结束后自动接入（2026-11-23）

用户要求后续每次行测复盘完成时，自动将本人已复盘范围内、原题材料和参考答案完整的真题纳入可判分与优先复测，不需要再提醒。先核对原题、全部选项、材料和配图，按已有题 ID 去重关联，首答及历史记录不得重写。新题和已核实旧题关联写入 `retest/reviewed-questions.json`；无法可靠判分的题写入 `deferred` 并注明具体原因，不得编造。原题目录、可判分状态、关联和优先复测由 `scripts/check-reviewed-questions.mjs` 在构建时核验；完成后还须验看线上页面。

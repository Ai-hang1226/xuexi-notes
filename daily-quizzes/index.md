# 每日测验

**每天18:00（北京时间），8道行测＋1道申论，约30—40分钟。**

先做题，再看结果与解析。试卷页保留完整题目，首答与批改分别归档。

## 使用方式

1. **闭卷作答**：打开当日试卷，记录答案、真实用时、确定或猜测。
2. **交卷诊断**：在每日测验专用聊天提交，保留首答，再核对解析。
3. **变式复测**：优先修复1—3个问题，约2天、7天后在正常测验中验证。

每天最多一份正式卷；未答不记零分、不补造时间，不积补债。题目为自编练习，申论分数标为学习性评分。

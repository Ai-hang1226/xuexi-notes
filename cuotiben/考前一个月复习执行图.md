<summary>文字速查与使用边界</summary>

| 怎么安排 | 本轮试行内容 |
|---|---|
| 工作日3小时 | 行测旧题35分钟＋申论旧题25分钟＋新题、课程与当日复盘120分钟 |
| 休息日每天6小时 | 旧内容约90分钟，其余按原计划 |
| 旧题优先级 | 不会、猜题、概念混乱 → 反复漏步、同类错误 → 方法成立但用时较长 |
| 行测怎么复习 | 同一方法先选1—2道代表题；在35分钟内只看原题，独立做3—5题，核对第一步和实际卡点 |
| 申论怎么复习 | 回到题干和材料，亲手重写一条或一道短小题；每周2次完整旧小题重写，替换部分新题 |
| 什么时候再查 | 从首次真正闭卷检查起算，约2天复查不稳点，约7天用同类新题验证；图中的两次间隔均相对首次检查，不是先2天再等7天 |
| 怎样调整 | 再错或猜对，约1—2天后再查；独立会用则逐渐拉长间隔；已有测验覆盖的验证计入原训练，不另加一整套 |

首次复习不按过去归档日期补欠账；按方法分组筛代表题，不要求第一周把所有旧题重做。图中分钟数是试行预算，工作日3小时、休息日每天6小时为本人本次再次确认的可用窗口；不等于每天实际完成的学习时长。复杂材料或完整申论题按实际需要调整，以替换新题时间处理，不强行压入25分钟。看懂、同题记忆、改写和陌生题独立验证分别记录。

</details>

# 归纳概括：问什么，归纳什么

**一句话**：归纳概括考的不是「找得多」，而是**找得准**——先看清题目问的是哪一种要素，再按那一种的边界去材料里取。

::: tip 本页怎么用
最容易错的一步是「要素认错」：题目问做法，你连成效一起写；问问题，你写成了现象罗列。本页的 11 类要素表就是用来防这个的。

来源：《公开课课件》DAY4（建构体系，PDF 第 20—26 页）与 DAY5—DAY15 各要素类型，PDF 第 27—105 页。
:::

## 一、四步策略框架

讲义把答题前的思考拆成四步，顺序不能乱：

### 1. 精准审题——先定四个坐标

| 坐标 | 看什么 | 例 |
|---|---|---|
| 判断题型 | 「概括」「归纳」「总结」这类动词 | 概括、归纳、总结、梳理 |
| 单一还是综合要素 | 问一种，还是问几种 | 「问题」是单一；「主要内容」「发展历程」是综合 |
| 锁定范围 | 根据哪几则材料 | 「根据给定资料 3」「结合材料 1—4」 |
| 明确对象 | 概括谁的什么 | 「基层治理的创新做法」「新能源汽车产业的瓶颈」 |

另外注意特殊要求：「分点作答」「分类归纳」「有逻辑性」——它们直接决定要点怎么组织。

### 2. 高效阅读——符号法标材料

讲义建议用符号快速标记：**P**（问题）、**R**（原因）、**S**（对策）、**E**（成效）、**G**（目的）、**//**（并列项）。符号不统一没关系，自己看得懂就行。

重点看四处：

- **首尾段、首尾句**：常是总结性观点。
- **关联词引导句**：转折词（但、然而）后多是问题；因果词（因为、因此）后多是原因或结论；并列词（此外、同时）提示多个要点。
- **观点句**：政府文件（「××通知指出」）、专家言论（「××认为」）、群众反馈（「村民表示」）。
- **数据与案例**：数据要转成结论（「60% 企业融资难」→「企业融资困难突出」）；案例要提炼普遍规律（「某村直播带货脱贫」→「利用电商平台拓宽销路」）。

### 3. 初步提炼——去伪存真

- **剔除**：背景描述、重复举例、与任务无关的铺垫。
- **合并**：同义要点归并。「政策执行不到位」「基层落实力度不足」「部门协作效率低」可合成「政策落实机制不完善」。

### 4. 分类归纳——按材料的逻辑，不按你的想象

三种依据，优先级从高到低：

1. **材料自身逻辑**：材料按主体、领域、时间、流程展开，就直接照它的维度分。
2. **权威观点**：材料里有政策表述或专家总结，优先拿来当总括句。
3. **通用框架兜底**：「主体—行为—结果」——谁做的、做了什么、产生什么效果。

材料没有对应关系时**不要硬套框架**。

## 二、11 类要素：边界在哪

同一个材料，问法不同，答案完全不同。下表是讲义 DAY5—DAY15 的要素清单。

| 要素 | 题目在问什么 | 取什么 | 别混进什么 |
|---|---|---|---|
| **做法／对策**（DAY5） | 做了哪些事 | 行动动词：推行、建立、开展、实行 | 成效、意义、背景 |
| **成效／效果**（DAY6） | 带来了什么变化 | 结果、数据、评价、群众反馈 | 具体做法（除非题目要「措施＋成效」） |
| **特点／作用**（DAY7） | 属性 vs 功能 | 特点＝不同于别处的安排；作用＝产生的影响 | 特点写成做法罗列；作用写成做法堆叠 |
| **问题／不足**（DAY8） | 哪里不行 | 负面表述、困境、短板、矛盾 | 现象（使用率低是现象，缺调研才是问题） |
| **原因**（DAY9） | 为什么发生 | 导致事件的因素、动机、条件、机制 | 成效（原因题不要求逐项配结果） |
| **理念**（DAY10） | 指导行动的思想 | 价值观、原则、导向（绿色发展、以人民为中心） | 具体做法（理念要能统摄做法） |
| **变化**（DAY11） | 前后有什么不同 | 时间维度上性质、状态、结构、数量的演进 | 单点现状（要能看出「从……到……」） |
| **过程**（DAY12） | 经历了哪些阶段 | 阶段划分与步骤（规划、建设、验收） | 与「变化」不同：过程重阶段，变化重差异 |
| **段话**（DAY13） | 用一段话概括多则材料 | 主题统一、句间有逻辑、不分条 | 分条罗列（题目要求成段就不能分条） |
| **流程／要求**（DAY14） | 办事的步骤与规矩 | 先后顺序、条件、时限、责任 | 泛泛的做法 |
| **经验**（DAY15） | 可复制的成功做法 | 从实践中总结的模式与方法，要能推广 | 只写这个案例的特殊细节 |

## 三、压缩的三条原则

讲义反复强调：**压缩不等于写空**。

1. **删重复，不删区分**：同一意思出现三次，留一次；但题目要求区分的（保护 vs 利用），必须分开。
2. **具体信息按字数取舍**：树种清单、技术参数、案例数字可删；有效行动、对象、功能、布局关系要留。
3. **总括词必须覆盖子项**：总括句写「搭建平台」，下面却讲康养基地，就是总括失效。

## 四、总括句怎么写

讲义给了两种合法路径：

- 概括**行动本身**（做了什么）
- 概括**行动带来的结果**（得到了什么）

选哪种取决于问法和材料，**不能用空泛标题覆盖具体差异**。

判断标准只有一条：把总括句盖在下面所有子项上，能不能都罩住。

## 五、自检清单

写完答案，按这五条过一遍：

- [ ] 要素认对了没有（问做法就别写成效）
- [ ] 每条有没有材料依据（不是自己推的）
- [ ] 总括词罩得住子项吗
- [ ] 有没有重复条目
- [ ] 字数、分条、成段等格式要求满足了吗

# 语病辨析：先找主干，再检查关系

> **核心方法：先弄清“谁做什么、说的是什么”，再检查搭配、句式、指代和逻辑。关键词只是检查提醒，不能代替整句分析。**

| 顺序 | 检查问题 | 常见动作 |
|---|---|---|
| ① 主干 | 谁怎样？谁做什么？什么是什么？ | 暂时划去修饰语，找承担动作、判断的成分 |
| ② 搭配 | 主谓、动宾、修饰关系都说得通？ | 并列项逐个代回检查 |
| ③ 语序与句式 | 修饰放对位置？套用了两种句型？ | 整理先后层次，保留一种完整句式 |
| ④ 指代与歧义 | 谁、什么对象，有没有两种理解？ | 把指代对象明确补出来试读 |
| ⑤ 逻辑 | 否定、数量、范围、两面对应符合本意？ | 换成直白话复述 |
| ⑥ 回题问 | 题目要“有语病”还是“没有语病”？ | 比较各项明确缺陷，避免只凭读着别扭 |

**不要机械记：**“省主语就错”“通过＋使就错”“有是否就必须再有是否”“抽象比喻就是搭配不当”。

<details>
<summary><strong>一、认识句子骨架：先抓关系，不必先背术语</strong></summary>

| 骨架 | 自拟例句 | 看哪里 |
|---|---|---|
| 谁＋怎样 | 方案可行。 | 对象与状态能否对应 |
| 谁＋做什么 | 学生整理错题。 | 动作由谁发出，对谁发生 |
| 什么＋是什么 | 复盘是一种检查过程。 | 判断前后能否对应 |
| 谁＋在何时何地＋做什么 | 他昨天在教室整理错题。 | 时间地点修饰了哪个动作 |
| 谁＋做得怎样 | 他解释得很清楚。 | 动作与程度、结果是否连贯 |

主语、谓语、宾语只是帮助描述关系。**并非所有正确句子都必须同时出现主谓宾。**“天气转凉了”不需要宾语；前文已明确主语时，后句也可以省略。

<strong>压缩主干的步骤：</strong>圈中心动作 → 找动作承担者 → 找动作对象 → 把修饰语放回去。长句先压缩，是为了看清关系，不是把修饰语一律当多余。

例如自拟句：“通过本次培训，学员系统掌握了新的操作方法。”先看“学员掌握方法”，主干明确；“通过本次培训”交代方式，不造成缺主语。

</details>

<details>
<summary><strong>二、六类问题：用来定位缺陷，不必争论唯一标签</strong></summary>

同一句可能同时涉及几类问题。做题优先说明“哪里不能成立、怎样改清楚”，不必为了归类耗时。

| 类别 | 主要检查 | 自拟病句 → 修改示例 |
|---|---|---|
| 成分残缺或赘余 | 必需关系缺失？意思无谓重复？ | “通过培训，使大家掌握了方法。”→“这次培训使大家掌握了方法。”；“大约30人左右”→“大约30人” |
| 搭配不当 | 主谓、动宾、修饰关系不合适？ | “提高知识。”→“丰富知识。”或“提高知识水平。” |
| 语序不当 | 时间、程度、范围、动作先后或关联顺序错位？ | “他不仅在比赛中夺冠，而且进入了决赛。”→“他不仅进入了决赛，而且最终夺冠。” |
| 结构混乱 | 两种句式拼在一起，或主语中途被偷换？ | “主要原因是由于准备不足造成的。”→“主要原因是准备不足。”或“这是由准备不足造成的。” |
| 表意不明 | 指代、修饰、停顿或对象存在关键歧义？ | “小王告诉小李，他被录用了。”→按本意明确“他”是小王还是小李 |
| 不合逻辑 | 否定、数量、分类、因果、范围或两面关系不合本意？ | “为了防止事故不再发生。”→若本意是避免事故，应改为“为了防止事故再次发生。” |

**例句均为教学自拟，修改只示范一种常见本意，不代表任何上下文下都只能这样改。** “大约30人左右”等重复表达在口语中常见，但在这类规范表达题中宜删去冗余。

</details>

<details>
<summary><strong>三、搭配怎么查：先拆开，再逐个还原</strong></summary>

### 1. 主语与谓语

问：这个对象能否发出这个动作，或具有这个状态？不要只看两个词是否常在一起，要看句子的实际意思与比喻。

### 2. 动词与宾语

出现并列宾语时，把同一个动词分别代回去。自拟：“提高认识和工作效率”可以分别读为“提高认识”“提高工作效率”；“增加收入和工作效率”则需分别检查“增加工作效率”是否恰当。

**并列项不必形式完全相同，但都要能承受共同的谓语。** 若无法共用，给其中一项补上合适动词。

### 3. 修饰语与中心语

问：这个修饰语究竟修饰谁？范围、程度是否适当？位置不同可能改变意思，不要只凭最近的词连接。

### 4. 比喻与语义

比喻本来就允许跨对象表达；只要对应关系清楚，不因“不是字面事实”就判搭配错误。第16题C用“绣花、针针线线”比喻治理环节精细衔接，平台据此判为无语病。

</details>

<details>
<summary><strong>四、信号词检查表：看到它，去检查什么</strong></summary>

| 信号 | 应检查的关系 | 不要机械判断 |
|---|---|---|
| 通过、经过、由于、使、让 | 介词结构是否把原本的主语包了进去？全句有没有明确承担者？ | “通过培训，使大家……”在缺少其他主语时常有问题；“学校通过培训，使大家……”已有主语，不能见词就判错 |
| 和、以及、与、并 | 并列层级是否一致？共用动词能否搭配每一项？ | 出现并列并不自动需要每项补一个动词 |
| 不仅……而且…… | 内容是否确有递进？语序、关联词位置是否配合主语？ | 先看具体层次，不把任何“而且”都理解成程度加深 |
| 是否、能否、成败、高低 | 整句是在谈两个结果与相应条件吗？ | 不是单字数量配对；有“能否”不等于另一边必须再写“是否” |
| 防止、避免、禁止、不、没有 | 最终是要事件发生，还是不发生？ | 先还原本意；不能把所有“避免＋不”不加分析地判错 |
| 大约、左右、至少、超过、近、倍 | 数量范围、增减方向和计算口径一致吗？ | “增加到”是终值，“增加了”是增量；减少一般用比例、分数或具体量表达，避免含混的“减少几倍” |
| 这个、其、他、自己、对…… | 指代和评价对象能否唯一确定？ | 汉语允许省略；只在关键对象确实不清时补明 |

**两面对应的自拟反例：**“能否按期交稿，取决于准备是否充分。”关系清楚；“这次试验的成败，取决于设备状态。”后半“设备状态”本身可涵盖不同状态，也不能仅因没写“好坏”就断言错误。要看句义是否真正只承接了其中一面。

</details>

<details>
<summary><strong>五、第16题完整复盘：平台答案与解释边界分开</strong></summary>

**原卷选D，平台答案C；用时80秒。** 用户明确表示：当时缺乏系统的分析网络，不知道怎样具体检查语病；尚未提供最初选择D的更具体理由，不能补写成某个未经确认的误判。

| 选项原句 | 平台判定 | 更稳妥的学习结论 |
|---|---|---|
| A. 民众对清洁工揭发相关企业偷排污水的问题，普遍感到非常气愤 | 平台认为气愤对象可能不明，存在歧义 | 检查“对……”结构的范围及评价对象。自然阅读容易理解为对企业偷排污水气愤；不要据此把所有类似长修饰结构都判为病句 |
| B. 叙述是把人物的经历或事物发展变化的过程表述出来，就叫叙述 | 两套定义句式杂糅 | “叙述是……”与“把……表述出来，就叫叙述”择一保留；这是本题较明确的结构问题 |
| C. 像绣花一样精细化治理，意味着针针线线要无缝衔接、融为一体 | 平台判无语病，选C | 比喻对应精细治理与环节衔接；不因抽象表达或比喻而直接排除 |
| D. 当年我与你认识的时候，还是个十多岁的少年，背井离乡充满幻想 | 平台认为后句无法确定说“我”还是“你” | 在独立选项中明确补“我”会更清楚；但连续主语省略在汉语中正常，不能推广成“后句没有主语就一定错” |

**按本题平台解释进行改写：**

- A：“民众对相关企业偷排污水的行为普遍感到气愤，这一问题由清洁工揭发。”先明确气愤对象。
- B：“把人物的经历或事物发展变化的过程表述出来，就叫叙述。”保留一种定义句式。
- D：“当年我与你认识的时候，我还是个十多岁的少年，背井离乡，充满幻想。”按说话者描述自己的本意补明对象。

<strong>边界：</strong>A、D的歧义程度存在语境与阅读习惯影响。本笔记如实保留平台判法，并提炼“明确修饰范围、补明关键对象”的方法；不把平台措辞升级为无条件语法禁令。原题与完整平台解析见[重点题阅读版](/cuotiben/言语理解专项复盘-2026-10-17)。

</details>

<details>
<summary><strong>六、做题与复盘怎么分工</strong></summary>

<strong>做题时：</strong>先确认题问 → 压缩主干 → 优先找明确的搭配、杂糅、否定等问题 → 比较剩余项 → 带回原句复读。读着别扭可以触发检查，但不能成为唯一判错证据。

<strong>复盘时：</strong>用三行记录即可：

> 问题位置：哪段词句？<br>
> 关系缺陷：缺对象、搭不上、混句式、指代不清，还是逻辑偏了？<br>
> 最小修改：改动尽量少，是否保留原意并修复关系？

最小修改是验证理解的方法，并非所有题目都只有一种改法。若两种解释都自然，应把歧义和平台选择依据写清楚，避免强造规则。

<strong>下一次最小验证：</strong>独立做未见过的语病题，先说出具体问题，再看解析；记录自己是“找不到关系”还是“找到了但修不好”。本轮只是完成教学归纳，不增加已完成练习量，也不把理解标为独立掌握。

</details>

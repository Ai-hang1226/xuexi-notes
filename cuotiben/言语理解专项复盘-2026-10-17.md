## 第1题｜陌生搭配不等于错误搭配 {#q1}

**错题｜原答A → 答案B｜23秒**

**题目回顾**

教育评价事关教育发展方向。如果仅仅以升学率作为唯一的评价指标，必然会（ ）教育的本质，导致学校和家长片面追求分数，从而（ ）了学生全面发展的空间。依次填入括号处最恰当的是（ ）。

- **A．** 扭曲 限制
- **B．** 偏离 挤压
- **C．** 违背 压缩
- **D．** 模糊 剥夺

**我的原始思路**：第一空认为“偏离”应搭配道路、轨道，先排B；“违背”联想到意愿，认为“模糊本质”不贴，选A。第二空实际看过，但觉得限制、挤压、压缩、剥夺都可以。

**最终解析**：仅以升学率评价 → 片面追分占用其他发展余地 → 偏离教育本质／挤压全面发展空间 → 整组优选B。

**易错提醒**：“偏离”可用于抽象目标、本质；“限制发展空间”并非语言错误。挤压侧重一方占用而排挤另一方，不能仅凭第二空断言A绝对不通。

## 第5题｜并列特征不自行补成手段目的 {#q5}

新一届戏曲文化周（　）艺术性与专业性，体现群众性和参与性，运用现代科技诠释（　）传统戏曲魅力。依次填入横线处最恰当的是（ ）。

- **A．** 强调 演绎
- **B．** 突出 展演
- **C．** 融合 呈现
- **D．** 结合 凸显

**我的原始思路**：把“结合／融合艺术性、专业性”理解为体现群众性、参与性的手段，先排A/B；又觉得凸显比呈现更突出，选D。

## 第6题｜重复出现同一名词，不等于只有一个论述方面 {#q6}

**错题｜原答A → 答案C｜22秒**

**题目回顾**

导致鸡蛋产生腥味的物质是三甲胺，饲料是三甲胺产生的“导火索”。鸡饲料一般为油菜籽、鱼粉等，它们含有芥子碱、胆碱、氧化三甲胺等物质，这些物质会在鸡的肠道内生成三甲胺，当三甲胺达到一定浓度时，就会导致鸡蛋出现腥味。鸡蛋是否有腥味还跟鸡的品种有关，有些种类的鸡体内存在一种生物酶，能将体内的三甲胺转化为氧化三甲胺，并随着排泄物排出体外，这种鸡蛋就没有腥味或者腥味很淡。这段文字意在说明（ ）。

- **A．** 三甲胺是导致鸡蛋产生腥味的主要物质
- **B．** 三甲胺含量的多少和鸡蛋的品质没有关系
- **C．** 鸡饲料成分、鸡的品种决定了鸡蛋有无腥味
- **D．** 鸡饲料成分中应尽量减少油菜籽、鱼粉等物质

**我的原始思路**：觉得首句更重要，后两句都谈三甲胺，因而把全文读成解释致腥物质，选A；复看后才发现饲料成分与鸡的品种是两个方面。

**最终解析**：饲料成分 → 生成三甲胺；鸡的品种 → 酶转化、排出三甲胺。“还跟……有关”补充另一方面 → 两方面共同概括 → C。

**易错提醒**：A只抓致腥物质，未概括全文两个方面；不能只数关键词重复次数。原题写“饲料成分”，本人口述的“鸡的成分”不作为原题改写。

- **A．** ⑥④②①③⑤
- **B．** ④⑥①⑤②③
- **C．** ⑤③④⑥①②

**最终解析**：⑤引出历史地理学 → ③因此说明两学科结合 → ④概述两学科侧重 → ⑥具体解释时间／空间 → ①提出时空结合理念 → ②补充理由 → C。

**易错提醒**：④内部转折完整，②内部因为所以完整，不能仅因关联词就禁止作首句。⑤③、④⑥等衔接须在选项和全段中验证；不是背一句定义必首。

## 第16题｜语病题先建检查顺序 {#q16}

**错题｜原答D → 答案C｜1分20秒**

**题目回顾**

下列句子中没有语病的一项是（ ）。

- **A．** 民众对清洁工揭发相关企业偷排污水的问题，普遍感到非常气愤
- **B．** 叙述是把人物的经历或事物发展变化的过程表述出来，就叫叙述
- **C．** 像绣花一样精细化治理，意味着针针线线要无缝衔接、融为一体
- **D．** 当年我与你认识的时候，还是个十多岁的少年，背井离乡充满幻想

**我的原始思路**：原卷选D；本人未提供当时选D的具体依据，明确表示缺少系统知识网络、不知道如何具体检查语病。

**最终解析**：主干与修饰层次 → 搭配／句式 → 指代与逻辑。B混用两套定义句式；A按平台判定气愤对象有歧义；D按平台判定省略主体产生歧义；C最明确 → C。

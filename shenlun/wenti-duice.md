# 问题对策：先有问题，再看办法

**一句话**：对策不是想出来的，是**从材料里推导**出来的——先看材料有没有现成措施，没有就从问题、原因、经验教训反推。

::: tip 本页怎么用
对策题最大的分差不在「想不出办法」，而在「脱离材料自己编」。本页的顺序就是考场顺序：先认命题形态 → 再定对策来源 → 最后逐条检查落地性。

来源：《公开课课件》DAY25（建构体系，PDF 第 155—160 页）与 DAY26—DAY29，PDF 第 160—177 页。
:::

## 一、先分清三种命题形态

同一个「提对策」，题干问法不同，答案结构完全不同。写错结构，内容再对也丢分。

| 形态 | 题干长什么样 | 要不要写问题 | 答案结构 |
|---|---|---|---|
| **常规类**（DAY26） | 「梳理问题并提出对策」「针对……问题提出建议」 | 要 | 问题与对策**一一对应** |
| **纯对策**（DAY27） | 「就……提出建议」「请提出解决措施」 | 不要 | 直接给对策，可先表态 |
| **混分析**（DAY29） | 「分析……并提出对策」「谈谈你的看法和建议」 | 要（分析部分） | 分析为主，对策为辅 |

**常规类的两种写法**（讲义给的模板）：

```
写法一（逐条对应）：问题：……。对策：……。
写法二（先总后分）：问题：1.……；2.……。对策：1.……；2.……。
```

题干出现「问题梳理准确、有条理」这类要求时，**必须梳理问题**，不能只给对策。

## 二、对策的三个来源（按优先级）

### 1. 直接对策：材料里已经写了

标志词：「应」「应该」「必须」「需要」「要」。

还包括：政策文件表述、领导干部与专家讲话、其他地区和国家的成功做法。

> 例：材料说「博物馆通过提供『场所』进行文化价值的『输出』，实现了教育功能」→ 对策直接写成「提升博物馆教育功能，加强文化价值输出」。

**能直接抄的绝不自己编**，这是最稳的得分方式。

### 2. 间接对策：从问题、原因、经验教训转换

| 转换方式 | 怎么做 | 例 |
|---|---|---|
| 问题推对策 | 把问题反过来写成「消除这个问题的动作」 | 「中介欺骗、搪塞、临时加价」→「建立严格准入退出机制，整顿租赁乱象，追责严惩中介欺骗」 |
| 原因推对策 | 找到根本原因，针对原因下手 | 「房东不愿配合办暂住证，导致租户权益无法享受」→「提供房东配合办证的补贴，消除租户与业主待遇差异」 |
| 经验教训推对策 | 成功经验复制、失败教训规避 | 「大城市都在出台政策吸引人才」→「多建公租房、人才公寓，给应届生最长三个月免费公租房」 |

### 3. 自创对策：材料没有，但要能落地

讲义给了六个维度的问题与对策对照，**只在材料确实没给办法时用**，且必须结合材料场景细化，不能整段照搬口号。

| 维度 | 常见问题 | 对应对策方向 |
|---|---|---|
| **体制机制** | 制度碎片化、权责不清、流程冗余、跨部门协同低效、考核模糊 | 制度重构（权责清单）／流程再造（标准化＋压缩时限）／协同创新（信息共享平台、会商机制）／考核量化（可追溯指标挂钩奖惩） |
| **作风能力** | 形式主义、专业能力不匹配、协作机制不健全 | 作风提质（干部下沉一线）／能力升级（靶向培训＋实战演练）／创新赋能（容错免责清单）／协作增效（AB 岗互补） |
| **执行监督** | 责任链条不清、监管手段单一、问责宽松、群众监督渠道不畅 | 责任压实（任务清单＋时间表＋责任人）／监管提效（日常督查＋大数据监测＋第三方评估）／问责从严（分级预警、专项约谈）／透明监督（信息公开＋监督奖励） |
| **宣传教育** | 受众定位模糊、传播形式单一、实效性差 | 分众传播（按干部、群众、企业定制）／融合创新（云端课堂＋实地实训）／实效提升（案例教学、情景模拟） |
| **资源保障** | 资源配置撒胡椒面、筹资渠道单一、资产闲置 | 精准配置（需求导向）／多元筹措（财政＋社会资本＋市场化）／绩效管控（使用绩效评估倒逼盘活） |
| **人才保障** | 引不来留不住、培养体系滞后、激励僵化 | 精准引才（需求目录＋柔性引才）／定向育才（政企校合作、订单班）／暖心留才（待遇＋晋升通道）／多元用才（本土人才＋跨区域共享） |

## 三、检查一条对策：四问

写完每条对策，用四个问题过一遍（讲义「检查一条对策」）：

1. **谁来做**——主体明确吗？（不能只写「加强管理」，谁加强？）
2. **做什么**——动作具体吗？（「完善机制」不如「建立跨部门信息共享平台」）
3. **针对什么问题**——和材料里的哪个问题对应？
4. **能否落地**——受题目要求、材料信息、现实条件三重约束。

四问过不了的，删掉或改写。**删去重复和空泛表述**本身就是得分动作。

## 四、评分逻辑（为什么同样写五条，分差很大）

讲义把对策题的分值拆成三块：

| 层次 | 占比 | 含义 |
|---|---|---|
| 踩分点 | 40%—60% | 材料里的关键对策有没有写到 |
| 逻辑层次 | 20%—30% | 有没有分类、有没有总括句、层次是否清楚 |
| 细节深度 | 10%—20% | 对策是否具体到可执行 |

对应的三类失分：

- **脱离材料，过度发挥**：凭主观经验答，忽略材料里现成的对策。
- **对策空洞**：满篇「加强」「推进」「完善」，没有具体内容。
- **逻辑混乱**：同一对策在不同分类中重复出现，或对策与问题不对应。

## 五、考场上怎么走

1. **读三遍材料**（讲义「材料三读法」）：读问题、读原因、读经验。
2. **标记来源类型**：这条是直接抄的、推出来的，还是自创的——心里有数。
3. **定结构**：按命题形态选「问题＋对策对应」或「纯对策分条」。
4. **写总括句＋具体措施**：每条先一句概括，再落到动作。
5. **四问回查**，删空话。

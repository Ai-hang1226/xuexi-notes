# 📌 使用指南

> 与首页「使用指南」同源，原文保留；这里补充全站找路说明。

## 四步闭环

1. **学方法**：在每个模块的 `.md` 里用 Markdown 写笔记，体系与方法都在里面
2. **查知识**：顶部搜索栏支持全文搜索，任何知识点都能找到
3. **做错题**：做完题把错题按模块录进[错题本](/cuotiben/)，定期回顾
4. **走闭环**：每一题都归到位 + 记住错因，让小懒猫的知识真正长成体系

## 找路

- 不知道从哪开始 → [🗺️ 全站地图](/guide/)
- 想系统学某一块 → [📗 五大模块学习路径](/guide/#二按模块找内容)

## 把大段文字变成卡片

复盘里常有连着好几段的说明文字。现在可以拆成要点卡：一眼看到原判、修正、下一步，原文仍可展开查看。看[135题复盘页](/daily-quizzes/2026-11-07-xingce-135-review)的实际效果。

做法两步：

1. 在页面顶部 frontmatter（`---` 包围的区域）里加一个列表，例如：

```yaml
digest:
  - icon: "🧮"
    tag: "116 · 口径"
    title: "分母范围要换对象"
    before: "分母取新能源范围"
    after: "分母取全部汽车"
    body: "一句话说明。"
    steps: ["短名保留区别词", "先写对象式", "再找数"]
    status: "待试用"
    tone: "warn"
    link: "/cuotiben/135题混合真题批改-2026-11-07#q116"
```

2. 在正文对应位置放一行 `<VisualCards field="digest" />`。

每条可填：`icon` 图标、`tag` 小标签、`title` 标题、`before` / `after` 修正前后、`body` 说明、`steps` 步骤条、`status` 状态、`tone` 颜色（good / warn / bad / info / muted）、`link` 原文链接。同一页放多组卡片就用不同键名，再写对应 `field`。原文放进 `<details>` 折叠保留，不删任何记录。

## 把链接列表变成入口卡片

一排蓝色下划线的链接（例如文末「回到原始记录」）可读性差。改成入口卡片，图标、标题、一句说明、箭头各就各位：

```html
<LinkCards :columns="2" :items="[
  { icon: '📝', title: '135 题综合检测 · 结果复盘', desc: '原始判分与逐题反馈', link: '/daily-quizzes/2026-11-07-xingce-135-review' },
  { icon: '🧮', title: '速算工具箱', desc: '增长率、基期、比重随手算', link: '/tools/' }
]" back="/share/" backText="返回精选导读" />
```

`columns` 是列数（默认 2，手机端自动变单列）；`back` 与 `backText` 可选，用来生成底部的返回按钮。看[资料分析 7 道错题](/share/data-analysis-7-mistakes)文末的实际效果。

正文里零散的链接已经全站统一为「深靛蓝、无下划线、悬停才出现淡底线与背景」，不用逐页改。

## 六大板块 · 同款章节导航

每个内容板块都有**同版式**的章节卡片页：章号 → 章名 → 要点标签 → 直接跳到原文对应位置，方便按同一套节奏记忆。入口在[全站地图](/guide/)的「六大板块 · 同款章节导航」小节，也挂在侧栏各模块里：

| 板块 | 导航页 | 章数 |
|---|---|---|
| 言语理解 | [言语体系 · 16 章导航](/xingce/言语体系章节导航) | 16 |
| 数量关系 | [数量关系 · 16 章导航](/xingce/数量关系章节导航) | 16 |
| 判断推理 | [判断推理 · 四大题型导航](/xingce/判断推理章节导航) | 4 |
| 资料分析 | [资料分析 · 方法体系导航](/xingce/资料分析章节导航) | 10 |
| 常识判断 | [常识判断 · 知识范围导航](/xingce/常识判断章节导航) | 7 |
| 申论 | [申论 · 五大题型导航](/shenlun/五大题型导航) | 7 |

六个板块共用同一个 `SectionNav.vue` 组件与 `data/section-nav.json` 数据，由 `scripts/gen-section-nav.mjs` 从各体系页标题确定性抽取（含小节标题、列表项、表格首列）；519KB 的言语正文不拆章，只由导航页承载检索与跳转。页面里写一行 `<SectionNav section="板块键" />` 即可，言语页沿用 `<ChapterNav />` 别名。正文改动后运行 `npm run chapter:sync` 会同步全部板块，不会漏章。

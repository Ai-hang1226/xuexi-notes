## 概述

常识判断考察知识面广度，靠积累不靠突击。国考 15 题左右，建议用时 8—10 分钟，不要纠结。

> 💡 **策略**：知道的快速选，不会的凭感觉选，绝不恋战！

## 📚 考察范围

> ⚠️ **政治理论已单列**：2025 年起国考行测把政治理论从常识判断中剥离，单独成块（20 题）。本页只保留常识判断的经济、法律、科技、文史、地理、生态部分，政治内容见[政治理论](zhengzhi-lilun)。

| 领域 | 占比 | 备考方式 |
|------|------|---------|
| 法律 | 25-30% | 宪法、行政法、民法典基础概念；新法常结合情境考 |
| 科技 | 20-25% | 近年科技成就、航天、生物技术；物理化学生物基础 |
| 文史 | 15-20% | 中国古代史框架、著名文学作品 |
| 经济 | 10-15% | 基本经济概念、宏观经济政策 |
| 地理 | 8-10% | 中国地理、世界地理常识 |
| 生态／社会 | 8-10% | 生态文明、社会民生相关常识 |

## 三、文史常识

### 中国古代朝代顺序

```
夏 → 商 → 西周 → 东周（春秋/战国）→ 秦 → 西汉 → 东汉
→ 三国 → 西晋 → 东晋 → 南北朝 → 隋 → 唐 → 五代十国
→ 北宋 → 南宋 → 元 → 明 → 清
```

### 文学常识

| 时期 | 代表作品 |
|------|---------|
| 先秦 | 《诗经》《楚辞》《论语》《庄子》 |
| 汉 | 《史记》《汉书》 |
| 唐 | 李杜诗歌、韩柳古文 |
| 宋 | 苏轼、李清照、辛弃疾词 |
| 元 | 关汉卿《窦娥冤》、王实甫《西厢记》 |
| 明清 | 四大名著 |

# 言语理解与表达

## 概述

言语理解与表达是行测中题量最大的模块，考察对语言文字的理解和运用能力。

## 📊 题型分布（国考）

| 题型 | 题量 | 建议用时 |
|------|------|---------|
| 逻辑填空 | 15-20 | 12-15 分钟 |
| 阅读理解 | 15-20 | 12-15 分钟 |
| 语句表达 | 5-8 | 5-8 分钟 |

---

## 一、逻辑填空（选词填空）

### 解题步骤

1. **通读全文** → 把握语境和感情色彩
2. **分析空缺处逻辑关系** → 并列/转折/递进/因果/解释
3. **辨析词义** → 从选项中选择最合适的

### 常见逻辑关系

| 关系 | 标志词 | 解题要点 |
|------|--------|---------|
| 并列 | 和、与、同时、既...又... | 前后语义相近 |
| 转折 | 但、却、然而、不过 | 前后语义相反 |
| 递进 | 甚至、更、尤其 | 后比前更深一层 |
| 因果 | 因为、所以、因此 | 前后有因果关联 |
| 解释 | 也就是说、换言之 | 前后语义相同 |

### 高频易混词辨析

::: details 📝 我常搞混的词（持续更新）

| 词语 | 含义 | 适用场景 |
|------|------|---------|
| 推脱 / 推托 | 推脱=推卸责任 / 推托=借故拒绝 | ①他有错不认，一味**推脱** ②他以生病为**推托**没来 |
| 必需 / 必须 | 必需=不可缺少的东西 / 必须=一定要 | ①水是生活**必需**品 ②**必须**完成 |
| 遏制 / 遏止 | 遏制=控制住 / 遏止=使其停止 | ①**遏制**疫情蔓延 ②**遏止**暴力行为 |

:::

## 二、阅读理解

### 主旨概括题

**核心方法**：找中心句 → 提炼主题词 → 匹配选项

> 💡 中心句常见位置：段首、段尾、转折后、总结性词语后

**快速定位技巧**：
- 🚩 "因此""所以""可见"后面的往往是主旨
- 🚩 "但是""然而""不过"之后往往是重点
- 🚩 首句提出话题 + 末句回扣 = 总分总结构

### 细节判断题

逐项对照原文，注意偷换概念、无中生有、绝对化表述

### 推断题

基于原文合理推断，不选原文直接复述的选项

---

## 三、语句表达

### 语句排序

1. 先看选项首句，排除不适合做开头的
2. 找关联词配对（虽然...但是...、不仅...而且...）
3. 找指代词回溯（"这""那""其"前面一定有指代对象）
4. 按时间/逻辑顺序排列

### 语句填空

根据空缺位置判断：
- **段首** → 总起下文
- **段中** → 承上启下
- **段尾** → 总结全文

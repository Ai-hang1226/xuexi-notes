# 常识判断

## 概述

常识判断考察知识面广度，靠积累不靠突击。20 题建议用时 10 分钟，不要纠结。

> 💡 **策略**：知道的快速选，不会的凭感觉选，绝不恋战！

## 📚 考察范围

| 领域 | 占比 | 备考方式 |
|------|------|---------|
| 政治 | 25-30% | 关注时政热点、重要会议、政策文件 |
| 法律 | 20-25% | 宪法、行政法、民法典基础概念 |
| 科技 | 15-20% | 近年科技成就、航天、生物技术 |
| 文史 | 10-15% | 中国古代史框架、著名文学作品 |
| 经济 | 10-15% | 基本经济概念、宏观经济政策 |
| 地理 | 5-10% | 中国地理、世界地理常识 |

## 四、文史常识

### 中国古代朝代顺序

```
夏 → 商 → 西周 → 东周（春秋/战国）→ 秦 → 西汉 → 东汉
→ 三国 → 西晋 → 东晋 → 南北朝 → 隋 → 唐 → 五代十国
→ 北宋 → 南宋 → 元 → 明 → 清
```

# 类比推理

> 判断推理 · 四大题型之一。[← 返回判断推理总览](panduan-tuili.md)

## 概述

类比推理题量约 10 题，速度快，1 分钟 3 题。

## 📊 常见关系类型

| 关系 | 示例 |
|------|------|
| 种属关系 | 苹果 : 水果（苹果是水果的一种） |
| 组成关系 | 轮胎 : 汽车（轮胎是汽车的组成部分） |
| 功能关系 | 笔 : 书写 |
| 因果关系 | 下雨 : 地湿 |
| 近义/反义 | 美丽 : 漂亮 / 前进 : 后退 |
| 顺序关系 | 申请 : 审批 : 执行 |

## 解题技巧

```
先造句子 → "A 是 B 的一种" → 看选项谁最像
         → "A 用来做 B"    → 横向/纵向对比
```

# 🚩 政治理论（行测单列模块）

**一句话**：政治理论已从常识判断里独立出来，是行测六大专项之一——考的不是"知道多少新闻"，而是**党的创新理论 + 方针政策 + 基本原理**能不能对上号。

## 为什么单独成块

2025 年起国考行测把政治理论从常识判断中剥离，2026 年延续这一设置：

| 项目 | 情况 |
|---|---|
| 题量 | 20 题（常识判断为 15 题） |
| 占行测比重 | 约 14%—15% |
| 三类卷差异 | 省部级、市地级、行政执法类共用同一套政治理论题，无差异题 |
| 大纲表述 | 「主要测查报考者学习理解掌握党的创新理论及党和国家方针政策的情况」 |

这意味着它不能再用"常识靠积累、不会就蒙"的策略对待，而是要像言语、判断一样**按考点系统过一遍**。

## 考查范围：五块

| 板块 | 具体考什么 | 备考方式 |
|---|---|---|
| **党的创新理论** | 习近平新时代中国特色社会主义思想：科学体系、高质量发展、全过程人民民主、全面依法治国、全面从严治党 | 抓体系框架，记"是什么、为什么、怎么做"的对应关系 |
| **重要讲话与文章** | 《求是》杂志发表的重要文章、重要会议讲话、考察调研讲话 | 按时间线积累，记讲话的**核心判断句** |
| **重要会议与文件** | 党的全国代表大会、中央全会决定、五年规划建议、中央经济工作会议、中央城市工作会议、中央一号文件 | 记会议名称 + 核心议题 + 标志性提法 |
| **马克思主义基本原理** | 马哲（实践观、矛盾论、联系与发展）、政治经济学（剩余价值、生产要素配置） | 原理要能"对号入座"，不背原文 |
| **党章党规党纪** | 党的性质宗旨、组织原则、纪律要求、自我革命 | 记关键词，注意与讲话表述的区别 |

## 高频考点分布

以 2026 年国考公开解析的考点分布作参考（20 题）：

| 考点类别 | 题量 | 说明 |
|---|---:|---|
| 领导人讲话及思想 | 约 7 | 重要讲话、考察讲话、党性相关表述 |
| 中央文件及方针政策 | 约 7 | 农业强国规划、科技强国、文化强国、依法治国、经济工作、人口工作、教育强国 |
| 五年规划 | 约 2 | 规划编制历史、五年规划建议 |
| 党和国家重大会议 | 约 2 | 中央政治局会议、中央城市工作会议 |
| 马克思主义基本原理 | 约 2 | 实践观、理论综述 |

**结论**：前两类合计约七成，**讲话与文件是主战场**，马哲只占零头但不能丢。

## 知识骨架

### 1. 习近平新时代中国特色社会主义思想

- **体系定位**：当代中国马克思主义、二十一世纪马克思主义；党的创新理论的核心内容。
- **常考切面**：科学体系（"十个明确""十四个坚持""十三个方面成就"的整体框架）、中国式现代化、高质量发展、新发展理念与新发展格局、新质生产力、全过程人民民主、全面依法治国、全面从严治党。
- **记法**：先记"总目标—总任务—总体布局—战略布局"的层级，再往里填具体提法。考题多问"下列理解正确的有几项"，考的是**提法准不准**，不是背长篇。

### 2. 中国式现代化

高频出题点，通常以"正确项有几个"形式出现。需要能分辨：

- **是本质要求**的：共同富裕、人与自然和谐共生、走和平发展道路等。
- **不是目标**的：把"物质文明超越西方发达国家"当成主要目标——这类偷换是常见干扰项。
- **是创造**的：中国式现代化创造了人类文明新形态。

> 判断诀窍：凡是把中国式现代化说成"照搬某国模式""单纯追求某一方面超越"的，基本都是错的。

### 3. 重要会议与文件

| 会议／文件 | 核心议题 | 易考提法 |
|---|---|---|
| 党的全国代表大会 | 中心任务、"两步走"战略安排 | 中心任务表述、中国式现代化的中国特色 |
| 二十届三中全会 | 进一步全面深化改革、推进中国式现代化 | 改革总目标、重大原则 |
| 中央经济工作会议 | 年度经济工作部署 | "稳中求进""以进促稳"等总基调 |
| 中央城市工作会议 | 城市发展阶段性判断 | 城市工作重心转变 |
| 中央一号文件 | "三农"工作 | 乡村振兴、粮食安全 |
| 五年规划建议 | 中长期发展目标 | 主要目标、重点任务 |

### 4. 马克思主义基本原理

**马哲四条主线**：

1. **唯物论**：物质决定意识，意识有能动作用。
2. **辩证法**：联系与发展；三大规律——对立统一（矛盾）、量变质变、否定之否定。
3. **认识论**：实践是认识的基础、来源、动力、检验标准；认识的两次飞跃。
4. **唯物史观**：社会存在与社会意识、生产力与生产关系、经济基础与上层建筑、人民群众是历史创造者。

**政治经济学**：商品二因素、劳动二重性、剩余价值、资本循环周转、生产要素配置。

考法特点：题干常引一句领导人讲话，问"体现了什么哲学原理"。**先找讲话里的关键词**（"实践""矛盾""发展""人民"），再对原理。

## 作答技巧

| 技巧 | 怎么用 | 适用场景 |
|---|---|---|
| **排除法** | 从最有把握的选项入手逐个排除 | 最通用，尤其"有几项正确"题 |
| **关键词法** | 提取题干与选项的关键词做对应 | 题干与选项对应关系明确时 |
| **对比分析法** | 比较选项之间相似或相悖的表述 | 两个选项说法对立，必有一错 |
| **绝对化警惕** | "唯一""根本""完全""超越"要格外小心 | 提法题、理解题 |

**三条通用纪律**：

1. 提法类题目**认原文表述**，不认"意思差不多"。
2. 出现"照搬别国模式""只搞一方面"这类表述，先判错。
3. 马哲题不要背原理全文，抓"这句话在讲什么关系"。

## 怎么复习

1. **按月积累时政**：只记"会议／文件 + 核心提法 + 一句判断"，不抄长文。
2. **抓两类主线**：领导人讲话、中央文件——占七成题量。
3. **马哲单独过一遍**：四条主线 + 三大规律，配 10 道真题对号入座即可。
4. **做题只复盘错因**：是"没听过"还是"提法记混"，前者补时政，后者补体系。

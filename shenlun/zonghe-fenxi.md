# 综合分析

综合分析题在概括的基础上，要求你理解材料的深层含义，分析现象背后的原因、影响和本质。

## 常见题型

| 题型 | 问法 | 特点 |
|------|------|------|
| 词句理解 | "谈谈你对...的理解" | 解释含义 + 分析原因/影响 + 得出结论 |
| 观点分析 | "对...观点，你怎么看" | 表态 + 分析 + 建议 |
| 现象分析 | "分析...现象" | 是什么 → 为什么 → 怎么办 |

---

## 一、词句理解题

### 答题框架

```
1. 解释含义（是什么）
   - 字面意思 + 深层含义

2. 展开分析（为什么）
   - 原因、影响、表现

3. 得出结论（怎么办）
   - 简要提出对策或总结提升
```

### 示例

> 谈谈你对"人在做，天在看"的理解。

**答题结构**：
1. 释义：这句话强调做人做事要对得起良心、遵守道德法律
2. 分析：当前一些领域存在诚信缺失问题；需要加强社会信用体系建设
3. 总结：每个人都应自律，同时制度要跟上

---

## 二、观点分析题

### 答题框架

```
1. 表态：正确/错误/片面/辩证看待

2. 分析：
   - 正确的部分 → 为什么对
   - 错误的部分 → 为什么错
   - 如果片面 → 补充完整视角

3. 建议：怎么做更好
```

---

## 三、现象分析题

### 答题框架 = "是什么 → 为什么 → 怎么办"

```
1. 是什么 → 概括现象，下定义
2. 为什么 → 分析原因（多角度）
   - 主观原因 + 客观原因
   - 内因 + 外因
   - 直接原因 + 深层原因
3. 怎么办 → 提出对策（简要）
```

---

## ⚠️ 常见错误

| 错误 | 正确做法 |
|------|---------|
| 只谈看法不结合材料 | 每个观点都要有材料依据 |
| 分析空泛无深度 | 从多角度、多层次展开 |
| 只分析不总结 | 分析完要有结论或对策 |
| 表态模糊 | 明确指出对还是错，不要"好像有道理" |

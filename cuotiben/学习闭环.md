# 学习闭环 · 通用框架（行测 / 申论通用）

> 这是从「言语理解」那套学习思路里**抽出来的通用流程**，去掉言语专用方法，剩下的是任何模块都能套的骨架。
> 核心：**做一个题，不只对答案，而是「归到位 + 记住错因」，让知识长成一套体系。**

---

## 一、闭环四步（每做一题都走一遍）

```
1. 归位    → 这题属于体系哪个节点？（题型分类 / 知识点）
2. 找病因  → 我为什么错？（规律性错误，不是"粗心"）
3. 记对策  → 下次遇到同类，怎么调用正确方法？
4. 回炉    → 这题暴露的薄弱节点，回头复习对应那一节；错题进错题本
```

---

## 二、逐题复盘模板（每个错题都这么填）

| 字段 | 填什么 | 例（言语·题1） |
|---|---|---|
| 来源 | 哪套真题 / 题号 | 2023 江苏 · 题1 |
| 题型 | 属于哪个体系节点 | 中心理解 · 总分类 |
| 我的答案 | 我选了啥 | A |
| 标准答案 | 正确是啥 | B |
| 错因 | 一句话：为什么错 | 被大而全选项带偏 |
| 正确思路 | 标准解法一句话 | 总句＝中国在产业链的角色 |
| 下次注意 | 一句可复用的提醒 | 先定话题再找中心 |

> 这模板在 [行测错题本](xingce-cuoti.md) 已成型，任何模块照填即可。

## 四、通用「错误类型」词汇（模块无关，可复用标记）

> 具体到某模块再细化；这里给通用的一套，错题本"错误类型"栏直接标 #编号。

| 编号 | 错误类型 | 一句话 |
|---|---|---|
| #1 | 没识别题型 | 不知道这题考什么，瞎套方法 |
| #2 | 条件/概念看漏 | 题干关键条件没看到 |
| #3 | 方法选错 | 会但调用错了方法 |
| #4 | 陷阱没认出 | 被选项偷换/绝对化/干扰带走 |
| #5 | 计算/落实出错 | 思路对，执行错了 |

> 言语自己的 4 大病因见 [..](../xingce/yanyu-lijie.md) 的「核心病症」，那是言语专属；上面这套是通用的。

言语有专门的「每日一页」（fenxiang/）。其它模块做到一定量后，再各建一版：

第一部分、中心理解

# 第一章 基础知识铺垫

## 一、基本概述

中心理解 = 抓文段的**观点/重点**。他的路子不是背「转折之后是重点」这类口诀，而是先判断**文段的脉络怎么走**，再看**观点落在哪**。

底层两件事，对应前两章：

1. 文段怎么展开的 ← **脉络**（本章）
2. 观点是谁发出的 ← **以人为本**（第二章）

## 二、脉络的顺承

顺承 = 句子之间是「接着说」的关系。判断顺承后重不重要，只看一件事：**后面有没有冒出新的主体。**

### 1、顺承后的内容重要

**规则：顺承引出了新的主体（新话题、新概念），这个新主体就是重点。**

作者肯花笔墨引出一个新东西，那才是他真正要讲的。

- **例 1.1**：前面讲脱贫成就 → 后面引出「**科技的力量**」→ 新主体是科技，重点在科技
- **例 1.2**：前面讲「运动是良医」→ 中国在此基础上提出「**体医融合**」→ 新概念是体医融合，重点在体医融合

动作就一个：**扫后面有没有出现前面没提过的东西。**

### 2、顺承后的内容不重要

**规则：后面只是在解释同一个主体——讲它的意义、作用、结果、影响——没冒出新主体，后面就不重要。**

- **例 1.3**：讲基因工程这项新技术 → 后面「**这项新技术**估计每年可望挽救十万名癌症病人的生命」→ 说的还是它，只是它的**意义** → 意义不重要，重点仍是「新技术」
- **例 1.4**：讲珊瑚 → 后面全在说珊瑚白化、珊瑚死、珊瑚复原 → 还是珊瑚
- **例 1.5**：讲剧本 → 最后「是编剧重要的创作本领」→ 回扣编剧，没新主体

> **顺承说意义时，意义本身不重要，发出意义的主体才重要。**

💡 这两条最容易混，一句话分开：**后面冒出新东西 → 后面重要；后面还在说老东西 → 后面不重要。**

### 3、逐步引出

**规则：文段一层层往下引（A 引 B，B 引 C……），前面都是引子，最后落点才是重点。** 首句往往只是引子。

- **例 1.6**：介子 → 衰变 → 夸克转化 → 费曼图 → W 玻色子 → 落点「**不同夸克的相互转化**」（选 D）

⚠️ 本质和「顺承后重要」是同一条：**最后出现的新主体最重要**。区别只是链条更长，容易把人绕进去。

### 4、顺承中的代指＋总结

**规则：出现指代词（这、此、它、该）＋总结性表述，那一句直接就是重点，抓它。**

- **例 1.7**：「**因此**，在英国引种小麦首先需要排水」→ 因此引导结论
- **例 1.8**：「**其实**通过'输入——输出'的变化来解释大脑的研究方法是不得已之举」→ 转折＋定性，落点是「有先天缺陷」（选 A）
- **例 1.9**：「**不过**，引起和维持这些变化的机制，目前尚不能明确」→ 尾句转折，落点在低度炎症（选 B）

💡 见「因此 / 所以 / 可见 / 这说明 / 其实 / 不过」接指代，直接锁那一句，不用从头捋。

> **待核 ⚠️**
> - 例 1.6 / 1.8 / 1.9 的答案（D / A / B）是我按脉络推的，讲义没印答案
> - 「顺承后重要」与「不重要」的分界，我归纳为「有没有冒出新主体」；他的原话可能更细

# 第二章 以人为本

## 一、基本概述

中心理解的核心一句：**文段的重点，是「人」发出的观点。**

所以读文段的顺序永远是：

1. **谁在说**（观点的发出主体）
2. **说了什么**（观点内容）
3. 拿这个去匹配选项

这也是「以人为本」四个字的由来——不是找「最重要的一句话」，是找**那个发出观点的人**。

## 二、万能通用解题公式

> 以下三条是原讲义正文里**本来就有的**内容（不是我的重建）：

1. 熟练掌握**观点提出的六大方式**，分析文段结构，锁定观点。第一步永远是抓住被观点主体，有时可秒杀题。
2. 找到**观点发出的主语**和**宏观限定**。
3. 匹配选项，排除干扰。

**解读**：六大方式是「怎么锁定观点」，主语和宏观限定是「怎么把观点对到选项上」。第 2 条是很多题的唯一区分点——观点内容对了但主语错了，照样选错。

## 三、观点提出的六大方式

### 其一：必要性提出观点

**识别**：出现「关键 / 核心 / 前提 / 基础 / 当务之急 / 势在必行 / 必须」这类词时，那件事就是观点。

- **例 2.1**：末句「因此浓盐水的处理已经是制约工业废水排放的**关键技术**」→ 观点 = 浓盐水的**处理**（选 C）
- **例 2.3**：「**只有**通过强农惠农……**才能**全面扩大内需」→ 必要条件句式
- **例 2.4**：「摸清他们心理健康问题检出率的'家底'**应属当务之急**」→ 当务之急
- **例 2.7**：「**显然**，要让地方政府拿出……3 倍的经费办职业学校，这不但涉及增加教育经费投入，而且也将是重大的**教育政绩观转变**」→ 选 D

> 原讲义在此处留了一句提示（他的原话）：
> **区分：A 是 B 的基础；在 A 的基础上，需要 B。**
> 这两种句式的落点不一样——「A 是 B 的基础」落点在 A；「在 A 的基础上需要 B」落点在 B。

#### 拔高*：必要性的保底思想

**规则（我的理解，待核 ⚠️）**：看到「意义重大 / 很重要」这类**泛泛的必要性**，但文段没有把必要性收到某个具体动作上时，要往**「怎么做」**上落——即「保底」在一个可执行的对策上。

- **例 2.5**：讲勤俭节约、末句「形成节约资源保护环境的消费习惯**意义重大**」→ 选 D「一粥一饭，当思来处不易」（**怎么做**），而不是泛泛说「要节约」

### 其二：设问提出观点

**识别**：文段自己提问、自己回答（含「？」）。

**规则：问什么答什么——答案就在回答里，问题本身是引子。**

- **例 2.8**：「我们是否真的对音乐产生了情绪共鸣？」→「**一个带有争议的观点认为**，我们所感知到的不过是反复交替的紧张与放松」→ 观点在作答处
- **例 2.9**：「如何解释近来接二连三的强震，它们之间有关联吗？地球是否就此进入了地震活跃期？**对此，中外专家均认为**……」→ 观点在作答处
- **例 2.11**：「那么，算盘为何有如此魅力……呢？**就是**它以框梁档珠的简单结构……」
- **例 2.12**：「**有意思的是**，虽然父母们自己已经被手机、电脑、电视占据了太多时间，却有 13.63% 的家长希望借助阅读挤压孩子玩电子产品的时间」→ 转折词带出真正的观点

⚠️ 设问的分寸：**问句本身不是观点，回答才是。** 选项里若只重复了问句的内容，是干扰项。

### 其三：三大提对策给观点

观点 = 对策。对策有三种给法：

#### 1. 开门见山给对策

直接出现「必须 / 应该 / 需要 + 动作」。

- **例 2.13**：「**必须提高社会养老能力**，才能适应加速到来的老龄化社会的要求」
- **例 2.14**：「国家在制定语言人才培养政策时，要**有统筹规划的意识**……应充分考虑各国、各民族的语言和文化」→ 选 D
- **例 2.15**：「**权威的第三方信息披露，本来就需要相关部门出面组织**，而做好这样的日常服务，会比出事后再'强化监管'有效得多」

#### 2. 做法 + 危害 / 意义给对策

前面讲危害（或意义），观点是**反推出的对策**。

- **例 2.17**：讲盗墓猖獗、地方政府破土开棺的危害 →「**如果**神州大地处处古墓大开挖，将不但是对先人的不敬……」→ 选 C「地方政府不应肆意破土开棺」
- **例 2.18**：「**如果**报纸不能从知识层面生产信息，只是在海量信息层面做文章，竞争不过新媒体是自然而然的事」→ 选 D「今天报业欲生存应多在知识层面生产信息」

#### 3. 否定型对策

用**否定句**给对策：「不应 / 不能 / 没有任何理由」。

- **例 2.19**：讲我国资源紧缺、人民还不富裕 →「我们**没有任何理由**奢侈浪费」→ 选 B「现实国情决定了我们必须节俭」
- **例 2.21**：「我们**不应**忽略科举制的历史性」→ 选 C「科举制是当时历史条件下的理性选择」

#### 补充思维：否定性观点不直接，同时出现时优选直接观点

**规则：否定表达（「没有…」「不应…」）绕了一层，不如直接表达来得直接。当选项里同时有「否定型观点」和「直接观点」时，优选直接的那个。**

- **例 2.22** 是这条的完美样本：
  - D「**没有**放之四海而皆准的法治模式」＝ 否定型
  - C「**应坚定探索**适合自身的法治道路」＝ 直接型
  - 文段末句「任何一个国家进行法治建设，都**必须探索**适合自己的法治道路」→ **选 C**

### 其四：利用他者经验态度提观点

**识别**：文段讲别人（他国、专家、历史）的经验或态度，问法是「启示 / 意在说明」。

**规则：他者的经验 → 转化成本国（或作者）该怎么做。落点是「该怎么做」，不是「别人怎么样」。**

- **例 2.23**：美国城镇化前期放任、后期加强调控 → 「这段文字给我们的**启示**是」→ 选 D「政府**应该**对城镇化发展施行规划与干预」
- **例 2.24**：波普提出证伪理论 → 选 B「科学的方法**应是**'可证伪'」
- **例 2.25**：化石燃料改变碳同位素 → 选 D「碳年代测定技术**可能不再准确**」

#### 补充思维：自身观点大于他者观点

**规则：文段里他者观点和自身观点同时出现时，自身观点是重点。**

- **例 2.26**：先讲「法、德、俄等当代数学强国的经验都启示我们……」（他者）→ 后讲「我国数学发展要走向强盛，就**需要**在加强数学文化氛围方面付出更多努力」（自身）→ 落点在自身
- **例 2.27**：先讲物理空间的小 → 结论「**因此**，小剧场不宜过度渲染舞台美术的宏阔与震撼效果，而**应该**关注思想性、艺术形式表达或创新探索维度等戏剧艺术的本体呈现」（自身）→ 后面引彼得·布鲁克的话是他者，只是佐证 → 选 C

### 其五：重要性提观点

**识别**：文段反复讲某事物的价值/意义/地位。

- **例 2.28**：三叠纪「**赋予三叠纪以特殊的意义**……对中生代生物界的发展……都有深远影响」→ 观点 = 三叠纪很重要
- **例 2.30**：手撕钢攻克 711 次试验、打破国外垄断 → 选 B「精诚所至金石为开」

#### 补充思维：重要性的跳板思维

**规则（我的理解，待核 ⚠️）**：「重要性」往往不落在「它很重要」上，而是**踩一下跳到「所以要怎么做」**——重要性是跳板，落点在对策。

- **例 2.31**：先论证传统村落承载的历史信息更鲜活、更真实（重要性）→ 末句「**因此，我们有充分的理由重视传统村落，保护传统村落**」（跳到对策）
- **例 2.32**：先论证文学经典的价值主导力、文化吸引力（重要性）→ 末句「当前国际社会普遍将传承和弘扬本民族的文学经典作为……**重大战略**」（跳到对策）

### 其六：本身观点性

**识别**：文段本身就是作者在表态——第一人称（「我希望」「我认为」）或明显的价值判断句。

- **例 2.33**：「**我希望**每一项新的惊人的技术突破都会遇到来自……怀疑主义的质难」→ 选 B「人类必须重视技术突破带来的负面影响」
- **例 2.34**：讲粉丝从幕后走到台前、话语权提升，末句「粉丝们**并不十分认同**娱乐市场中，一些品牌方、平台方对数据的过分依赖」→ 作者态度落在末句

## 四、观点的深刻剖析

> 这一节讲的是「已经找到观点了，接下来怎么把观点用准」。七个小节。

### 1、观点的优先性

**规则（我的理解，待核 ⚠️）**：文段里有多个观点/多个信息时，按重要性排序，抓**优先级最高**的那个。「更重要 / 关键是 / 首先」是信号词。

- **例 2.35**：两位学者都回忆「听」比「念」效果好 → 选 C「背诵诗文要发挥**听觉记忆**作用」
- **例 2.36**：罗列「秋老虎」的多个诱因后，末句「在这段时间，因工作劳累而缺乏休息的人，尤其要**警惕心肌梗死突然来袭**」→ 选 D
- **例 2.37**：「**更重要的是**，大时代、大变迁，让中国人有着无比丰富的生命可能」→ 「更重要的是」直接标出优先级

### 2、观点的对比性

**识别**：文段用对比来立论（这个 vs 那个、以前 vs 现在）。

**规则：对比的落点在作者偏向的那一边，不是对比本身。**

- **例 2.38**：高校竞争 →「**在此基础**上，个性化专业设置……成为独特目标开启了新通道」→ 落点在个性化专业设置
- **例 2.39**：教育「关键期」——抓住 vs 错过，两头对比，落点在「关键期很重要」
- **例 2.40**：格林斯潘认为儿童自我意识发展取决于父母与孩子的**同理心关系** → 落点在同理心

### 3、观点的统一性

**规则（我的理解，待核 ⚠️）**：文段前后讲了两件事，**但它们在讲同一个道理**。观点要把这两件事**统一起来**表述，不能只选其中一件。

- **例 2.41**：讲科学源于哲学 → 讲定量化 → 讲科学与哲学分离 → 选 B「**定量化**在科学研究中的意义」（统一在「定量化」这个共同要素上）
- **例 2.42**：讲受制于英语谱系（问题）→ 讲应重视非英语谱系（对策）→ 选 B「法律思想史研究**须重视非英语学术谱系**」
- **例 2.43**：讲知识产权激励创新 → 选 B「**保护知识产权就是保护创新**」（把两者统一成一句话）
- **例 2.44**：这是道**选非题**（「最不能体现上述文段思想的是」）→ 文段讲群众路线，A/B/C 都涉群众，D「清风两袖朝天去」讲的是廉洁 → 选 D

### 4、观点的具体性两式

**规则：观点最终要落到一个「具体的东西」上。传递路径有两种。**

#### 1）经典传递搭桥型

**传递链是明写的**：A 重要 → 所以要 B → 而 B 的前提是 C。逐层搭桥，落点在最后一环。

- **例 2.45**：量子计算重要 → 量子纠缠是核心资源 → 「**因此**，大规模纠缠态的制备……是核心问题，**而高品质纠缠粒子对的同步制备是实现大规模纠缠态的首要条件**」→ 选 A
- **例 2.46**：公共外交需要更多力量 → 大数据提供平台又提升能力 → 选 B「**大数据对公共外交的支撑和推动**」
- **例 2.47**：人的需要 → 人兽不同 → 「**因此**，人类必须要通过对象性活动，即社会实践来改变自然」→ 选 B

#### 2）隐藏传递搭桥型

**传递链藏在比喻或隐含表达里**，要自己把桥搭出来。

- **例 2.48**：「风筝不断线」是比喻——风筝 = 作品，线 = 与生活的联系 → 选 C「**艺术创作应当以生活为基础**」
- **例 2.49**：讲新闻传播学重构需平衡人与技术 → 引唐·伊德的话 → 「**因此**需要从一个超越的角度来对待围困我们的技术社会」→ 选 B
- **例 2.50**：基因编辑的危害 → 末句「**只有保持清醒的头脑**，才能使人类不断进步」→ 选 C

### 5、观点的转换性

**规则（我的理解，待核 ⚠️）**：文段前面讲的是**问题**，但观点已经**转换成了解决路径**。选项不能停在问题层面，要跟着转换。

- **例 2.51**：前讲贸易摩擦成因（问题）→ 后讲「通过大力发展对外直接投资，能够起到替代对外贸易的作用」（转换）→ 选 B「**对外直接投资有利于缓解国际贸易摩擦**」
- **例 2.52**：罗列公共健身器材管理三个盲区（问题）→ 末句「**健身器材建设好了，服务和管理工作也应跟上**」（转换）→ 选 B「不能'**重建轻管**'」

### 6、观点的偏向性四式

**规则：同一段材料，观点可以偏向四个不同方向。识别偏向，才能选对。**

#### 1）偏向具体展开

- **例 2.53**：从柏拉图讲到黑格尔（都在讲辩证法的发展），末句「**这些经典著作和论述都是我们提高辩证思维能力应该认真阅读和汲取的思想资源**」→ 选 A「阅读经典著作有助于提高辩证思维能力」

#### 2）偏向问题

**规则：观点落在「问题是什么」上，而不是「怎么办」。**

- **例 2.54**：「**对严肃新闻的漠不关心，对娱乐报道的过度追捧，对谣言谎言的麻木不仁，才是这个时代面临的更为迫切的问题**」→ 观点 = 指出了问题
- **例 2.55**：数字鸿沟 → 「**都应该**着眼长远，充分保障老年人的社会需求、权利和尊严」→ 选 A

#### 3）偏向论证

**规则：观点落在「论证的过程/依据」上。**

- **例 2.57**：怀旧综艺 → 论证经典老歌重新进入大众曲库 → 选 D
- **例 2.58**：方言消失 → 论证「语言还有文化属性，承载历史和文化」→ 选 C
- **例 2.59**：民法总则 → 论证互联网时代人格权受威胁 → 「**有效应对**」指 A
- **例 2.60**：诗歌要「敲打」→ 论证朴素 → 选 B

#### 4）偏向统一

**规则（待核 ⚠️，与上面第 3 条的区别见文末思考题）**：把文段的两个面向统一成一句话。

- **例 2.61**：环境与民生 → 选 C「**强调良好的生态环境是民生之福祉**」
- **例 2.62**：语文素养无捷径 + 阅读的作用 → 选 D「阅读对于提升语言能力的重要性」
- **例 2.63**：思考与创新 → 选 A「**创新离不开思考**」
- **例 2.64**：古法酱油——温度湿度可测，但师傅经验不可缺 → 选 A

> **原讲义留的思考题**：「偏向统一」和「观点的统一性」有什么共性以及细微的区别？
>
> **我的推测（待核 ⚠️，把握低）**：「观点的统一性」是**文段自己就在讲一个统一的东西**（如例 2.43「保护知识产权就是保护创新」，一句话把两个概念焊死了）；「偏向统一」是**文段讲了多个并列的东西，要你自己把它们统一成一句**。前者是读出来的，后者是选出来的。

### 7、主语及宏观限定的秒杀

**规则：观点内容对了，还要核对两件事——① 谁发出的（主语）② 限定范围（宏观限定）。这两件事对不上，选项就错。这是很多难题的唯一区分点。**

- **例 2.65**：讲科技体制改革要从微观转到宏观 → 主语是**政府管理者** → 选 A「应从**政府管理角度**思考科技体制改革问题」（其他选项主语对不上）
- **例 2.66**：讲「睦邻家园」建设 → 限定是**老城区** → 选 A「睦邻建设，**老城区**更有新服务」

> **待核 ⚠️（本章把握较低的地方）**
> - 「拔高*：必要性的保底思想」——我从例 2.5 倒推为「泛泛的重要性要落到具体做法」，把握低
> - 「重要性的跳板思维」——倒推为「重要性是跳板，落点在对策」，把握低
> - 「观点的优先性」「观点的转换性」——两个概念我都是从例题归纳的，边界可能不准
> - 「偏向统一」vs「观点的统一性」——讲义自己都留了思考题，我的区分把握低
> - 例 2.30 的答案（B）我不确定，这题选 C「百炼钢化为绕指柔」也说得通
> - 例 2.47 的答案（B）与 C 都沾边，我按末句落点选了 B

# 第三章 脉络剖析

> **本章是全部讲义里「黑话」最密的一章**（偏正大杀器、Cab、圈圈法、灵魂两问）。这些术语讲义只给了名字没给定义，我全靠例题倒推，**把握普遍低于前两章**，请重点核对。

## 一、偏正大杀器

### 1、偏正的展开性两式

**「偏正」= 文段有「偏」（铺垫、陪衬）和「正」（真正的落点）两部分。** 关键是识别哪部分是「正」。

#### 1）数量并列的展开

**规则（推断 ⚠️）**：文段并列罗列了**多个对象**（数量上「多」），落点不在任何一个对象上，而在**它们共同说明的那个上位概念**。

- **例 3.1**：《纲要》并列写了北京、天津、河北各自定位 → 落点是三者的**共同上位**（京津冀协同分工这一整体安排）
- **例 3.2**：《史记》传播者/接受者/研究者（多）+ 日本/欧美（多）→ 都在说「**《史记》生命力的来源**」→ 选 D
- **例 3.3**：先进制造业的多个特点并列 → 选 B「先进制造业的**主要特征**」
- **例 3.4**：北极熊夏天忍饥挨饿、行走中的休眠、瘦长 → 多个并列现象指向同一件事 → 选 B

**动作**：看到「多」，就往「它们合起来说明什么」上找。

#### 2）重点精讲的展开

**规则（推断 ⚠️）**：文段只对着**一个点**细细展开（数量上「一」），那个被精讲的点就是重点。

- **例 3.5**：从凝血机制 → 抗凝血蛋白 → 组胺 → 挠 → 越挠越痒，一路精讲一条链 → 选 B「被蚊子叮咬了为什么会**越挠越痒**」
- **例 3.6**：精讲「二分法」如何导引出「人类中心主义」→ 选 D「'人类中心主义'是如何形成的」
- **例 3.7**：精讲步兵在联合作战中的定位 → 「**因此，近战歼灭敌方是步兵在联合作战体系内的首要任务**」→ 选 B「步兵的**主要任务**」

**两式的分界**：**多 → 找共性上位；一 → 抓被精讲的那个点。**

### 2、偏正的总分和修饰性

#### 1）修饰性

**规则（推断 ⚠️）**：「正」被**修饰语包着**——核心词后面挂了一串限定/举例/解释，落点是**去掉修饰后的核心**。

- **例 3.8**：讲养老床位炒卖的种种问题 + 举例「比方说……」+「另外……」+「总之，如果不加以规范，有可能重蹈中国楼市的炒房覆辙」→ 选 B「政府应当关注养老机构的**床位定价**」
- **例 3.9**：钞票制作的设计/选纸/防伪/图案（全是对「制作」的修饰展开）→ 选 D「钞票对各项工艺流程要求严格」
- **例 3.10**：众包的定义（修饰）→ 落点「**因此**，相较于政府购买……政府众包展现出更开放的社会治理格局」→ 选 B

#### 2）总分性（了解）

- **例 3.11**：先总说军事机器人优势（总）→ 后「**然而（　）：参战的自主机器人到底是不是战斗员？又应当承担何种战争责任？**」→ 选 D「有关战争责任的伦理问题也随之出现」

> 讲义标了「了解」，说明考频低。

## 二、文段内容的两大展开

### 1、单层次展开两式

#### 1）总分式：前宏观事物引入，后具体阐述一个事物（圈圈法）

**规则**：前面铺一个大的宏观面（「圈」），后面**收进一个具体的点**（圈里的那个点）。**落点在后面那个具体的点。**

- **例 3.12**：先讲各艺术门类的相互吸收借鉴（宏观圈）→ 后收进「古典名画想要真正'活'化，还需要借助**跨界融合**」（具体点）→ 选 C
- **例 3.13**：先讲不讲道理的话语逻辑（宏观）→ 后收进「作为受过良好教育的现代公民，当有这份**责任意识**」→ 选 C「公民在公共平台上应有**理性表达的义务**」
- **例 3.14**：先讲火山灰是什么（宏观）→ 后收进「**火山灰年代学**正是利用……」→ 选 B

#### 2）定义式：前摆出一个宏观定义，后具体事物符合这个定义

**规则**：前面给一个概念的定义，后面拿一个具体事物去**套这个定义**。**落点是「这个具体事物符合/不符合该定义」这个判断。**

- **例 3.15**：先给「习惯壁垒」的定义 → 后讲蚝油的玻璃瓶包装 → 选 B「蚝油的玻璃瓶包装具有**排他性**」（正是「习惯壁垒」的定义特征）

### 2、多层次展开四大设计（Cab 并列系列，重点必考）

> **关于「Cab」这个记号（我的推断 ⚠️）**：讲义没给定义。从四个设计的描述反推，**C 应指文段的总括句，a、b 指并列的各个层次**。下面按这个理解写。

#### 设计一：若 Cab 有文段自己写出来的总括时，可直接选择总括（标准格式）

**规则**：文段自己把「总」写出来了（通常带「因此 / 所以」），**直接选这个总括**。这是最省事的标准格式。

- **例 3.16**：讲制造业转移背景（a/b）→「**因此**，发达国家应该更多承担这部分额外排放的减排责任」→ 选 B
- **例 3.17**：西太平洋海山的地质/物理/生物三个价值（a/b/c）→「**因此**，海洋科学家可以在此开展……多学科协同探测与研究」→ 选 A
- **例 3.18**：`复原力` 需要储蓄（a）→ 童年是关键期（b）→ 三要素是构筑关键（c）→ 落点在「**童年**」→ 选 A
- **例 3.19**：太阳系各个位置元素分层（a/b/c）→ 落点「**太阳系中不同元素的分布情况**」→ 选 C

#### 设计二：若 Cab 没有文段总括时，可选择 a＋b

**规则**：文段没写总括，那就**把并列的几块合起来**当答案，即「a + b」。

- **例 3.20**：书院「是中国文化的象征」(a) + 「更是中国文化向域外传播的窗口」(b) → 选 B「书院所承载的**教育及文化传播功能**」（a+b 的合并）
- **例 3.21**：综艺节目「要追求艺术表达令人眼前一亮」(a) + 「也必须蕴含价值导向、承担社会责任」(b) → 选项是 a+b 的合并
- **例 3.22**：清洁能源汽车「有利于持续推进新能源汽车产业」(a) + 「有利于其他清洁能源多种技术路线并存」(b) → 选 a+b
- **例 3.23**：《新青年》更名后「重新定义了'新青年'概念」(a) + 「也让《新青年》有了更加精准的办刊定位」(b) →「巧妙处理」= D「借助事件传播，**创造全新概念**」

> **设计二补充：a＋b 有可能是完全无关的两段话，拼在一起（文段就讲两件事）**
> - **例 3.24**：「蚂蚁森林」满足植树尽责形式创新 + 实现义务植树专业化——两件事拼一起
> - **例 3.25**：外来词汇本土化（a）+ 「异域特征淡化后被当地人视为母语一部分」(b) → 选 C

#### 设计三：若 Cab 没有文段总括时，可并列提取共性

**规则**：没有总括，也不适合 a+b 直接拼，那就**从并列项里抽出一个共同点**。

- **例 3.26**：柴窑/汝窑/龙泉窑 → 共同点是「**青**」→ 选 B「**青色对瓷器审美意义非凡**」（这个共性不是文段写出来的，是抽出来的）
- **例 3.27**：「顶层设计」(a) + 「协同发展视角」(b) → 共性 = 都是**培育策略** → 选 A「我国工匠精神培育的**主要策略**」
- **例 3.28**：加强种质资源保护(a) + 完善创新链条提升产业化(b) → 共性 = 都在讲种业创新 → 选 A「打造种子这枚农业'**芯片**'」

#### 设计四：若 Cab 没有文段总括时，可自行总括

**规则**：文段没有总括，也不好抽共性，那就**自己给它下一个总括**——比设计三更主动、概括度更高。

- **例 3.29**：超大规模市场是「锚」(a) + 多样性带来内部稳定性(b) → 自行总括为「**超大规模市场有助于我国经济保持稳定**」→ 选 C
- **例 3.30**：北极(a) + 太空(b) + 网络空间(c) 三个博弈领域 → 自行总括为「**多领域成为军事博弈制高点**」
- **例 3.31**：交流互鉴 → 自行总括为最高层级 → 选 C「**交流互鉴，推动人类文明永续发展**」

> **四设计的递进关系（我的理解 ⚠️）**：
> 设计一 = 文段给总括，**抄**
> 设计二 = 文段没总括，**拼**（a+b）
> 设计三 = 拼不了，**抽**（共性）
> 设计四 = 抽不出，**自己写**（自拟总括）
>
> 这是**同一件事从易到难的四个台阶**，不是四个并列的题型。

### 3、CAB 的三点深层思考

#### 1）思考一：什么时候 CAB 也能只选 A 或者 B？

> 讲义原文结构：**其一：观点的偏向性（见前）／其二：／其三：**（后两个是空的，配了例 3.32、3.33、3.34、3.35、3.36、3.37）

**我的推断 ⚠️（把握低）**：当文段虽然并列了多层，但**观点明显偏向其中一层**时，就可以只选那一层，不必总括。

- **例 3.32**：徐光启/王国维/大师们（多层并列）→ 但偏向「交流」这一层 → 选 B「中国的学术发展**离不开交流**」
- **例 3.33**：广东 20 项政策 + 各地组合拳 + 102 家企业名单（多层）→ 偏向「减负暖企」→ 选 A 或 B
- **例 3.34**：宣传引导 + 样板房（两层）→ 落点在「**提升社会对适老化改造的思想认识**」→ 「这段文字强调要」= 思想认识
- **例 3.35**：老街改造 → 选 D「老街改造**不能抹掉情感记忆**」
- **例 3.36**：水熊虫 → 落点「生命力最强」→ 选「水熊虫的生命力」
- **例 3.37**：针灸铜人 → 选 C「针灸铜人：古代针灸教学的人体模型」

**「其一：观点的偏向性」是讲义指明的第一条**——即「偏向」决定能不能只选一层。

#### 2）思考二：当多种设计同时存在时，怎么取舍？

**一致时**：
- **例 3.38**：总括「全社会要形成抵制网络不良信息的'防火墙'」+ 后面「健全群众举报体系」「引导教育网民」「帮助提高道德修养」三层 → 总括和分层方向**一致** → 选 B「要**依靠群众力量**」（依总括）
- **例 3.39**：甲骨文/诗经/本草（多层文献）→ 一致指向「记载鱼」→ 选 A

**不一致时**：
- **例 3.40**：乡村旅游资金 → 「可通过整合财政资金」「可通过撬动金融资金」「还可通过 PPP、众筹」→ 选 D「发展乡村旅游急需推进**多渠道投融资**」（自拟总括）
- **例 3.41**：横线在开头，后文是「游戏要团队协作」「开发团队」「政府部门」「家长」三方并列举证 → 空格要填**总起句**（协同的力量）

**推断 ⚠️**：一致时优先文段总括；不一致时走自拟总括或 a+b。

#### 3）思考三：偏正、CAB 以及单层次展开三者之间是什么关系？

**我的推断 ⚠️（把握低）**：
- **单层次展开** = 只有一层，简单
- **偏正** = 有「偏」有「正」，正的一层是落点
- **CAB** = 多层并列，要处理「总」和「分」的关系

三者可能是**规模的递进**：单层次（一层）→ 偏正（两层，有主次）→ CAB（多层，并列 + 总括）。

- **例 3.42**：保护文物（多层理由）→ 选 D「**文物保护的深远意义**」
- **例 3.43**：豆浆不流行(a) + 保存难(b) → 合起来导致价格高 → 选 C「**剖析豆浆在美国市场上价格偏高的原因**」（a+b 指向同一个结果）

### 4、CAB 的两点易错设计

#### 1）极小点并列

**规则（推断 ⚠️）**：并列的某一项**太小、太细节**，不能因为它并列就把它当重点。**别把芝麻当西瓜。**

- **例 3.44**：讲数字经济顶层设计/形势研判/干部能力/全民素养 → 四项都是具体做法（极小点）→ 选 B「要把发展数字经济**自主权**牢牢掌握在自己手中」（拔高的那层）
- **例 3.45**：农业保险的作用(a) + 是国际惯例(b) + 现实选择与长远需要(c) → 不要停在中间的小点上 → 选 D「**发展农业保险是保障粮食安全的必选项**」

#### 2）盲目尾句重点

**规则**：**不要无脑选尾句。** 尾句可能是列举的最后一项，不是总括。

- **例 3.46**：北大西洋暖流 → 尾句「这股暖流为西欧带去大量热量，使得冬季的气温比同纬度的其他地区高出很多」→ 但这只是影响之一 → 选 C「**北大西洋暖流的成因与影响**」（要总括，不是尾句）
- **例 3.47**：日本核污水 → 尾句讲碳-14 基因损害持续数千年（细节）→ 选 A「**日本福岛核污水可能会损害人类的DNA**」（总括）

## 三、转折的剖析

### 1、强转折五类

**「好但问」等四类的命名法**：「但」字前后的**性质组合**。

#### 1）好但问（纯问题文段）

**前面说好，但字后转出问题 → 落点在问题。** 属「纯问题文段」。

- **例 3.48**：硼酸盐玻璃「在皮肤组织修复领域展现出巨大潜力」（好）→「**然而**，硼酸盐生物玻璃会释放大量碱性离子……抑制细胞增殖」（问题）→ 落点在问题
- **例 3.49**：「零结果」→「**然而**它们通常不会被发表。这不仅会导致科研效率低下，也显示当前的科学出版流程可能存在很大问题」（问题）→ 选 C「**反思忽视'零结果'的问题**」（我推的，待核）

#### 2）问但好

**前面说问题，但字后转出好处 → 落点在「好」。**

- **例 3.50**：馆阁体「限制了楷书的书写自由……这是它的局限」（问题）→「**但是**，作为一种官方使用的书体，它又具有别的书体不可替代的**实用价值**」→ 选 B
- **例 3.51**：海洋酸化 → 珍宝蟹受冲击（问题）→「**但**翼足类……可能会经历轻微的下降」+「海洋哺乳动物和海鸟**较少受**海洋酸化的影响」→ 选 D「**海洋酸化对海洋生物影响不大**」

#### 3）观但问（纯问题文段）

**前面给观点/背景，但字后转出问题 → 落点在问题。**

- **例 3.52**：回溯奶粉产业链 →「传统畜牧模式已成为中国奶粉发展最大的**掣肘**」→「而这需要……**难度比恢复奶粉信用还高**」→ 选 B「从生产模式上**变革困难重重**」

#### 4）问但观（以观解问）

**前面摆问题，但字后给出观点/对策 → 用观点去解释问题。**

- **例 3.53**：青藏高原冰川缩减、湖泊增加（问题）→「专家表示……'适应'始终是核心，**这就需要建立相应的预警体系**」（观点）→ 选 C「建立亚洲水塔灾害**监测预警体系势在必行**」

#### 5）前后表达相反

**「但/然而」前后是同一维度上的正反两说，落点在作者真正支持的那一边。**

- **例 3.54**：大学研究应做贡献（一方面）→「**然而**对于一种最好的教育来说，还存在着无法用美元或人民币衡量的**更重要的方面**」→ 落点在后者
- **例 3.55**：人的本质在于自由 →「**而**极权主义敌视个人和生活的个性……一句话，**消灭了自由**」→ 落点在后者

### 2、弱转折之尾句弱转（了解）

**规则**：「不过 / 其实」这类**弱转折**出现在尾句时，**一般不是重点**，只是补充说明。

- **例 3.56**：低度炎症 → 前面说「会缩短生命，促进许多年龄相关性症状」（重点）→ 尾句「**不过**，引起和维持这些变化的机制，目前尚不能明确」（弱转，不是重点）→ 选 B「**低度炎症的发生机制与影响**」（落点在前面的「影响」）
- **例 3.57**：唐花/温室技术 → 尾句「**不过**在汉代的时候更多是为了满足皇帝冬天吃蔬菜的需求」（弱转，补充）→ 选 C「我国古代已经出现了**实用的温室技术**」

> ⚠️ 注意：这条和第一章「顺承中的代指＋总结」里例 1.9 的处理**看起来矛盾**（例 1.9 我把「不过」句当成了落点）。**这两处的差别是我把握最低的地方**，请务必核对。

## 四、地位的感知

### 1、文段的地位感知——两者(多者)地位相当，反复联系

**规则**：文段里两个概念**地位平等**，且**反复互相联系**时，**两个都要**，不能只选一个。

- **例 3.58**：「学」和「习」两个概念地位相当、互相联系 → 选 C「《论语》中的'**学**''**习**'观」（两个都带上了）
- **例 3.59**：文化的**民族性**与**世界性**地位相当 + 反复联系 → 落点是两者的关系

### 2、选项的地位感知

**规则**：把「地位感知」用到选项上——**看选项本身有没有把两个地位相当的东西只说了半个**，说了半个的就是错的。

- **例 3.60**：古代技术（偶发）vs 近代技术（连续），两者对比 → 落点不在「区别」而在「跨越式发展」→ 选 A
- **例 3.61**：传统营销（漏斗效应）vs 网红营销（涟漪效应）→ 选 A「网红营销**影响巨大的原因**」

### 3、灵魂两问：好不好与行不行

**规则（推断 ⚠️，把握低）**：拿到选项问自己两句话——
- 「**好不好**」= 这个说法是在做**价值评价**吗？
- 「**行不行**」= 这个说法是在讲**能不能做成/做得到**吗？

**判断选项的表述类型和文段的落点类型是否匹配。**

- **例 3.62**：雅典民主经过多次改革逐渐完善 → 「**不是一蹴而就的**」（讲「行不行/过程」）→ 选 B
- **例 3.63**：影视旅游要保持「长红」，就要不断注入内容 → 选 A「影视旅游产业的持续发展**须以'内容为王'**」

## 五、对比的剖析

> 这一节最绕的是「古今时间对比」和「古今时间并列」的区分。讲义自己标注了两处「区分」，说明是易混点。

### 1、古今时间对比两式

#### 其一：过去现在型

**规则**：两个时间点，**「过去……而现在……」**，落点在**现在**（或由对比得出的变化结论）。

- **例 3.64**：「很长一段时间……**而如今**，类型文学海外传播则更注重市场需求」→ 选 D「中国文学海外传播的路径需要**与时俱进**」
- **例 3.65**：「新的技术或商业模式**刚出现时**……**现阶段**，消费者受惠主要体现在……**相信随着**'无人超市'遍地开花」→ 落点在未来 → 选 C「**将给消费者带来更多实惠**」

#### 其二：双点时间型

**规则**：也是两个时间点，但**两点之间是「条件变化」关系**——前一个时段是背景，后一个时段是**新条件触发的转变**。

- **例 3.66**：「**市场经济时期**，劳动密集型……工人被高度'去技能化'」→「**但是，当一个国家的产业结构向中高端迈进时**，高水平职业教育的支撑作用就会显现出来」→ 落点在后者

### 2、多点时间并列顺承（区分古今时间对比）

**规则**：**三个及以上**时间点，且是**顺着排下来**（唐以前→唐代→宋代→宋代之后），不是「对比」。

**落点看整体脉络，不落在最后一个点上。**

- **例 3.67**：唐以前 → 唐代 → 宋代 → 宋代之后，一路顺承讲海棠 → 选 B「**海棠在中国古典园艺史上的地位变迁**」
- **例 3.68**：古时候 → 现代 → 后来 → 如今，一路顺承讲加密 → 选 D「**信息加密的发展历程**」

### 3、古今时间并列（区分古今时间对比）

**规则（推断 ⚠️）**：**只有两个**时间点，但**两个都要**（并列），不是取其中一个。

- **例 3.69**：古代（画海蛇怪兽）vs 现如今（外太空拍照）→ 两个都要 → 选 B「**知识是治疗恐惧的良药**」
- **例 3.70**：中国传统不重视雕塑 + 今天收藏家心态不成熟 → 选 B「**高古石雕在中国不受重视的原因**」

> ⚠️ **这两组（2 和 3）与「1、古今时间对比」的区分是我把握最低的地方。** 我能看出的差别是：
> - **对比** = 两方是**对立/比较**关系，落点在一方或对比本身
> - **并列** = 两方**地位相当、都要**
> - **多点顺承** = 三点以上且是**时间轴推进**
>
> 这个区分把握低，请核对。

### 4、新旧事物对比

**规则**：**同类事物的新版本 vs 老版本**（不是时间上的古今，是**新旧事物本身**）。落点通常在**新事物**。

- **例 3.71**：机器学习易受干扰（旧问题）→「**近日**，'Data61'机器学习小组研发出了一种机器学习的新算法……帮助机器学习'修炼'出**抗干扰能力**」→ 选 B「**新算法助机器学习抵抗干扰**」
- **例 3.72**：传统理论（气候变化被迫直立行走）→「**一项最新研究则认为**……」→ 落点在新研究
- **例 3.73**：测量生物钟的常用方法（要坐暗室、抽血，麻烦）→「**目前，多国科研人员正尝试开发快速检测人体生物钟的新法**」→ 落点在新法

### 5、差异主体对比

**规则**：不是新旧，也不是古今，而是**两个不同的主体**做对比。落点在**差异所说明的那件事**。

- **例 3.74**：奥斯曼突厥人 vs 欧洲对手 → 奥斯曼善用新武器、有纪律 → 选 C「**奥斯曼帝国的军事力量遥遥领先于对手**」
- **例 3.75**：「南瞿北杨」——瞿家占地利但子孙未出仕；杨家父子进士、善鉴别 → 落点在**杨家的优势来源**
- **例 3.76**：鲁冰花原产美洲（悲苦）vs 台湾（护茶）→ 落点在「**鲁冰花成为母爱之花的缘由**」→ 选 A
- **例 3.77**：挪威加拿大重视森林核算 vs 我国强调森林/耕地/水资源 → 落点在**我国为什么这样选**（因为生态服务不能进口）

# 第四章 四大文段

讲义把中心理解常考的文段分成四类：**原因类、纯问题类、观点类、概括类**。先判类，再决定抓哪句——同一句话放在不同类文段里，地位完全不一样。

> ⚠️ 本章（以及第五章）原讲义**除标题和例题外没有印出任何讲解正文**，所以本文没有「原讲义原文」引用块，全部内容都是我按标题和例题倒推的。
>
> ⚠️ 原讲义在部分例题后印了一个百分数（推测是正确率），**讲义没说它指什么**。本书正文不逐题标注，全部汇总在书末「附录：讲义标注的百分数」里。

## 一、原因类文段

**规则（推断 ⚠️）**：问「为什么」的文段，先把**原因**和**结果**切清楚；答案落在原因上还是结果上，取决于它属于下面哪种设计。

### 1、四大设计

> 讲义只给了四个名字、没给定义。以下定义是我按例题倒推的，务必核对。

#### 1）因果阐明（最佳答案）

**规则（推断 ⚠️）**：选项**把因和果一起说出来**（「A 源于 B」「A 背后的 B」这种完整因果表述）的，是最佳答案。

- **例 4.1**：问答文化（因）→ 谜语诞生（果），末句「一切谜语文化都是从这里出发的」→ 选 C「谜语文化源于古老的问答文化」（我推的）
- **例 4.2**：南京改名「根本源头在于统治者的好恶」，再举徽州、严州、宁波 → 选 A「地名变迁背后的政治因素」（我推的）

💡 选项里同时有「完整的因果表述」和「只说原因」的，优选完整的那句。

#### 2）果的因（常见答案）

**规则（推断 ⚠️）**：结果已经在文段里说死了，一大半篇幅在解释**为什么**，答案就落在「原因」上——选项常常直接写成「……的原因」。

- **例 4.3**：皮肤老化（果）＋一个又一个原因（不规律饮食、微量元素不均衡）→ 选 C「皮肤老化的原因」（我推的）
- **例 4.4**：牛顿定律算不出三体运动 → 混沌 →「三体问题」浮出水面 → 选 B「'三体问题'产生的原因」（我推的）
- **例 4.5**：不准说上海话（因）→ 沪剧没观众、没人干、生态消失（果）→ 选 A「沪语不被重视的'后遗症'」（我推的，把握中低：B「分析了沪剧创演人才和观众消减的原因」也说得通，但覆盖面偏窄）
- **例 4.6**：咖啡因刺激蜜蜂蕈形体 → 记住采蜜地 → 离不开这种花蜜，问「标题」→ 选 C「蜜蜂为何'单恋一枝花'」（我推的）

💡 「果的因」和「因果阐明」的区别只在选项写法：一个写成「原因」，一个把因果揉成一句话。

#### 3）因果并列

**规则（推断 ⚠️）**：文段里因果**不止一条**（多个因、或多个果）时，答案要能装下这几条并列的因果，不能只抓其中一条。

- **例 4.7**：婴儿超重 ↔ 肠道菌群不同；消毒剂多 → 毛螺菌多 → 热量多 → 发胖 → 选 A「揭示家庭消毒剂与婴儿体重的关系」（我推的）
- **例 4.8**：大脑进化出合作功能 → 群体竞争 → 利他意识、伦理观、良知、尊严 → 选 B「大脑在群体生活中的进化可以激发美德」（我推的）

💡 只覆盖其中一条因果的选项，是这一类的标准陷阱。

#### 4）果因单论（结果一定重要）

**规则（推断 ⚠️）**：整段只讲**一组**因果时，后面那一大段对原因的展开只是展开，**结果本身一定在答案里**——别被篇幅带偏。

- **例 4.9**：中微子数量极多，但人类研究开始较晚（结果），原因是自由来去、极难探测（后面整段都在展开原因）→ 选 B「人类对于中微子的研究开始得比较晚」（我推的，**把握低**：若按「篇幅落在哪就选哪」读，D「中微子的存在很难被感知或探测」也成立）

💡 这一条是提醒「别被大篇幅的原因描述带走」，不是让你去数句子多少。

### 2、两大特殊题型

#### 1）多因多果

**规则（推断 ⚠️）**：原因和结果都不止一个，正确选项要**把多个因和多个果都框进去**。

- **例 4.10**：近代上海人口规模大、人口异质程度高（两因）→ 创新速率高（果）→ 选 D「近代上海创新能力强与人口规模大、人口异质程度高有关」（我推的）
- **例 4.11**：「有偏见的暴露效应」→ 觉得当下道德水平低；「有偏见的记忆效应」→ 觉得过去道德水平高（两组因果）→ 选 A「'世风日下'可能是一种群体心理错觉」（我推的）

#### 2）小篇幅原因

**规则（推断 ⚠️，把握低）**：原因只在**结尾一小句**带过时，它不是重点，重点仍在前面大篇幅讲的内容。

- **例 4.12**：唐代女着男装打破性别界限、颠覆礼法规则（大篇幅讲意义），末句才补一句原因（外来文化尝鲜＋女子地位上升）→ 选 A「剖析唐代盛行女着男装的意义」（我推的）

### 3、两大实用技巧

#### 1）借助选项（重要）

**规则（推断 ⚠️）**：文段看不出落点时，**先看选项给了哪几个方向**（原因／对策／必要性……），再回文段对号——文段没给对策，就排除对策项。

- **例 4.14**：智慧城市停在信息系统建设、迈不进整合利用阶段，根源在「数据孤岛」→ 文段只讲了问题和根源，没讲怎么办 → 选 B「智慧城市发展缓慢的原因」（我推的；C「各企业、单位应积极打破'数据孤岛'」、D「如何破除……」都是文段没给的对策）

#### 2）抓准原因结果，对比择优

**规则（推断 ⚠️）**：选项里同时出现「只说因」「只说果」「因果都沾」的，逐个回文段比对，选覆盖最准的那一个。

- **例 4.15**：基因突变（因）→ 一方面更聪明，另一方面阿尔茨海默更复杂难解 → 选 D「阿尔茨海默症与基因突变的关系」（我推的）
- **例 4.16**：夕兽传说 → 贴春联放爆竹 → 年三十便叫除夕 → 选 A「介绍除夕的来历」（我推的）
- **例 4.17**：买难卖难、果贱伤农（果）← 价格背离价值 ← 线下渠道环节过多（因）→ 选 D「'果贱伤农'的根本原因在于销售环节过多」（我推的）
- **例 4.18**：水熊顽强 → DNA 混合体 → 还发现一组特殊蛋白质 →「致使这种动物接近于不可毁灭状态」→ 选 C「水熊拥有神秘 DNA 使它接近于不可毁灭」（我推的，**把握低**：严格按原文，让水熊「接近于不可毁灭」的是蛋白质，D 更贴字面但只覆盖局部）

### 4、两大思考

#### 1）观点类和原因类文段的思考

**规则（推断 ⚠️）**：同样是「因为……」，如果它是为**前面的观点**做支撑，落点在观点；如果它自己就是文段要解释的对象，落点在原因。分辨看「因为」前面有没有站着一个已经说完的观点。

- **例 4.19**：「更有效的方式是加强药品生产、使用和废气的管理」（观点），后面「因为药品一旦进入环境……」（用因果撑观点）→ 选 B「药品环境污染前端管理胜于末端治理」（我推的）
- **例 4.20**：登陆火星难 → 需借地球公转「甩」过去 → 需要合适时机＝「发射窗口」→ 全篇在解释为什么 → 选 D「解释要抓住窗口期发射火星探测器的原因」（我推的）

#### 2）原因类文段的破坏

**规则（推断 ⚠️）**：文段一层层追原因，追到根上后**突然给出对策**——对策把原因盖掉了，落点是对策那一句。

- **例 4.21**：为什么租赁市场滞后 → 需求不旺 → 租购不同权 →「对症施策，就是在法律上明确规定'租购同权'」→ 选 B「需要规定'租购同权'的原因」（我推的；A/C/D 都是被"破坏"掉的原因项）

## 二、纯问题类文段

### 1、总括问题

**规则（推断 ⚠️）**：文段通篇在说「有什么毛病」，答案就是**把这些毛病总括起来**的那句，别去选项里找对策。

- **例 4.22**：观众群减少、剧目创作萎缩、优秀演员流失、生存艰难，近年好转但仍旧弱势 → 选 A「传统戏曲面临的生存困境」（我推的）

### 2、合理、精简解决问题

**规则（推断 ⚠️）**：文段摆完问题后，正确选项给的是一个**能对上问题、又不啰嗦**的对策。

### 1、以观解问

**规则（推断 ⚠️）**：文段先抛一个**问题/质疑**，再用**观点**去解答它——落点在那个观点上，不在问题上。

### 补充思维：出题人最爱的出题逻辑

**规则（推断 ⚠️）**：**转折之后给对策**——前半铺成绩／背景，后半「但／然而／因此」一转，落点就在那句对策上。

### 2、表达观点

**规则（推断 ⚠️）**：文段本身就是作者在表态（「必须」「不应」「我们当……」），答案就是**他表的那句态**，不是他引的事实。

# 第五章 重点内容补充

## 一、例子的剖析

### 1、例子的三大判定特征

**规则（推断 ⚠️）**：文段里怎么认出「例子」？看三个标志：**短、多、如**。认出例子，就知道它是佐证，不是重点。

#### 1）短

**规则（推断 ⚠️）**：一段议论里突然插进来一个**很短**的具体事例，它就是例子。

- **例 5.1**：前文讲传统文化应对不灵活、缺乏创新能力，末尾插一句「《花木兰》的故事被美国人拿去拍成动画片，影响跨越国界，就充分显示了民间传统文化创新的魅力」→ 选 B「保护传统文化的关键是文化创新」（我推的）

#### 2）多

**规则（推断 ⚠️）**：**好几个并列的、同类的**事例堆在一起，它们是例子，重点在它们共同指向的那句总的表述上。

- **例 5.2**：首句「交流互鉴是人类社会进步的标识，是文明发展的尺度」，后面丝路、茶叶之路、香料之路、「一带一路」等一串事例 → 选 C「交流互鉴，推动人类文明永续发展」（我推的）
- **例 5.3**：怀旧音乐综艺扎堆、年轻人听歌进「考古」岁月、老歌重进大众曲库（几个并列现象）→ 落点「经典的滚石、宝丽金时代的老歌，越来越被年轻歌迷所认识和了解」→ 选 D（我推的）

#### 3）如

**规则（推断 ⚠️）**：出现「比如／再比如／以……为例／……也不例外」这类标志，**后面就是例子**，答案在前面那句观点上，不在例子里。

- **例 5.4**：首句「科学的发展总带给人类崭新的思维方式」＋「比如，在大数据背景下……」「再比如……超弦理论……」→ 选 D「科学之光点亮思维」（我推的）
- **例 5.5**：首句「量化历史研究的一部分工作，就是找到合适的量来反映过去」＋「比如身高数据恰好可以……承担起这样的角色」→ 选 C「量化历史研究如何选取恰当的参量」（我推的，把握中低：D「身高数据'冻结'了社会经济状况」是例子里的句子，标准陷阱）
- **例 5.6**：首句「如何让它们'活'起来是值得思考的话题」＋观点「依托更生活化的载体、借助灵动的设计'活'在当下」＋「故宫文创产品就是最好的印证」→ 选 A「要让文化遗产'活'在当下」（我推的）
- **例 5.7**：首句观点「原始体育的萌芽与日复一日地生产劳动分不开，跳绳运动也不例外」，后面整段讲跳绳（编绳索的起源故事＋汉代画像石、南宋《荆楚岁时记》）→ 选 D「原始体育起源于生产劳动」（我推的，**把握低**：后半段大篇幅在讲跳绳的史料，按「内容在哪就选哪」读会选 B「跳绳运动的悠久历史」）

### 2、例子的论证作用

**规则（推断 ⚠️）**：例子只为**证明**一个东西而来；问「以……为例是为了说明」，答案一定是例子**要撑的那个观点**，不是例子本身的内容。

- **例 5.8**：「跑完一场马，爱上一座城」是所有城市办马拉松的出发点和落脚点＋以天津马拉松为例（地标、赛道）→「这是绝佳的展示文化和魅力、营销城市的机会和方式」→ 选 A「举办马拉松赛事有助于城市营销和推广」（我推的）

### 3、例子的特殊情况

**规则（推断 ⚠️）**：例子**本身成了文段的重点**——「以……为例」之后用「然而」一转，观点落在了这个例子上，这时要抓的是这个例子的情况，不是它原本要佐证的大观点。

- **例 5.9**：前面说人类一直想找抗衰老药，「以干细胞抗衰老疗法为例」……「然而科研人员提醒，虽然干细胞疗法在动物实验中表现出一定的治疗效果，但对于人类而言，还需要等待临床试验结果」＋「干细胞目前还无法同时针对所有组织细胞发挥治疗或起到延缓衰老的作用」→ 选 B「干细胞治疗用于延缓衰老还有许多问题」（我推的，把握中低：D「当前干细胞的抗衰老研究仍处于实验探索阶段」只对上了前半句）

## 三、脉络的省略性

**规则（推断 ⚠️，把握低）**：文段的铺垫环节被**省掉**了，句子是「跳着」走的——从甲主体直接跳到乙主体、从具体直接跳到宏观，中间的过渡句不写出来。落点通常就在**跳过去之后的新主体**上；不自己补上省掉的那一环，就容易把中间某一环当成重点。

### 1、确定首句

**规则（推断 ⚠️）**：首句要挑「能当门的那句」——引出话题、下定义、交代时间背景的句子。反面是带**指代词**（这、这些、他们、该）和**关联词**（因此、但是、而、也、与此同时）的句子：它们必须有上文，当不了第一句。

- **例 1.1**：③「有趣的是」、④「而」、⑤「这主要」、⑥「这是因为」都不能开头 → 首句只能是 ②（仰望星空，辨恒星行星）→ ②（闪烁的是恒星）→ ⑥（这是因为…）→ ④（而…行星近、折射少）→ ③（有趣的是…行星更亮）→ ⑤（这主要与视距离有关）→ ①（亮度与光的强度成正比）。（选 A，我推的）
- **例 1.2**：① 是「1994 年…发现」的具体事件，⑤ 是「计算可以理解为…」的定义 → 首句 ⑤ → ⑤ 定义计算 → ③ 乘法不难 → ⑥ 反过来分解难 → ② 于是认为本质很难 → ④ 计算困难成了现代密码学的基础 → ① 1994 年量子计算机打破它。（选 B，我推的）
- **例 1.3**：⑥ 是景物描写（人得先在外面才看得见），④「受不了家里的闷热，我决定出去看看」才是开头 → ④ 出门 → ① 一出门的所见 → ③ 夏夜凉爽 → ⑥ 天空挂着弯月 → ⑤ 不像中秋的月亮 → ② 月光倾泻。（选 C，我推的）
- **例 1.4**：②「倘若…的话」不能开头 → 首句在 ②／④ 里选 ④（20 世纪 70 年代，一位澳大利亚科学家）→ ④ → ③ 他进一步测量找到声源 → ① 另一位加拿大科学家发现响声与缺水程度相关 → ⑤ 但当时无法解释 → ② 倘若是有意为之，令人惊叹。（选 D，我推的）

💡 首句三件套：**指代词开头的不要、关联词开头的不要、只有具体细节的不要**。剩下的那句就是开头。

### 2、内容衔接

**规则（推断 ⚠️）**：首句定下来以后，剩下的句子靠**句与句之间的粘合点**来串——指代词找它指的那个词（这、这些、他们），关联词找它成对的那一句（因此／但是／而／也／与此同时），例证句跟着被证明的那句，定义句跟着被定义的那句。**粘得最紧的那一组先钉死，再往两边接。**

- **例 1.5**：⑥ 总说能量靠脂肪 → ② 距离越远耗脂越多 → ④ 飞越沙漠大海的需存脂更多（具体化）→ ⑤ 举数据（积累 50%、减重 44%）→ ③ 因此食物充足极为重要 → ① 有的鸟就因食物缺乏夭折。（选 A，我推的）
- **例 1.6**：① 原先照着惯例摹写、有固定理解模式 → ⑥「这一模式」指的就是它 → ④ 1984／1985 年被视为新小说元年 → ⑤ 1985 年前后改观，照自己理解的文学图式写 → ③「这种所谓的文学图式」承接 ⑤ → ②「总之」收尾。（选 D，我推的）
- **例 1.7**：② 数字技术降低成本、促进数据价值发掘 → ⑥ 数据资源扩散到各领域、成为新的关键生产要素 → ④ 设备联网，生产对数据依赖上升 → ①「也」承接 ④（科技发展、创新同样依赖科学数据）→ ⑤ 数据成为战略资源、影响一国竞争优势 → ③「与此同时」承接 ⑤。（选 B，我推的）
- **例 1.8**：⑥ 摊贩是城市商业的组成部分，要同时破解「几难」→ ① 摊贩有生存需求，但占道噪声等问题亟待破解（「几难」展开）→ ③「如何求取最大公约数?」→ ⑤ 实践告诉我们，倾听百姓心声、统筹兼顾很关键 → ② 事实上许多城市的管理都走过从禁到放的过程 → ④ 结合城市发展和百姓需求实际，引导依法依规经营，是题中应有之义。（选 D，我推的）

### 2、某一主体可以拆分为多个部分，先部分定义，再整体定义

**规则（推断 ⚠️）**：主体不止一层时（大概念套小概念、一个词有两种含义），**定义句成组地排在前面**，先交代清楚再往下讲特征和后果。

- **例 1.16**：⑤ 先定义「生态」（不断发展演进的系统）→ ② 再定义「生态红线」（生态平衡被打破的临界状态，定义里用到了 ⑤ 的「生态系统」，所以 ⑤ 必在 ② 前）→ ④ 生态红线是保证生态安全的底线，有约束性强制性 → ③ 在红线面前破坏行为必须停止 → ⑥ 一旦突破，再投入人力财力也难恢复 → ①「因此」生态红线不能触碰。（选 D，我推的）
- **例 1.17**：⑤ 总说「我们通常所说的音准，一般有两种含义」→ ⑥ 第一种：音高的准确性，即音准 → ②「这种音准」承接 ⑥，说它有精确的物理意义 → ④「而在音乐中使用的音」接着说 → ③「另一种音准」指的是听力反应，应叫「音准感」→ ① 人们听音依靠的就是「音准感」。（选 D，我推的）

⚠️ 标题原文写的是「先部分定义，再整体定义」，但上面两道例题的顺序看起来是**先给大的／总说的那句下定义，再给具体的那个下定义**（例 1.16：生态 → 生态红线；例 1.17：总说两种含义 → 分说第一种）。标题和例题的对应关系我拿不准（**把握低**），以课上讲的为准，见文末待核。

## 一、尾句引出新主体

**规则（推断 ⚠️）**：下文推断看**尾句有没有冒出一个前面没讲过的新主体**。冒出来了 → 接下来就讲这个新主体，而不是接着讲整段的老话题。

## 二、话题思维

### 1、注重逻辑性和时间性

**规则（推断 ⚠️）**：下文要接的是文段**逻辑链上还没走完的那一步**（摆出现象→讲原因；说到瓶颈→讲瓶颈是什么；给出时间线→按时间往下走）。既不跳步，也不往回退。

**规则（推断 ⚠️）**：文段里**自己悬着没答的东西**（设问、悬念、摆出来的怪现象），就是下文要回答的东西。问什么答什么。

- **例 2.11**：新规明令排除非法证据 → 尾句「这类证据犹如顽固的牛皮癣，禁而不止、杜而不绝」→ 下文接非法证据为何无法严格排除。（选 A，我推的）

💡 找**文段欠着没交代**的那件事：一个问句、一个「为什么」、一个只报了结果没报过程的实验。

**规则（推断 ⚠️）**：尾句落在「问题／挑战」上时，下文顺着问题给应对——**怎么办**。

# 第三章 细节判断

> **本章讲义状态**：和全书一样是学生版——**没有一句印出来的正文**，只有节标题和例题。「一、正确答案特征」这一节连例题都没有，只有标题。
>
> **关于节号**：讲义印的是「一、正确答案特征 / **一**、常见错误 / 二、特殊题型」。按内容看，中间那节「常见错误」应为「**二**、常见错误」，后面的「特殊题型」顺延为**三**。本文件按 一 / 二 / 三 写。

## 一、正确答案特征

> 这一节讲义只有标题，没有任何例题，正文无法从讲义反推。下面三条是通用规律，**全部是我的推断（把握中低）**，不是讲义内容。

**规则（推断 ⚠️）：细节判断问的是「说法与原文是否一致」，不是「哪句是重点」。所以正确答案的第一特征是——它在原文里找得到依据，而不在于它重不重要。**

**规则（推断 ⚠️）：正确答案多为「同义替换 / 概括表述」，很少照抄原句。照抄原句的选项，往往偷换了一两个字（见下面八种错误）。**

**规则（推断 ⚠️）：表述留有余地的选项（可能、往往、一般、部分、有助于）比绝对表述（一定、只有、才能、都）更可能是答案——八种错误里「绝对化」是高频设错点。**

💡 一句话：**细节判断是「对答案」，不是「找重点」。选项回原文逐字对，对不上就错。**

> 选是题（「正确的是」）与选非题（「不符合文意的是」）问法不同，答案方向相反；讲义例题里两种都有，做题先看清问法。

## 二、常见错误

八种设错方式。讲义每一节只印出「体现了该错误的那个选项」，其余选项大多没印——**所以下面很多题的答案我推不出来，只能指出讲义印的那项错在哪**。

### 1、偷换时态

**规则：把原文的「未然 / 将然」说成「已然」，或反过来。信号：原文「有望 / 将 / 计划」，选项「已 / 已经 / 了 / 正在」。**

- **例 3.1**：原文「**有望为将来**实现猪—人器官移植铺平道路」→ 讲义印 C「猪-人器官移植**已开始**发展起来」，把「将来」说成「已」→ 问「无法推出的是」，**选 C，我推的**
- **例 3.2**：原文「新型锂电池**有望**广泛用于笔记本电脑、手机等电子产品」→ 讲义印 C「新型锂电池**已广泛使用**于手机等电子产品」，同一手法。但这题问「可以知道」，**C 是干扰项不是答案**；讲义没印其他选项，答案我推不出
- **例 3.3**：原文「**将**委托专业金融机构对中国女足发展基金进行管理和运作」→ 讲义印 D「**已确定**了管理机制和运作规则」→ 问「不符合文意的是」，**选 D，我推的**

💡 扫选项里带「已经 / 已 / 了」的，先回原文看那句是「还未发生」还是「已发生」。

> **一条可复用的规律（我从本章例题归纳，推断 ⚠️，请核对）**：题干问「无法推出 / 不符合 / 错误的是」时，讲义印出来的错误项**就是答案**；题干问「可以知道 / 正确的是」时，讲义印出来的错误项**是干扰项、不是答案**。本章下面我按这条处理。

### 2、偷换概念

**规则：把原文的 A 概念换成表面相近的 B 概念——主体、对象、原因、属性被换掉。**

- **例 3.4**（四选项全印）：原文只说 COL17A1 的表达受**年龄**和应激（氧化、紫外线）影响 → A 印成「**年龄与性别**因素都会影响」（凭空多出「性别」）；B 把高低说反；C 把「紫外线会使其下降」推成「防晒措施能**提高**」→ 我选 D「COL17A1 的表达水平与皮肤组织的老化程度**负相关**」，与原文「表达水平下降，皮肤随之老化」吻合（**选 D，我推的**）
- **例 3.5**：乡下孩子认字认不过，原文给的原因是「我的孩子**并没有机会练习**」→ 讲义印 C「乡下孩子们对捉蚂蚱熟练，而对**文字的兴趣不浓**」，把「没机会」偷换成「没兴趣」→ 问「错误的是」，**选 C，我推的**
- **例 3.6**：原文讲西方工业革命带动的新兴产业波及东南亚殖民地、刺激劳动力需求 → 讲义印 B「华人廉价劳工移民东南亚**主要从事**工业革命以来的**新兴产业**」，原文没有这层职业信息 → 问「与文意不符的是」，**选 B，我推的**

💡 概念被偷换时，选项单看很通顺，一定要回原文确认「原文说的是不是这个主体 / 这个原因」。

### 3、偷换范围

**规则：把「局部」说成「整体」，把「一部分」说成「全部」。信号：选项里出现「全 / 都 / 各地 / 整体」，而原文只讲了其中一块。**

- **例 3.7**：原文「这对中国网络文化**抓住**中国技术领先契机、『引领全球文化』具有划时代的历史意义」→ 讲义印 B「5G 时代中国**引领**全球文化」，把「契机 / 意义」说成「已引领」→ 问「错误的是」，**选 B，我推的**
- **例 3.8**：原文「濒临式微的广播业……得以在**交通广播领域**施展拳脚」→ 讲义印 B「广播业因堵车而**重新焕发生机**」，把「交通广播这一块」放大成「整个广播业」→ 问「不可以得出」，**选 B，我推的**

💡 例 3.7 也能归到「偷换时态」，例 3.8 也能叫「以偏概全」——**八种错误不是互斥的，同一选项常能命中两三种**，分类只是帮你看清设错手法。

### 4、偷换逻辑

**规则：改掉原文句子之间的逻辑关系——必要条件说成充分条件（只有……才 ↔ 只要……就）、把「有助于 / 可以」说成「才能」、把因果倒过来推。**

- **例 3.9**（讲义同时印了 B、D 两项）
  - 原文：「保存动植物遗体的**必要条件**是快速掩埋」「生长在水中或水边的动植物的遗体是最易被保存下来的」
  - 讲义印 B「**只有**生长在水中或水边的动植物的遗体**才能**被保存下来」→ 把「最易」改成「唯一」
  - 讲义印 D「**只要**被快速掩埋，动植物遗体**就能**被保存」→ 把必要条件改成充分条件
  - 两项都是逻辑偷换。题目问「不正确的是」，**但两项都错，我判断不出答案是 B 还是 D**（也可能讲义印漏了题干，或本题是多选）→ 见章末待核
- **例 3.10**：原文「可以分析火星形成的历史，**以增加**人类对地球、月亮等星球起源的了解」→ 讲义印 D「通过研究火星地震**才能**了解月亮起源」，把「有助于了解」改成「才能了解」→ 问「与这段文字意思相符的是」，**D 是干扰项不是答案**；其余选项未印，答案我推不出
- **例 3.11**：原文「其他能够专注于工作的人士，同样也可获得长寿」→ 讲义印 B「长寿者多是善于集中注意力的人」，把「专注 → 长寿」倒成「长寿 → 专注」→ 问「与原文相符的是」，**B 是干扰项**，答案我推不出

💡 只盯三组词：**「只有 / 只要」「才能 / 就能」「因此 / 因为」**。这几个一换，逻辑就变了。

### 5、强加对比

**规则：原文只分别说了 A 和 B 的情况，从没比过；选项硬造一个「A 比 B 更……」的结论。**

- **例 3.12**：原文「可通过行为治疗**或**刺激性药物改善症状」→ 讲义印 C「行为治疗**比**药物治疗**效果更好**」，原文没有这层比较 → 问「相符的是」，**C 是干扰项**，答案我推不出
- **例 3.13**：原文「唐代留存了很多掌故类笔记，宋代则**更多**……到了明代，沈德符的《万历野获编》**很有名**」→ 讲义印 A「宋代比唐代多，明代**又比宋代多**」，明代那句只说了「有名」，推不出「又多」→ 问「不符合原文意思的是」，**选 A，我推的**
- **例 3.14**：原文「婴儿有**大量**褐色脂肪来保暖，褐色脂肪多的成年人也更苗条」→ 讲义印 D「婴儿体内的褐色脂肪**更多**」。这题我卡住了：**原文本来就写了婴儿褐色脂肪多，D 与原文并不冲突**，所以 D 若是答案逻辑上说不通 → 答案存疑，见章末待核

💡 看见选项里出现「比 / 更 / 相比 / 不如」，回原文找有没有真的比较过。

> 例 3.14 的问法是「下列在文中**没有提及**的是」，其实是「有无提及」型（见下文三、1），却排在「强加对比」下面——**这处归属我存疑**，见章末待核。

### 6、绝对化

**规则：把原文留了余地的话说死。信号：选项里的「一定 / 必然 / 都 / 完全 / 就能 / 最高 / 唯一 / 只要……就」。**

- **例 3.15**：原文对不可控环境是「善于正确对待，**尽量**避免它对事物的消极影响」，对**可控**环境才「大胆**改造**」→ 讲义印 D「对**不可控**环境因素的**改造**能够**避免**它们对事物的消极影响」，对象换错 + 「避免」说死 → 问「不相符的是」，**选 D，我推的**
- **例 3.16**：原文只说那个时代的瑞典科学院对以思想实验为主的相对论「**持保留意见**」→ 讲义印 A「狭义相对论代表了思想实验的**最高成就**」，原文全无此意 → 问「不能推知」，**选 A，我推的**
- **例 3.17**：原文说当众羞辱会「培养」学生的自卑、仇恨甚至社会攻击倾向 → 讲义印 C「学生有了自卑，仇恨甚至社会攻击倾向，**就会走向犯罪**」，原文没提犯罪 → 问「理解不当的一项是」，**选 C，我推的**

💡 「绝对化」和「无中生有」经常一起出现（例 3.16 的「最高成就」两样都占），不必分太清，**认出「说得太满」就够**。

### 7、语义相悖

**规则：选项不是偷换，而是和原文说反了、主体搞错了——最直白的一种，但长选项里最容易漏看。**

- **例 3.18**：原文「根据不同食材、不同季节为不同舌尖找到味觉的最佳刻度，这是**厨房**的乐趣」→ 讲义印 D「品尝因地制宜因季而为的美食是**食客**的乐趣」，主体从「厨房」换成「食客」→ 问「不符合文意的是」，**选 D，我推的**
- **例 3.19**：原文「锿-254 会衰变为锫-250，**后者会发射有害的伽马射线**」→ 讲义印 C「锿-254 在衰变后**不再**发射有害的伽马射线」，与原文相悖 → 问「与文段不相符的是」，**选 C，我推的**
- **例 3.20**：原文「有了**真情**的贯注，那么语言和作品就都有了……可以抵御时光而**历久弥新**」→ 讲义印 C「语言的真义**在于历久弥新**」，把「真情」换成「历久弥新」（原文的真义是「情者文之经」）→ 问「与文意不符的是」，**选 C，我推的**

💡 例 3.19 的坑在主语链：**锿-254 → 锫-250 → 发射伽马射线**，选项把中间一环省掉，就成了「不发射」。长选项要顺着链条走一遍。

### 8、无中生有

**规则：原文根本没有的信息，选项里凭空长出来——多一个原因、多一个结果、多一个比较对象。**

- **例 3.21**：原文「两汉时期，分餐制得到了**很好的传承**」→ 讲义印 B「分餐制在两汉时期得到了**全国推广和普及**」，原文无「全国 / 推广 / 普及」→ 问「理解正确的是」，**B 是干扰项**，答案我推不出
- **例 3.22**：原文说该设备「能清晰地记录**初级神经元的内部活动**」，「**精神修复术**」只是应用领域 → 讲义印 B「该设备能够清晰记录**细胞神经的修复活动**」，把两处拼成原文没有的说法 → 问「正确的是」，**B 是干扰项**，答案我推不出
- **例 3.23**：原文「各大游戏厂商纷纷加大网游**出海**业务布局」→ 讲义印 C「越来越多企业选择**跨行业加入**网络游戏市场」，原文无「跨行业」→ 问「理解正确的是」，**C 是干扰项**，答案我推不出

💡 无中生有的选项往往「听着很对、很符合常识」——正因为符合常识，才要警惕它可能不是原文说的。

## 三、特殊题型

### 1、有无提及

**规则（推断 ⚠️）：题干问「没有提及 / 没有提到的是」。做法是把选项给的那几个「维度词」逐个回原文扫一遍，四项里三项都能找到对应，找不到的那项就是答案。**

- **例 3.24**：选项维度＝特殊性能 / 科学原理 / 功能缺陷 / 应用前景。原文有原理（氢键、共价键、「分子绳」）、有性能（透明坚韧、受拉力出现网状纹路、拉力消失恢复原状）、有前景（军用装备轮胎）→ 没提「**功能缺陷**」→ **选 C，我推的**
- **例 3.25**：选项维度＝分类 / 功能 / 材质 / 结构。原文有结构（内中外三层）、材质（方解石、角质层、文石）、功能（御寒、防热、避敌害）→ 没提「**分类**」→ **选 A，我推的**
- **例 3.26**：选项维度＝山峰的形态 / 峰顶的松柏 / 岩峰的走向 / 山壑与山涧。原文有形态（青筋裸露、直插霄汉）、松柏（亭亭如盖）、山壑山涧（曲壑蟠涧）→ 没提「**走向**」→ **选 C，我推的**
- **例 3.27**：题干限定「关于『耕地保护制度』的**意义**」。原文有：划定基本农田保证播种面积（→ 保障粮食安全）、严禁建设项目占用基本农田（→ 遏制基建扩张）、提升耕地质量 / 剥离再利用（→ 可持续）→ 没提农药化肥 → **选 A，我推的**

💡 关键动作是**先看选项给了哪几个维度**，再带着维度回原文扫，比通读全文快得多。

### 2、难题的对比择优

**规则（推断 ⚠️，把握中低）：几个选项都没有明显硬错时，不再找「错」，而是比「谁在原文里的依据更足」。依据最薄、延伸最多、最像常识补白的那个，就是错的。**

- **例 3.28**：原文王孙满答楚王「周德虽衰，**天命未改**，鼎之轻重，**未可问也**」→ 四个选项里只有 C「王孙满认为楚庄王**不应当**问鼎之轻重」直接对应「未可问也」（**选 C，我推的**）。A 把「天命未改」读成「周王室依然强大」；B、D 都是往作者 / 《左传》身上加的推断，依据都更薄
- **例 3.29**：原文「一个地区物质的贫困，**往往**与其精神的贫乏、文化的落后息息相关」→ A「亟需精神扶贫」、B「出现了双重贫困」、D「有必要从文化层面重建」都还能从这句推；C「与**硬件建设**相比，流动在硬件背后的『**文化流**』**更为重要**」引入了原文没有的对比对象和「更为重要」的判断（**选 C，我推的；把握低**）
- **例 3.30**：原文「能够在**条件适宜的城市**促进纯电动出租车的推广」→ A「换电模式的应用有利于电动出租车在**全国**的推行」把范围放大（**选 A，我推的**）。B / C / D 都能在原文找到对应句

💡 择优题的信号词是**范围词和程度词**：「全国 / 都 / 更为 / 最」。

### 3、细节中心化

**规则（推断 ⚠️，把握低）：「中心化」我理解为——文段本身没有一句现成的观点句，是围绕一个对象铺开说的；这时正确答案是那个**能统辖全段**的选项，只覆盖某一个细节的选项都是干扰项。**

- **例 3.31**：全段都在说捆扎蔬菜的胶带「风险极小」（释出大量甲醛可能性极小、动物胶植物胶无害、每日不超过 12 毫克无影响）→ A「食用了胶带捆扎的蔬菜影响健康的**概率小**」是能统辖全段的表述（**选 A，我推的**）。B「**并不**产生甲醛」、C「**才**不会对人体造成危害」、D「**只应**摄入 12 毫克」都是把某个细节说死
- **例 3.32**：出土物来自西亚、中国、泰国等多地 → C「阿尔马塔夫是古代亚欧文化艺术交流的**集散地**」是统辖全段的表述（**选 C，我推的**）。A「最具地方特色」、B「明初已存在**频繁的官方往来**」、D「**繁荣发达**」在原文都没有依据

💡 这类题的问法还是「正确的是 / 可以推出」，但**做法是「找能盖住全段的那句」，不是逐字对**——和前面八种错误的路子正好相反。

### 4、细节判断和中心理解的题型识别

**规则（推断 ⚠️）：看问法分。问「符合 / 不符合文意」「可以推出 / 不能推出」「没有提及」→ 细节判断，回原文逐项对；问「主要说明 / 意在强调 / 主旨 / 概括最准确」→ 中心理解，找观点。**

**两类混血题（推断 ⚠️，本节最该注意的地方）：**
1. **问法像中心理解，实为细节判断**（例 3.35）
2. **问法像细节判断，却要答中心**（例 3.31、3.32，即上面的「细节中心化」）

# 第一章、四大契合

**本章主旨（推断 ⚠️）**：「契合」＝所填词要和语境给出的某个维度对上。四个维度就是四节：解释说明、具体展开、主谓宾性质、比喻。先判断横线该跟哪个维度对齐，再去选项里找对得上的。

## 一、契合解释说明

**规则（推断 ⚠️）**：横线后面常跟着「比如 / 例如 / 就好像 / 再如」引出的举例，**举例就是对横线的解释**——把例子里反复出现的那个意思抽出来，就是答案。

- **例 1.1**：「孩子从书中获得什么，也不是______的，比如……**立刻**就会写作文了」→ 例子落在「立刻」→ 选 A 立竿见影（我推的）
- **例 1.2**：「这些发现看上去高深而______，**却**在某些方面改变了未来」→「却」提示前面是「离生活远」→ 选 A 遥远（我推的）（把握低）
- **例 1.3**：「这种______**已经相当明显**，甚至已经蔚为壮观。比如，'应援经济'迅速崛起」→ 例子讲一种正在成形的走向 → 选 C 趋势（我推的）
- **例 1.4**：「呈现出很强的______。若是再仔细分辨的话，**区别**就更大了。比如，河南朱仙镇……苏州桃花坞……」→ 例子全在比不同 → 选 C 差异性（我推的）（把握低）
- **例 1.5**：「必须尽量是**原汁原味**，随便地'______'就**失去了本来的文化意义**了。就好像京剧，加入西洋器乐……再如国画加油彩，茶道添歌舞」→ 例子全在「往原样的东西里加、改原貌」→ 选 D 改头换面（我推的）（把握低）

💡 解释说明的题，**横线自己读不出答案，答案在横线后面**。先往后扫，找到「比如 / 再如 / 就好像」，把几个例子的共同点抽出来。

## 二、契合具体展开

**规则（推断 ⚠️）**：横线后（或前）的文字把词的意思**一项项摊开写**——写出它具体是什么样、包含哪些动作。选项要和这些具体表现逐项对得上，而不只是方向对。（与「解释说明」的分界：解释说明靠举例打比方，具体展开靠正面描述；这条把握低 ⚠️）

- **例 1.6**：「很多所谓的高科技产品______，**来也匆匆去也匆匆**……最后**无影无踪**」→ 来去匆匆、无影无踪就是这个词的具体表现 → 选 A 昙花一现（我推的）
- **例 1.7**：「修复工作也要______，在**沿袭中国传统技法的同时，也要运用现代科学技术、借鉴西方的修复理念**」→ 展开的就是「传统＋现代一起上」→ 选 A 与时俱进（我推的）
- **例 1.8**：「必须______，**寻找新的'登天之梯'**」→「找新的路」→ 选 B 另辟蹊径（我推的）
- **例 1.9**：「出版人需要______，能够**从茫茫人海中发现**有价值的作者，能够**从只言片语中发现**优秀作品」→ 两个「发现」→ 选 C 独具慧眼（我推的）
- **例 1.10**：「诗人的目光仿佛具有______的本领，生活中许多**琐碎、平淡甚至枯燥**的事物，经过它的描述，便产生了**丰富的意味**」→ 从平淡里出丰富 → 选 C 点石成金（我推的）

💡 横线后面是一串「具体怎么做 / 什么表现」时，把每一项都圈出来，**每一项都对得上的那个词**才是答案。

## 三、契合主谓宾性质

**规则（推断 ⚠️）**：填词前先把横线所在句的**主语、谓语、宾语是谁**找准；所选词的性质（人 / 物、具体 / 抽象、能不能带这个宾语）必须跟这个主谓宾搭得上。近义词之间分不开时，就比「谁能跟这个主语、宾语搭」。

- **例 1.11**：主语是「人物动作、场景结构等元素」，目的在后半句「内容的**认知门槛**就能有所降低」→ 降门槛＝看得懂 → 选 B 直观（我推的）
- **例 1.12**：「郑板桥**观察**生活，不是______；相反，他是极为**细致**且有一定深度的」→ 主语动作是「观察」、反义是「细致」（＝看得粗）→ 选 B 走马观花（我推的）
- **例 1.13**：「他们的革命、奋斗、拼搏精神不仅推动着**时代**______」→ 宾语是「时代」→ 选 B 进程（我推的）
- **例 1.14**：「这些**资源**都是用**财政科技资金**______的」→ 主语是「资金」、宾语是「资源（设备类）」→ 选 B 购置（我推的）
- **例 1.15**：「一块块**移动电子屏**，让**书籍**______，极大地拓展了阅读的时间与空间」→ 主语是「电子屏」、受益的是「书」→ 选 D 触手可及（我推的）

💡 两个选项都觉得对时，**回头看主语是谁**：主语是人还是物、是资金还是技术、动作是「看」还是「钻研」——往往这一处就把两项分开了。

## 四、契合比喻

**规则（推断 ⚠️）**：句中出现了比喻（带引号的「宝库」「超级矿藏」「水源」「画卷」「名片」「通行证」等）时，横线的词要**顺着喻体的语义选**：喻体是水就用水系的词，喻体是画就用画系的词。

- **例 1.16**：「符号化产生了知识的'**宝库**'……大数据将成为人类的'**超级矿藏**'，其……价值已经______」→ 矿藏刚被开采＝刚刚露头 → 选 B 初露峥嵘（我推的）
- **例 1.17**：「'文化**底片**'，形象地**显影**着一个国家的______；'文化**芯片**'，深刻地______着……精神**密码**……'**通行证**'」→ 底片→显影→底蕴；芯片→密码→揭示；通行证→抵达 → 选 B「底蕴 揭示 抵达」（我推的）（把握低）
- **例 1.18**：「避免陷入'**到处是水，却没有一滴可以喝**'的窘境……才能成为人们真正需要的'**水源**'」→ 水的比喻，把水澄净得能喝 → 选 A 沉淀（我推的）（把握低）
- **例 1.19**：「尽管有**前车之鉴**，但是依然不乏职能部门______」→「前车之鉴」直接点名「重蹈」→ 选 C 重蹈覆辙（我推的）
- **例 1.20**：「将五千年中华文明比作一幅璀璨夺目的**画卷**，那么甲骨无疑是其中（ ）的一笔」→ 画的比喻 → 选 C 浓墨重彩（我推的）

# 第二章 三大注重

**本章主旨（推断 ⚠️）**：「注重」＝选词时要额外盯住的三个维度：主谓宾是谁、程度轻重、情感色彩。

## 一、注重抓准谁是主谓宾

**规则（推断 ⚠️）**：填空前先确定横线这一句真正的主语、谓语、宾语，别让旁边的修饰成分把主语带偏；词义差不多时，看哪一个能跟这个主语、宾语搭上。

- **例 2.1**：「**科学家**在利用现有模型预测未来变暖时仍然存在______」→ 主语是「科学家」（人），不是「模型」→ 选 A 分歧（我推的）（把握低）
  - ⚠️ 若按「模型有毛病」理解就会选短板 / 漏洞 / 瑕疵；这题考的正是先认主语。
- **例 2.2**：「千里岷江和沱江的**冲积**，______了肥沃的成都平原」→ 主语是自然力「冲积」、宾语是「平原」→ 选 D 造就（我推的）
- **例 2.3**：「一个个**新创意、新技术**将舞台变得美不胜收，______地丰富游客的体验」→ 主语是「创意 / 技术」（不是游客），横线修饰「丰富」这个动作 → 选 D 想方设法（我推的）（把握低）
- **例 2.4**：「哲学课的**地位**与法语、数学和物理这样的主课______」→ 比的是「地位」，后半句「哲学课都是必修课」作证地位相当 → 选 B 不相上下（我推的）（把握低）
- **例 2.5**：「但每向前走一步都不______，都是不断**突围**的结果……会遇到未曾遇到的**阻力**」→「突围、阻力」都在说它难 → 选 C 容易（我推的）（把握低）

💡 主语认错，全题就错。**近义词之间的胜负，常常只在「主语是谁」这一处**（例 2.1 是典型）。

## 二、注重程度轻重

**规则（推断 ⚠️）**：选项常是同一方向但**程度不同**的一组词，看文中把程度限定在哪一级——有「一部分人 / 还算 / 总的来说」这类限定就取轻的，有「最、彻底、一无是处」就取重的。

- **例 2.6**：「一百多年后它**遭到**______……在后一个阶段它**被一部分人**视作现代医疗发展的羁绊」→「一部分人」程度轻 → 选 A 质疑（我推的）
- **例 2.7**：「他们的生活变得______，好像每个人都守着很多不能告诉别人的秘密」→ 主语是孩子的「生活」，语气轻 → 选 A 神秘兮兮（我推的）
- **例 2.8**：「古城的活力**日减**，如何用新鲜血液**激活**（ ）的古城……是（ ）古城的重要一步」→「日减」＋「激活」指向「还没死、只是冷清」＋「重新活过来」→ 选 D「落寞 复苏」（我推的）
- **例 2.9**：「电报的高商业使用率反而______了它自身在普通消费者群体的沉降与普及」→ 不是全堵死，是拖住了 → 选 A 妨碍（我推的）（把握低）
- **例 2.10**：「屠格涅夫……他的态度倒还像个**绅士**，总的来说还算**温和**。托尔斯泰就比较厉害……**最猛烈的攻击**」→ 前后对比定程度轻 → 选 B 颇有微词（我推的）

💡 程度题看三个信号：**限定词**（一部分、还算）、**旁边的对比对象**（有更重的在旁边）、**结果是否被完全堵死**（拖住→妨碍，全堵→阻止）。

## 三、注重情感色彩

**规则（推断 ⚠️）**：先定横线所在句是褒、贬还是中性，再选同色彩的词；褒义语境里的贬义词、贬义语境里的褒义词直接排除。

- **例 2.11**：「国学非但不会被这些人'**发扬光大**'，相反可能会走入**狭隘化、极端化、边缘化**……钻进狭小天地里______，……变成了一块'化石'」→ 全句贬 → 选 D 孤芳自赏（我推的）
- **例 2.12**：「救助资金最终仍会______到**政府头上**，导致受援国主权债务增加」→ 推责任，贬 → 选 A 转嫁（我推的）
- **例 2.13**：「这个'**数千年未有之大变局**'的酿成乃是中国农耕文明______与西方工业文明______的双重结果」→ 变局是坏事，且农耕文明没到「消亡」→ 选 A「式微 侵凌」（我推的）
- **例 2.14**：「**不过**，不论**营销术语**如何（ ）未来的美好蓝图，目前新能源行业依旧以电池为主」→「不过」「营销术语」带怀疑，贬 → 选 B 渲染（我推的）
- **例 2.15**：「都不得不运用（ ）的语言，即广义的'**陈言**'，因为……前人从未使用过的崭新语言是无法进行交流的」→ 客观陈述语言规律，中性 → 选 D 约定俗成（我推的）
- **例 2.16**：「为偶像打榜、刷数据______，其背后……**灰色产业链**的助推」→ 贬 → 选 B 大行其道（我推的）

💡 色彩题最快的判据：**看这句里有没有「灰色、牟利、狭隘、极端、助推」这类自带判断的词**，有就是贬义场，褒义词（如蔚然成风）先划掉。

# 第三章 三大内部关系

**本章主旨（推断 ⚠️）**：「内部关系」指**横线所在句和上下文之间的逻辑关系**（递进、并列、反义）。三种关系直接决定横线该往哪个方向取词。

## 一、前后文递进

**规则（推断 ⚠️）**：出现「甚至 / 乃至」就是递进，递进两端同方向、程度递增；横线在「甚至」之前就取轻一档的，在「甚至」之后就取重一档的。

- **例 3.1**：「普通话和方言可以做到**并行不悖**，甚至______，**相得益彰**」→ 递进后要更进一步 → 选 C 珠联璧合（我推的）
- **例 3.2**：「带来**革命性**______，甚至改变**世界力量平衡**」→ 后项更重，前项也得够重（不是「影响」）→ 选 C 变革（我推的）
- **例 3.3**：「发挥着**重要**的，甚至是______的作用」→ 在「重要」上再加码 → 选 B 不可替代（我推的）
- **例 3.4**：「往往被______，甚至被**忽视乃至遗忘**其思想价值」→ 递进链是「略过→忽视→遗忘」，横线在最前，取最轻 → 选 B 一带而过（我推的）（把握低）
- **例 3.5**：「韩国婴儿第一次吃到泡菜时**抓舌头**甚至______的视频」→ 比「抓舌头」更进一步的身体反应 → 选 A 推拒（我推的）（把握低）

💡 递进题的捷径：**先用「甚至」另一侧那个词定方向，再比程度**。方向不对的直接排除，方向对但程度错档的也排除。

## 二、顿号的同义并列

**规则（推断 ⚠️）**：顿号连接的是同义并列成分，横线处要与顿号另一侧的词**同义同向**，多数情况下就是找一个近义词。

- **例 3.6**：「用仿佛是**第一次发现的**、（ ）的目光注视着自己的时代」→「第一次发现」＝新奇 → 选 C 新奇（我推的）
- **例 3.7**：「作为一群几乎______、**很少被研究过**的生物」→「很少被研究」＝没人知道 → 选 C 不为人知（我推的）
- **例 3.8**：「拿出**虚心以待、胸怀若谷**的姿态，砥砺______、**从善如流**的自觉」→「从善如流」＝乐意听批评 → 选 D 闻过则喜（我推的）
- **例 3.9**：「习近平总书记始终______、**以上率下**……以行动作无声的号令、以身教作执行的**榜样**」→「以上率下 / 榜样」＝自己做表率 → 选 B 以身作则（我推的）
- **例 3.10**：「就要**常怀远虑**、______，始终谦虚谨慎……不为任何风险所惧」→「常怀远虑」＝想到远处的风险 → 选 B 居安思危（我推的）

💡 顿号题就一句话：**看顿号旁边那个词**。旁边词的意思就是答案的意思（「去伪存真」旁边就是「去芜存菁」）。

### 补充：多者并列及同义并列的不绝对性

**规则（推断 ⚠️，把握低）**：当顿号并列项**多于两项**、或各项只是大方向一致（各管一个侧面）时，横线**不要求跟某一项严格近义**——只要跟整组的方向一致即可，别死抠挨着的那一个词。

- **例 3.11**：「倡导______、**日积月累、不断求知**的学习精神」→ 整组说「学得勤、学得久」，各项各有侧重 → 选 A 孜孜不倦（我推的）
- **例 3.12**：「从海量信息中______、**去伪存真**、分析处理、归纳总结」→ 一组处理信息的动作，「去伪存真」那一项最贴 → 选 B 去芜存菁（我推的）
- **例 3.13**：「情商绝对不是**逢迎拍马，口是心非**，______，也绝对不是否认自己的情绪」→ 整组都是贬义的「嘴上好听」→ 选 B 巧言令色（我推的）
- **例 3.14**：「从艺术**现场破题**，从**问题症结处**______，锐意创新」→ 与「破题」并列，动作要对着难点去 → 选 A 迎难而上（我推的）（把握低）
- **例 3.15**：「从**个人无意识**、______的影像记录，到**组织严密、目标明确、系统全面**的深度追踪」→ 与「系统全面」反向、与「无意识」同侧 → 选 A 碎片化（我推的）

💡 多者并列时别只盯旁边那一个词，**先把整组的方向读出来**（是「勤」、是「处理信息」、还是「贬义」），方向对了再看谁的侧重点最合。

## 三、前后文反义

**规则（推断 ⚠️）**：出现「但 / 而 / 反而 / 不过 / 与……不同」等转折，或前后语义对立时，横线取与另一侧**相反的方向**；带引号的俗语、比喻常成对出现（冷板凳 ↔ 香饽饽）。

- **例 3.16**：「茶饮的原料**非常复杂**……但咖啡的原料______」→ 与「复杂」反义 → 选 B「接近 单一」（我推的）
- **例 3.17**：「如今，线上艺术不像以往那样坐'**冷板凳**'，而成为'______'」→ 引号俗语成对反义 → 选 A「无限 香饽饽」（我推的）（把握低）
- **例 3.18**：「纸画才逐渐形成与帛画______的唯有宣纸才有的水墨表现体系……而以重彩见长的帛画反而______」→ 前「不同」、后「衰落」，与纸画的兴盛相反 → 选 A「截然不同 日渐式微」（我推的）
- **例 3.19**：「与传统文化消费的______不同，……人们在文化消费过程中越来越注重**话题分享和即时交流**」→「分享交流」的反向＝单向 → 选 B 单向性（我推的）
- **例 3.20**：「从**修修补补**向______推进」→「修修补补」的反向＝彻底改 → 选 A 脱胎换骨（我推的）

💡 反义题先找**转折词**（但、反而、不过、与……不同），再找和它对立的那个词，横线就是「另一个极端」。带引号的最好用：引号里往往是现成的俗语对。

### 补充：语境相反

**规则（推断 ⚠️，把握低）**：不只是词与词反义，**整句的语境会反转**（前面说「好感」，后面翻成「厌烦」）。横线要照顾这种反转，选能带出反转的那个词。

- **例 3.21**：「曝光效应……产生**好感**……不过______，心理学上还有一个概念叫'**过度曝光**'……超过这个次数，反而会让被试产生**厌烦感**」→ 好感翻成厌烦 → 选 D 物极必反（我推的）
- **例 3.22**：「……**最初的**物质构成______。科学家**此前认为**……阻止了……混合。**但**研究表明，木星的成长速度不足以阻止……这意味着……将拥有______的成分」→「此前认为不同」被「但」推翻成「类似」→ 选 D「大相径庭 类似」（我推的）
- **例 3.23**：「其中**绝大多数**与地球______。**不过**，《发现》杂志曾预测……就应该会找到一个**类似地球**的小型行星」→「不过」翻向相反 → 选 D 大相径庭（我推的）

💡 语境相反的题，**转折词后面那句才是命题人想说的话**，横线要跟它站一边。

# 第四章 三大谬误

> **本章说明**：讲义只印了三个名称（局部谬误 / 搭配不当 / 分割谬误），**没有给任何定义**。下面的规则全部是我从例题倒推的，把握普遍偏低，请结合课程核对。
>
> 原讲义在部分例题编号后印了百分比（推测为通过率）。本书正文不逐题标注，汇总见书末附录。

## 一、局部谬误

**规则（推断 ⚠️）**：**逻辑填空不能只盯横线附近那几个字就下手。** 横线附近的局部提示词往往把你往错项上引，真正决定答案的线索常在文段的另一头——**多是横线之后**。先通读，再落笔。

- **例 4.1**：前有「几代学者」→ 只看局部像"研究"类词（孜孜以求 / 潜精研思）→ 但后文「直到今天，考古界**才确定**它就是一种类似现代意义上的'小火锅'」说明此前一直没搞清 → 选 B 迷惑不解（我推的）
- **例 4.2**：后文「**似乎**西方逻辑哲学的理论就是逻辑哲学的唯一真理」「不是采取批判的态度……而是**全盘照搬，奉为圭臬**」→ 已把这种认识定性为错 → 选 A 错觉（我推的，把握低：B 误解 同样成立，两者差别在"错觉＝错误的感知／认知"、"误解＝错误的理解"）
- **例 4.3**：前面「给人视觉上的冲击与震撼」→ 局部看像"精彩 / 完美"→ 但后文全是「重重**谜团**」「至今都没有定论」「甚至无从找寻线索」→ 选 B 神秘（我推的）
- **例 4.4**：前文讲代价（「需要花费大量的时间和精力」「有时甚至要颠覆整门课程」）＋ 条件「**如果没有合理的激励机制**」→ 因难而退 → 选 A 望而却步（我推的）
- **例 4.5**：后文「只是我们**不知道它现在何方**，也不知道它**何时降临**」→ 藏着、伺机而发 → 选 C 潜伏（我推的）

💡 读到横线别急，先把整段读完，重点扫横线**之后**——「才确定 / 才发现 / 其实 / 但」后面那半句往往才是答案。

## 二、搭配不当

**规则（推断 ⚠️）**：**横线处的词要能和它真正的搭配对象组成常见搭配。** 意思对但搭配不对的选项直接排除；判断搭配看的是横线的**中心语或谓语**，不是句子大意。

- **例 4.6**：「消费税是一种____**比较宽**的**税**」→ 能与"宽"搭配的是"面"(覆盖面 / 涉及面)，"灵活性""影响力"都不与"宽"搭配 → 在两个"面"里选 → 选 A 覆盖面（我推的，把握低：C 涉及面 也通，我按"对'税'的描述用覆盖面"取 A）
- **例 4.7**：「对信息的重要性**做出**____」→「做出判断」；且后句已有「做出自己的**抉择**」，避免与"选择"重复 → 选 A 判断（我推的）
- **例 4.8**：「时间安排不可避免地与人体生物钟**发生**____」→ 固定搭配「发生冲突」→ 选 A 冲突（我推的）

💡 先把横线能组的搭配摆出来（"比较宽的 X"、"发生 X"、"做出 X"），用搭配砍掉一半选项，剩下再看语义。

## 三、分割谬误

**规则（推断 ⚠️，把握低）**：**不要把横线周围的结构切碎了看。** 横线修饰／支配的常常是一个**完整的动宾结构**，夹在中间的修饰成分只是干扰；要把横线和它真正管的那一截连起来读。

- **例 4.9**：横线修饰的是「____**创造出**……1.2 亿摄氏度……1.6 亿摄氏度……**世界纪录**」这一整个动宾结构，不是就近的"燃烧 101 秒"；两项纪录前后相继 → 选 A 接连（我推的）
- **例 4.10**：「取决于如何____相对富裕者的**收益**和相对贫穷者的**损失**」→ 要一个能同时管住"收益""损失"两头（得失）的词 → 选 B 权衡（我推的）

💡 划横线时把横线的**宾语／中心语**圈出来（"创造出……世界纪录"），别让中间那一长串修饰语把搭配对象挡掉。

> **待核 ⚠️**
> - 「三大谬误」这一章讲义**只印了名称，没印定义**，三个规则全是我从例题倒推的，把握低。
> - 「局部谬误」我推为"只看横线附近的局部提示、忽略后文"；也可能指的是"出题人在局部设的错项"——两种理解我都无法证实。
> - 「分割谬误」与「搭配不当」的边界我不确定（例 4.10 的"权衡收益与损失"按搭配不当也讲得通）。
> - 例 4.2 的答案（A 错觉）把握最低，B 误解 我认为同样成立。
> - 例 4.6 的答案（A 覆盖面）与 C 涉及面 难以分开，我按搭配取 A。

# 第五章、三大一致

> **本章说明**：讲义只印了三个名称，也没给定义。以下规则为倒推，把握偏低。

## 一、因果一致：原因致果两大设计

**规则（推断 ⚠️）**：**横线处的词要服从文段的因果链。** 讲义说"两大设计"，具体是哪两大我无法确认，我按"由因推果 / 由果推因"两个方向理解：横线在**原因**一侧时，它要能推出后文的结果；横线在**结果**一侧时，它要由前文的原因推得。无论哪种，填进去后**因和果必须接得上**。

- **例 5.1**：「习惯了一种写作和思维路径后，**很难有别的考察和分析视角**」→「人们读到的史书就难免____」→「这在一定程度上使读者____」→ 两空要串成一条因果链（史书雷同 → 读者没兴趣）→ 选 D 大同小异 兴味索然（我推的，把握低：A 如出一辙 在第一空可能更准）
- **例 5.2**：「借助热播影视剧，不仅**提高了人气**，而且带来了可观的**经济收入**」→ 一个动作带出两样收获（一因多果）→「可谓____」→ 选 A 一举多得（我推的，把握低：B 名利双收＝人气为名、收入为利，同样贴）
- **例 5.3**：「自然村十年前有 360 万个，现在则只剩 270 万个，一天时间消失的自然村大概有 80 个到 100 个」→ 消失得快 →「保护传统村落成了____的事情」→ 选 D 迫在眉睫（我推的）。首当其冲＝最先受冲击，责无旁贷＝责任推不掉，一触即发＝一碰就爆发，都不在"紧迫"这一义上。
- **例 5.4**：「历代官修史籍……不可能完全准确，也不可能面面俱到」→「**于是**，后世各种史类的'札记''纠谬''商榷'等著作____」→ 因有缺漏、果是这类著作接连出现 → 选 C 层出不穷（我推的）。汗牛充栋＝形容书多，不绝如缕＝形容声音微弱或局势危急（易误用），此起彼伏＝交替起落。
- **例 5.5**：「含耐药基因的微生物在自然界中____」→「这意味着人类有可能回到没有抗生素的时代……轻微的细菌感染都可能引起____的后果」→ 分布广 → 后果致命，两空成链 → 选 D 无处不在 致命（我推的）。B 不可胜数 也能说数量多，但"在自然界中无处不在"更贴"到处都有"这层因。

💡 填空前先在草稿上写出这条因果链（因为……所以……），再挑能让链条闭合的词；两空题重点检查"第一空能不能推出第二空"。

## 二、高度思维：成分一致

**规则（推断 ⚠️，把握低）**：**横线的词要和句中"对应的成分"一致。** 「高度思维」我理解为站到句子结构的高度去看，「成分一致」指横线要跟它对应的那个成分（谓语与宾语、并列成分之间、上下文同一位置）同类、同向——不重复、不越级、不搭错对象。

- **例 5.6**：「____形式主义**仅仅有外力干预**还远远不够，如果不能对……深层次根源釜底抽薪，那就不能**真正除弊**」→ 横线只能到"外部压制"这一层；若填"消除 / 破除"就与后文"除弊"重复、越级 → 选 B 遏制（我推的，把握低：A 破除 亦可争）
- **例 5.7**：「'秋风有意**染**黄花'，如果你领悟了菊的意韵，是不是也会去有意为菊____一番」→ 与前文"染"字呼应同一层意思 → 选 B 点染（我推的）。藻饰＝修饰文字，润饰＝润色，点缀＝衬托装饰。
- **例 5.8**：「与新一代人工智能相适应的操作系统正在____原有的**垄断**」→ 与宾语"垄断"组成固定搭配（打破垄断）→ 选 B 打破（我推的，把握低：D 破除 也能搭配"垄断"，但"破除"多用于迷信、陋习、旧观念）

💡 填空前先问"这个空在句子里干什么活"——它后面接谁（宾语）、前面是谁（主语），然后到同一层面上找词。

## 三、句式一致

**规则（推断 ⚠️）**：**横线所在的分句要和相邻分句在句式、节奏上平行。** 并列的几个分句"说的是同一类事、用同一类说法"，选那个能和并列句对齐的词。

- **例 5.9**：「客户会员**越办越多**，各种'套路'也____」→ 前句是"数量不断增多"的句式，后句也要"不断出现"这一类 → 选 A 接踵而至（我推的，把握低：C 应运而生 也通，它偏重"顺应时机而产生"）
- **例 5.10**：「网络领域里**热闹不断**，各路观点____」→ 与"不断"对齐 → 选 A 层出不穷（我推的）。此起彼伏＝交替起落，良莠不齐＝好坏混杂，参差错落＝交错不齐，都不在"不断出现"这一义上。
- **例 5.11**：「街市内**店铺**____，各类招幌林立，商贾云集，人流如织，**叫卖声**____」→ 先用搭配砍：B 浩如烟海（只能形容文献）、A 漫山遍野(只能形容山野)都不能形容店铺，剩 C、D → 再看第二空，「叫卖声**余音绕梁**」不成立（余音绕梁形容歌声优美悠长，不用于叫卖声）→ 选 D 星罗棋布 此起彼伏（我推的，把握低：单看第一空"鳞次栉比"更贴店铺，此处靠第二空排除）
- **例 5.12**：三句并列「它们____了历史的风云，**寄托着**先人的情怀，**充满了**生命的活力」→ 三个谓语都是"内蕴充盈"的方向 →"经历"（中性时间经历）、"折射"（向外反映）方向反了 → 在 B、C 里选 → 选 B 浸透（我推的，把握低：C 蕴含 是最强干扰项）

💡 把横线所在的整句和它的邻居并列着读，看**主语类型、动词方向、字数节奏**是否一致；方向反了的（如"折射"向外、与"充盈"向内相反）先排除。

> **待核 ⚠️**

> - 「原因致果两大设计」的"两大设计"具体指哪两个，我无法确认；文中我按"由因推果 / 由果推因"理解。
> - 「高度思维：成分一致」是最抽象的一节，我只能从例 5.6–5.8 看出"与后文表述不重复、与宾语搭配"两点，可能不完整。

# 第六章 特殊技巧

> **本章说明**：这是六条临场技巧，命名同样未给定义，规则为倒推。带（重点）的第六节讲义自己标了重点，应是必考。

## 一、敏感于固定搭配

**规则（推断 ⚠️）**：**一看到横线，先想这个词有没有"标配"的伙伴。** 成语有固定对象（"琳琅满目"只配商品、书籍一类）、词语有固定组合（"民生福祉""铭记历史"）；固定搭配对上了，往往可以直接锁答案。

- **例 6.1**：「是大**自然**的____造就的自然生态平衡之美」→「大自然的鬼斧神工」是固定说法（精雕细琢是人工，开天辟地是前所未有的开创，沧海桑田是世事变迁）→ 选 A 鬼斧神工（我推的）
- **例 6.2**：「____历史、____先烈、____和平、____未来」→ 四个动宾各有固定搭配：铭记历史 / 缅怀先烈 / 珍爱和平 / 开创未来 → 选 B 铭记 缅怀 珍爱 开创（我推的）
- **例 6.3**：「某些人'为黑而黑'的把戏相当____」→「把戏」的固定伙伴是"拙劣"；且后文「**但**不得不说……曾经一度在舆论场上呼风唤雨」是"如今已显拙劣"的反衬 → 选 D 拙劣（我推的，把握低：A 浅薄 也通）
- **例 6.4**：「事关当代人的民生____和后代人的发展空间」→「民生福祉」固定搭配（福祉＝幸福、福利）→ 选 B 福祉（我推的）。A 幸福、C 利益 都不能和"民生"组成固定说法。
- **例 6.5**：「____的商品就像阿里巴巴的山洞」→「琳琅满目的商品」固定搭配（五花八门用于门类，形形色色多用于人，丰富多彩用于内容形式）→ 选 B 琳琅满目（我推的）

💡 把常考的固定搭配当"识字卡"过一遍（民生福祉、鬼斧神工、琳琅满目、铭记历史……），考场上先扫一眼有没有它们的影子。

## 二、保障基础性

**规则（推断 ⚠️，把握低）**：**选项意思都说得通时，回到"最基础、最朴素"的那个词上。** 花哨的词（新颖、独特、理想、神奇）常常不是答案；能兜底、最不容易出错的基础词（恰当、合适、需求）才是。**把握低**：另一种读法是"先保证最基础的搭配／语义成立"，我在例 6.8、6.10 上用的就是这一读法。

- **例 6.6**：「让人眼花缭乱的舞台美术和高科技不过是**华丽的外表**，真正能够打动人心的……如何采用____的方式激发……文化认同」→ 与"华丽的外表"对立，要的是朴素的基础词 → 选 A 恰当（我推的）
- **例 6.7**：「如果贸然将其放归野外，结局很可能是死亡。就算可以放归野外，也必须为他们找到____的栖息地」→ 说的是"放对了地方"，取最基础的说法 → 选 A 合适（我推的）
- **例 6.8**：「植物在巨大的自然选择压力下，也演化出了许多____的防御机制。于是……'军备竞赛'不断____，道高一尺、魔高一丈」→ 第二空"军备竞赛**升级**"是基础搭配；第一空"巧妙"与动物"花样繁多"的觅食技巧对举 → 选 C 巧妙 升级（我推的）
- **例 6.9**：「只要依靠创新、下足功夫，中国品牌一定可以____世界知名品牌」→"超越 / 领先"说得太满（文段只讲"突围""快速提升"），要的是"比得上"这一基础义 → 选 A 媲美（我推的，把握低：C 比肩 同样成立）
- **例 6.10**：「人们对字画艺术品的____必然是在社会安定……以后才有可能**产生**」→"产生"只能配"需求"（青睐要"受到青睐"，热衷要接"于"，收藏不能说"产生"）→ 选 C 需求（我推的）

💡 拿不准时问自己"文段敢不敢把话说这么满"。凡选项里有更基础、更保守的说法，优先它。

## 三、多对多对应

**规则（推断 ⚠️）**：**文段里提示点有几个，空就要跟它们一一对上。** 尤其在并列结构里：前一半的提示词管前一半，后一半的提示词管后一半，不能张冠李戴。

- **例 6.11**：「有时候他们觉得自己充满力量，非常自信，似乎是**全能的存在**；有时候却又觉得自己好像虚弱无力，____，非常自卑」→ 三个位置一一对应，空处要对"全能的存在" → 选 B 一无是处（我推的）。A 弱不禁风＝身体虚弱，与"虚弱无力"重复。
- **例 6.12**：「不能真正了解到对方的**优势**和**劣势**」→「由此导致的结果，要么是'____'，要么是'交友不慎'」→ 优劣两头各对应一个结果：没看清劣势 → 交友不慎；没看清优势 → 错过 → 选 D 坐失良机（我推的）
- **例 6.13**：「戏曲相对于互联网时代知识文化的____、**快餐式传播**，其**可重复欣赏**和**耐咀嚼**的品格显得更为可贵」→ 前后两两相对："可重复欣赏"对"快餐式传播"，"耐咀嚼"对空处 → 选 A 碎片化（我推的，把握低：若按"耐咀嚼"的反面取，B 肤浅化 也说得通）
- **例 6.14**：「单一的**政策实施、理论指导或实践探索**难以（ ）」→ 三个并列的"单一做法"都不管用；后文「只有在政策、实践和理论探究之间建立起……良性循环，才可能**标本兼治**」正好是"综合才管用" → 选 B 奏效（我推的）。"长远"是形容词，与"难以"不成搭配。
- **例 6.15**：「历经百年风雨而**风华正茂**、饱经磨难而____的**精神基因**」→"历经百年风雨"对"饱经磨难"，"风华正茂"对空处 → 空处要与"风华正茂"同向（生机旺盛） → 选 D 生生不息（我推的，把握低：B 百折不挠 是最大干扰，它讲的是意志不屈，不是生命力）

💡 遇到并列句，先在草稿上画配对（前半 ↔ 后半），一格一格对，别让两个空互相串味。

## 四、看透出题人的小心思

**规则（推断 ⚠️，把握低）**：**选项的坑常摆在"看着最顺"的那个词上。** 出题人会用近义词的细微差别、或"字面顺但对象错"的词做干扰；要看透题目在哪个点上设了卡（对象、方向、程度、搭配），而不是凭语感挑最顺口的。

- **例 6.16**：「新诗与旧体诗有**各执一端**、____的倾向」＋「都是正确创作方向的____」→ 第一空要与"各执一端"并列（各走各的路）→ 分道扬镳；第二空"迷失方向"是固定搭配 → 选 C 分道扬镳 迷失（我推的）。D 分崩离析 形容国家、集团分裂瓦解，对象错。
- **例 6.17**：「网络文学生产仿佛一场在相同时空里不断发生的____」＋「作者和读者之间存在大量**互动**」「作品**创造、更新和进化**」→ 一棒接一棒的"接力"才对；对抗赛 / 擂台赛 / 淘汰赛都是对抗语义，与"互动、共同汇聚'创意'"相反 → 选 B 接力赛 反馈（我推的）
- **例 6.18**：「当处于**落后**地位时，虚心向比自己发达的国家学习；而当处于**领先**地位时，又____，克服内外压力，精益求精，从不满足」→ 落后时学、领先时也不松懈 → 忧患意识；领先时提前谋划 → 未雨绸缪 → 选 A 忧患 未雨绸缪（我推的）

💡 选定前扫一遍"这个选项是不是只是读着顺"，再核对它与前后文的**对象、方向、程度**是否真对得上。

## 五、锁定目标，要什么找什么

**规则（推断 ⚠️）**：**先定"这个空要填个什么角色"，再带着目标去文段里找线索。** 空要的是动作？是性质？是名词？确定了目标，该找哪句话就清楚了，不用全段反复读。

- **例 6.19**：第一空「古代法律对聘财的**认定标准**相当____」要的是"标准"的性质，后文「对聘财的形式及数量**并无严格的限定**」「聘财不拘重轻」→ 标准松 → 宽松；第二空「即为法律所____」要的是法律的动作 → 法律**认可** → 选 A 宽松 认可（我推的）
- **例 6.20**：「离不开一个____：促进发展经济的措施**必须**符合基本经济逻辑」→ 冒号后是客观要求，且后文「**历史证明**，什么时候系统化地推进经济发展，什么时候就会大幅提高国家经济潜力」是在验证一条规律 → 选 A 规律（我推的，把握低：D 原则 也说得通，两者差别在"客观规律"与"人为准则"）

💡 读段前先问"这个空是名词还是动词？它修饰谁？"——目标明确后，扫读会快很多。

## 六、注重逻辑填空首句（重点）

**规则（推断 ⚠️）**：**首句往往给整段定调、给判断标准。** 先把首句的定性抓住（尤其是"是……""最后一道防线""不等于……"这类判断句），横线的词必须与首句的定性同向。

- **例 6.21**：「推进公交专用车道的**开放共享，不等于**废除公交专用通道，**更不等于**在城市交通治理中不再坚持'公交先行'的理念」→ 定调：共享不能牺牲公交 → 尾句「而并非____」要填"顾了这个丢了那个" → 选 C 顾此失彼（我推的）。厚此薄彼＝重视一方轻视另一方，侧重的是态度不公。
- **例 6.22**：「公正司法是维护社会公平正义的**最后一道防线**」→ 首句已给"最后"这个定性 → 司法在社会关系调节和纠纷解决中的作用就是"终局" → 选 D 终局性（我推的）

💡 先读首句，圈出定性词（最后、不等于、最……），再回头填——首句常常一句话就把答案框住了。

# 第七章 语句填入

本章按**横线在文段中的位置**分三类：开头、中间、结尾。四、逻辑填空同源是收口——把「语句填入」和「逻辑填空」打通。

⚠️ 先分清两种题：**语句填入**的选项是**一整句**，问法多为「填入画横线部分最恰当的一句」；**逻辑填空**的选项是**词或成语**，问法是「填入/依次填入画横线部分最恰当的一项」。本章前三节是语句填入，第四节把两类放在一起看。

## 一、横线在开头

**规则（推断 ⚠️）**：横线在开头，这一句多半是全文的**总起句**——它要罩得住后文全部内容，不能只对应后文的某一句。

判断标准就一条：把后文每一句都拿来对一遍，罩不住的选项就是错的。

- **例 7.1**：横线在文段开头 → 后文讲了四件事：老年人用社交网络**找老朋友、结新朋友**（交友）、分享抗衰老心得、线上交流＋同城活动＋交通房屋维修（服务）→ 总起要同时罩住「交友」和「服务」两块 → 只讲交友（C）、只讲服务（D）覆盖不全；主体写成「人们」而不是「老年人」（B）主体错 → 选 A（我推的）
- **例 7.2**：横线在开头，而且直接就是个问句（「那么，____？」）→ 后文答的是「不管是选择药物治疗还是手术治疗，年龄和疾病病程都是最重要的因素」→ 问的是**怎么治**，不是「有哪些表现」（A）、「是什么原因」（B）→ 选 C（我推的）
- **例 7.3**：横线在开头，后面紧跟「关键是要树立正确的发展思路，因地制宜选择好发展产业」，段尾又用「思路一变天地宽」回扣 → 落点在「思路」→ 选 C（我推的）
- **例 7.4**：横线后紧跟「主要体现为我们既坚持以经济建设为中心、把发展作为第一要务，又主动为发展营造安全环境」，再往下用「前者…后者…」拆开这两块讲 → 横线处要能统住这两块＝理念和战略上的转变 → 选 D（我推的）
  - ⚠️ 注意：这一题的横线严格说**不在文段最开头**，而在第二句的末尾。讲义仍把它归进「开头」一节，说明这一节实际是「横线靠前、重点看下文」，不是死抠「第一个字」。
- **例 7.5**：横线在开头 → 后文先给现象「很多画家借西方画法画山水画大多不成功」，再举例「李可染、赖少其在这方面较为成功」，理由是「他们都有深厚的传统文化功底」→ 开头要落在一个观点上，而不是停在现象上（D）→ 选 C（我推的）

💡 开头横线的两条操作：一是**用「罩得住」筛选项**，后文出现的每一块内容都得被这句盖住；二是**后文带「例如/比如」时，例子不决定答案**，例子服务的那个观点才决定答案（例 7.5 就是只讲现象不落观点的错项）。

## 二、横线在中间

**规则（推断 ⚠️）：横线在中间＝承上启下。要同时满足两件事：接得住前一句的落点，而且后一句能顺着它往下说。**

- **例 7.6**：横线夹在前文两个例子和后文「成为一个城市的精神和文化象征」之间 → 前文两个例子分别是「紫禁城见证北京城的过往」（历史文化）和「拓荒牛标记深圳的开拓进取」（时代风貌）→ 横线处必须把这两类都收进来 → 选 B（我推的）
- **例 7.7**：横线前是「因为格陵兰，是丹麦的领土」，横线后是「它具有高度的自治权」→ 转折词「不过」已经给出，横线处只需把「地位特殊」点出来，让后面「自治权」接得上 → 选 D（我推的）
- **例 7.8**：横线后紧跟「因此，在艺术生的培养过程中可以给学生创造更多的社会演出机会」→ 横线处要说清**为什么**需要更多演出机会，即中间缺一个通道 → 选 C（我推的）
- **例 7.9**：横线前铺的全是「我国管理制度在不断完善」这一层（制度），横线后是「防范外来物种入侵，人人有责」＋「任何单位和个人未经批准，不得…」这一层（个人）→ 横线处要承接出「不能只靠制度」→ 选 C（我推的）
- **例 7.10**：横线前是「增添文艺的元素，则是其题中应有之义」，横线后举例说老一辈科普作家善于借用文学艺术的力量（竺可桢《说飓风》《说云》文字准确又生动）→ 横线处要给前一句一个理由，后面才好举例 → 选 C（我推的）（把握低）

💡 中间位置最怕「只顾一头」：只接上半句的选项，往下读会断；只启下半句的选项，往上读接不上。**上下两个方向都读通，才留。**

## 三、横线在结尾

**规则（推断 ⚠️）**：横线在结尾，多数情况是全文的**结论/对策**，常见标志是横线前有「因此 / 所以 / 鉴于此」；但结尾句也可能只是衔接最近一句。

> 原讲义原文（P159，讲义排在例 7.14 与例 7.15 之间）：
> PS：尾句也可能衔接最近内容。

- **例 7.11**：结尾，横线前有「鉴于此，我们必须」→ 前文落点是「不能做简单的固化处理」「更不能只注重形式而忽略对其内涵的传承」→ 对策＝纠正形式化倾向 → 选 B（我推的）
- **例 7.12**：结尾，横线前有「因此，要减少对海洋生物的过度捕捞」→ 前文的因果链是：淡水污染的信息 → 部分人改吃海产品 → 海洋被过度捕捞 → 要止损就得断在源头（让人重新信任淡水鱼）→ 选 C（我推的）
- **例 7.13**：结尾，横线前有「因此」→ 前文讲价值判断会带个人经验、情感、家庭背景的印记，价值判断不同则判决结论不同 → 对策＝对价值判断加以规范 → 选 B（我推的）
- **例 7.14**：结尾，横线前有「因此」→ 前文用「但是」转折，说重大事件片面发展、透支未来、不可持续，解决不了「城市病」→ 结论＝不能依赖 → 选 C（我推的）
- **例 7.15**：结尾，但这一题**衔接的是最近一句**（正对上文那条原文 PS）→ 前一句刚说「梧桐树高大茂密，常引来一些鸟儿共筑爱巢」→ 顺着这句往下接的才是对的 → 选 D（我推的）
- **例 7.16**：结尾 → 前文罗列「有的记忆力超强，有的学习能力超强，有的听觉特强，有的嗅觉特强」→ 收口要落在「功能各不相同」上 → 选 B（我推的）
- **例 7.17**：结尾 → 前文已给出换算关系：「哈勃常数数值越大，宇宙的年龄就越小」，而里斯测得的值比之前高出 9% → 年龄变得更小 → 选 A（我推的）
- **例 7.18**：结尾，横线前有「因此，本文尝试____」→ 前文点了原著两处欠缺：「没有从经济层面展开分析」＋「国别分析中范围仅限于欧洲」→ 要补的就是这两处 → 选 D（我推的）（把握中）

💡 结尾横线先做一次分流：横线前有「因此 / 所以 / 鉴于此」→ 往前找结论或对策；没有这种总结词 → 先看**紧挨着的上一句**（原文 PS 说的就是这个）。例 7.17 是顺着上文关系往下**算**出来的，不是总结主旨；例 7.15 是顺接最近一句。所以「结尾＝主旨句」是错的想法。

## 四、逻辑填空同源

讲义把「语句填入」整章放在**第三部分 逻辑填空**里，而不是放进第二部分（语句排序 / 下文推断 / 细节判断）——**章节归属本身就在说它的定位**。

**规则（推断 ⚠️）：语句填入和逻辑填空底层是同一套动作，只是填的颗粒度不同。**

1. 都要先定横线处**要跟谁对应**：只对应前文、只对应后文，还是前后都要对应。
2. 都靠**契合**拿分——解释说明、具体展开、比喻、句式/成分一致这些动作，直接从逻辑填空那几章搬过来用。
3. 差别在颗粒度：**填词**要额外抠词义、搭配、程度轻重、感情色彩；**填句**只要方向和话题对得上就行，句子本身漂不漂亮不重要。

- **例 7.19**：横线在中间，前文说绿萝是「盆栽的代名词」（熟悉），后文连用「但是」「更为神秘的是」讲它身世成谜（陌生）→ 横线处要一句同时接住这**两面** → 选 C（我推的）
- **例 7.20**：横线夹在一串并列动作里——「明确…优势种及其主要媒介蓟马优势种，____，并…进行分析」→ 横线处必须和前后并列，且比「明确蓟马优势种」再进一步，是同一类动作 → 选 C（我推的）
- **例 7.21**：横线在结尾，且是「用外界听得懂的语言，____」这一句的后半截 → 讲的应是对外表达的效果，与「听得懂」相衔接 → 选 D（我推的）（把握低）
- **例 7.22**：横线在「对于大部分高血压病人来说，____，需要治疗的迫切性就越高，……治疗就越精准」→ 后文三个「越…越…」是同一组递进，横线处必须是这条链的第一环，同时扣住全文「综合危险策略」＝**多个**危险因素一起算 → 选 D（我推的）
- **例 7.23**：横线前是「梁思成在世界和现代建筑的语境里」，横线后是他「运用新学新知，'再造'出理想的中国风格的现代建筑」→ 横线处要衔接「用世界/现代建筑的语言去整理中国建筑」→ 选 A（我推的）（把握中）
- **例 7.24**：横线后「新奇的**建筑材料**」「撑持起了一个有灵魂的**空间**」是比喻（对应逻辑填空·契合比喻那一章的动作）→ 喻体必须落在建筑上 → 选 D（我推的）
- **例 7.25**：横线填两个成语，分别被前面的「执着」和「清醒」两个限定词锁死 → 找与限定词契合的成语 → 选 D（我推的）

💡 做语句填入，动作和逻辑填空一样：先把横线处**要什么**写清楚（方向、话题、跟谁并列或对应），再拿选项去对。省下来的力气在于——填句不用抠词义轻重和感情色彩，**方向对了基本就能定**。

## 一、翻译推理（粉笔部分）

**题型特征**：题干出现明显逻辑关联词；问法为"可以推出 / 不能推出"。
**解题思路**：先翻译，再推理（别凭语感硬瞪，容易偏）。

### 1. 翻译规则

| 规则 | 翻译 | 必背关联词 |
|------|------|-----------|
| **前推后** | A → B | 如果…就／若…则／只要…就／所有…都／…是…充分条件／就·都·一定 |
| **后推前** | B → A | 只有…才／不…不…／除非…否则不／…是…基础·假设·前提·关键／…是…必要条件·必不可少 |

> 🚩 **易错**：**必要条件放箭头后**。谁必不可少，谁放在 `→` 右边（如"只有 A 才 B"→ B→A，A 是必要）。
> "除非 **A** 否则 **B**" → **非A → B**；"A 当且仅当 B" → A ↔ B。

### 2. 推理规则

- **逆否等价**：A → B ≡ 非B → 非 A。**肯前必肯后，否后必否前；否前、肯后不必然。**
- **传递规则**：A → B，B → C ⟹ A → C。

### 3. "且"与"或"

| 关系 | 含义 | 关联词 |
|------|------|--------|
| **且**（A且B） | 二者同时成立 | …和…、既…又…、不仅…而且… |
| **或**（A或B） | 二者至少一个成立 | …或者…、要么…、…和…至少一个 |

- **否一推一**：A或B为真 ⟹ 非A→B，非B→A。
- **德·摩根律**：非(A且B) = 非A或非B；非(A或B) = 非A且非B。

### 4. 补充

- **"有的"**：有的A是B = 有的A→B；带"有的"的翻译**不适用逆否**。
- **"并非"**：否定其后全部内容。必然↔可能，有的↔所有，且↔或互换，谓语动词后加否定。

## 二、归因论证

**归因**：指人们对他人/自己行为原因的推论。
**题目形式**：对比实验 + 原因推论（对策建议）；或既成事实 + 原因分析。有的省略原因分析，直接给结论。

### <1> 对比实验归因

| 方式 | 说明 |
|------|------|
| **另有他因** | 回归实验中（把水搅匀），另有原因造成结果 |
| **因果倒置** | 时间先后；本质是原因在结果**之后**，不算是真原因导致结果 |
| **否定此因** | 不讨论真正原因，只是给出理由 |
| **分组正确/回归实验** | 正确项回归实验分组 |

**选项特征**：实验题选项多为"样本数量不足、样本太全（以偏概全）"→ 力度很弱；"有果、特例"选项需选"果"。

### <2> 直接根本原因

- **常见形式**：题干呈现某观点 + 反对者观点，多数设问为**质疑反对者**。
- **常用公式**：根本原因（原观点）→ 表面原因（反对者）→ 结果。
- **理解**：原观点 = A 导致 C；反对者 = B 导致 C。
- **质疑反对者**：A 导致了 B，B 导致了 C ⟹ 其实是 A 导致 C，**原观点更对**。

### <3> 构成对比实验

- **支持方式**：选项为对比实验归因支持，或加入"异因异果"的对照群构成对比实验。
- **质疑方式**：添加"异因异果"（因果倒置/另有他因）或"异因同果"对照群。

## 三、一般质疑（归因类之外，不涉及因果关系）

由**论据 + 结论**两部分组成。选项特征：主体一致 / 话题一致 / 贴合题干。

### <1> 无论据有结论
- **常见结构**：背景 + 结论，分析 + 总结。
- **质疑方式**：有理由地反驳观点。

### <2> 有论据有结论
- **常见形式**：大段论据 + 结论，少数结论在句首。
- **质疑方式**：肯定论据前提下，选质疑理由；或质疑论据（论据本身有误）。
- **底层逻辑**：`A → B` 与 `A 且 非B` 矛盾。

### <3> 严谨逻辑关系

| 命题 | 翻译 | 怎么质疑 |
|------|------|---------|
| 如果 A 那么 B | A → B | A 且 非B |
| 只有 A 才 B | B → A | B 且 非A |
| 除非 A 否则 B | 非A → B | 非A 且 非B |

## 四、支持与前提假设

**问法**：支持论证类"以下哪项如果为真，最能加强上述论证"；前提假设类"上述论证最可能基于的潜在假设是"。选项特征：主体一致 / 话题一致 / 贴合题干。

### <1> 支持类论证（力度从强到弱）

解释说明 → 增加论据 → **断点搭桥** → 必要条件（力度弱）→ 举例支持（较弱）→ 类比选项（极弱）。

### <2> 前提假设类

| 方式 | 说明 |
|------|------|
| **断点搭桥** | 一定要和论据"搭桥"，选择包含论据关键词/结论新内容 |
| **补充漏洞** | 类似"增加论据"，多数为填补题干漏洞 |
| **必不可少** | 必要条件，没它不行 |

> 规律：**论据 + 缺的那个选项 = 结论**。

---

## 五、比例类论证

- **常见形式**：题干中有一比例关系，往往有数字（**分子**）。
- **常见错误**：题干只提到分子，没提**分母**。
- 💡 例：投诉电话是乙公司 **3 倍**（分子）→ 不代表甲更差，还要看**总销量（分母）**；新能源事故率、90% 不及格同学——都要看分母。

## 六、推出类题目

**题型分类**：等价推出 / 正推 / 逆推 / 两难推理等。
**提问**："由此可以推出""根据以上陈述，可以得出下列哪项"。

### <1> 一个符号两种条件
对于 A → B：A 是 B 的**充分条件**，B 是 A 的**必要条件**。**必要条件放箭头后**。

### <2> 命题形式与真假
四种形式：原命题 / 逆命题 / 否命题 / 逆否命题。
**A → B 为假**：只有"A 真且 B 假"时命题为假，其余情况均为真。

### <3> 三种推理方式
- **演绎推理**：一般 → 特殊。
- **归纳推理**：个别 → 一般。
- **类比推理**：特殊 → 特殊。

### <4> 四种相对关系
- **或且关系**：或、且；否定态。
- **范畴关系**：所有、有些；否定态。三个常考点：是否定态转化 / 两词互换 / "有些"逻辑（有些A是B 推出 有些B是A；"有些是"不能推出"有些不是"）。
- **可能关系**：可能、必然；否定态。
- **矛盾关系**（三种）：① 是A和非A；是A且B 与 非A或非B；是A或B 与 非A且非B。② 有些和所有（有些…是 与 所有…不是）。③ A→B 与 A且非B。

### <5> 五种命题
**如果 A 那么 B**（A→B）｜**只有 A 才 B**（B→A）｜**除非 A 否则 B**（非A→B）｜**或者 A 或者 B**（A或B）｜**要么 A 要么 B**（不相容选言，两者只能一真）。

## 七、分析类相关知识点

### <1> 真假分析
- **常用方法**：矛盾法（三种矛盾：A和非A、A且B与非A或非B、A或B与非A且非B）；假设法（同真同假：所有/有些/可能/必然）；代入法（A→B 与 A且非B）。
- **两真两假**：先找矛盾，再假设。

### <2> 范畴分析
- **题型**：所有、有些、特指 → 一分为二画图法。
- **注意**：已知条件找"所有"，所有 A 都是 B（B 包含所有 A）。

### <3> 日常分析
- **含义**：给出日常蕴含逻辑的条件，找内在联系推理。
- **常用方法**：代入法 / 画图画表 / 赋值法。
- **入手点**：**确定信息**（一般先把能确定的确定下来），**最大信息**入手。

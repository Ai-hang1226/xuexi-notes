# 申论知识框架｜Kiwi讲义主线

::: tip 本页在站内的位置
这是申论板块的**总纲**，覆盖归纳概括、综合分析、问题对策、公文写作、文章写作五大题型，因此**独立于任何单一题型**，不是「归纳概括」的下属页面。每类题型的讲义方法都可以从本页对应章节进入；本人的 DAY5—DAY9 真题属于「归纳概括」这一题型的实际练习。
:::

本页按个人提供的《公开课课件》和《申论作文》整理，讲义的题型与方法是主线。每题仍以题干、要求和给定材料为准；页面整理完成不代表本人已独立掌握。

## 一、先分清题目要做什么

| 题型 | 先问自己 | 主要动作 |
|---|---|---|
| 归纳概括 | 概括谁的什么？问一个要素还是几个？ | 找准范围，提取信息，归并同类 |
| 综合分析 | 解释、评价、比较、分析原因还是谈启示？ | 定准对象与观点，用材料说明依据 |
| 问题对策 | 要解决什么问题？是只要对策还是还要分析？ | 先找材料对策，再由问题、原因和经验转化 |
| 公文写作 | 写什么文种？以谁的身份，对谁说，达到什么目的？ | 按任务组织内容，核对题目要求的格式 |
| 文章写作 | 核心主题和文章要求是什么？ | 确定总论点、分论点，结合材料论证 |

来源：《公开课课件》PDF第15—20页；讲义目录见第1—2页。

## 二、所有题型共用：从题干到材料

1. **审题干**：标出任务动词、对象、要素、材料范围、身份、字数和特殊要求；没有的限定不自行补造。
2. **找信息**：按范围读材料，标出与任务相关的事实、观点、做法、问题、原因和结果；判断它是要点还是解释背景。
3. **归并**：先顺材料的主体、领域、时间或流程等关系分组；同类合并，具体信息仍要保留。
4. **成稿回查**：总括句要覆盖下面的内容；回到材料核对遗漏、重复、关系、字数及格式。

### 归纳概括：问什么，归纳什么

**明确对象与要素 → 逐段找点 → 同类归并 → 总括＋必要细节 → 回查。**

- 讲义按做法、成效、特点与作用、问题、原因、理念、变化、过程等分别练习。它们是不同的作答要素，先看题目要求哪些。
- 总括可以概括行动本身，也可以概括行动带来的结果；选择哪种，要看题目问法和材料，不能用空泛标题覆盖具体差异。
- 分类可参考主体、领域、时间、流程，材料没有对应关系时不要硬套；压缩时优先删重复，保留题目需要的区分。
- 本人已有题目：[DAY5城市绿化](/shenlun/day5-city-greening)、[DAY6营商环境](/shenlun/day6-business-environment)、[DAY7特点与作用](/shenlun/features-vs-effects)。

来源：《公开课课件》PDF第22—28页；DAY05—DAY15分别对应PDF第29—107页。

## 三、综合分析：观点和依据要对齐

**辨类型 → 找准分析对象 → 从材料形成判断 → 组织依据 → 按问法回查。**

| 讲义分类 | 先抓住什么 |
|---|---|
| 词句阐释 | 结合上下文解释题目中的关键词句，注意其具体语境 |
| 评论分析 | 判断材料中的现象、观点或做法，并用材料支撑 |
| 比较分析 | 明确比较对象及材料呈现的异同，避免只写一方 |
| 原因分析 | 找到所问现象或问题及其原因，核对因果方向 |
| 启示分析 | 从经验或教训提炼可借鉴的方法或警示 |

讲义提供“是什么—为什么—怎么办”作为观察框架：解释、原因和措施是否需要写，取决于题目任务与材料；例如只问原因时，重点是回答原因，不机械补全三个部分。分析要有材料依据，避免主观臆断。

来源：《公开课课件》PDF第108—113页；DAY17—DAY24见PDF第114—156页。

## 四、问题对策：先有问题，再看办法

**材料直接措施 → 从问题、原因或经验教训转化 → 必要时依据题意补充 → 检查可行性。**

- **直接提取**：先找材料已经提出或实施的相关措施，核对主体与适用情境。
- **间接转化**：问题对应改进方向；原因对应消除或缓解原因；成功经验、失败教训转化成可借鉴做法。
- **补充对策**：讲义另列自创对策；使用时受题目要求、材料信息和现实条件约束，不能把常见口号当作材料事实。
- **检查一条对策**：谁来做、做什么、针对什么问题、能否落地；删去重复和空泛表述。

来源：《公开课课件》PDF第157—161页；DAY26—DAY29见PDF第162—179页。

## 五、公文写作：文种和任务决定结构

**审文种、身份、对象、目的 → 找材料要点 → 按任务排结构 → 按要求核格式。**

- 先看文种和使用情境，再安排正文的重点、详略和语气。
- 标题、称谓、正文、落款是讲义介绍的组成部分；是否需要完整格式，以题干和具体文种要求为准。
- 报告、请示、简报、建议、提纲、发言、宣传、倡议、回应、编者按、短评、方案和招募等，分别对应讲义DAY31—DAY43；不要把一种文种格式推广为所有题的固定模板。
- 写完检查：对象是否清楚、任务是否完成、信息是否忠实材料、格式和字数是否符合要求。

来源：《公开课课件》PDF第180—186页；DAY31—DAY43见PDF第187—284页。

## 六、文章写作：从立意到论证

### 1. 确定论点

**读题干与材料 → 提炼总论点 → 确定分论点 → 检查分论点是否共同支撑总论点。**

讲义给出拆题、就近、概括、补充四种分论点寻找方式：可以从题干关系拆分，也可以回到出处段落、概括材料，或在材料和主题支持下补充角度。选哪一种取决于题目与材料，避免为了凑数量硬拆。

### 2. 写出论证

| 环节 | 记住的动作 |
|---|---|
| 开头 | 交代主题和问题，明确中心观点；引用、问题、对比等只是可选入口 |
| 议论段 | 观点 → 必要阐释 → 贴合的论据 → 分析论据如何支持观点 → 回扣 |
| 策论段 | 观点 → 解释必要性 → 具体可行的对策 → 总结其作用 |
| 结尾 | 收束论点，联系文章主题；升华或呼吁应贴合论证 |

论据要真实、贴题，不能编造数据和引文；结构和篇幅安排服从题目，讲义中的段落数量、字数比例和写作句式可作参考，不当作统一评分标准。

来源：《申论作文》PDF第2—7页（结构与文体）、第8—17页（论点）、第18—27页（润色）、第28—32页（开头）、第33—43页（议论）、第44—51页（策论）、第52—59页（结尾）。

## 七、怎样用这张框架复习

1. 合上页面，先说出五类任务和每类的第一个动作。
2. 回到本人已讨论的真题，指出题干要求、材料依据及答案如何组织。
3. 再用完整、未看解析的同类真题独立检验；记录首答、真实用时和把握程度，改写与陌生题结果分开。

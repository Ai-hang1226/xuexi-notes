## 🏷 错误类型分类（通用 # 编号）

| 编号 | 标签 | 说明 |
|------|------|------|
| #1 | `#没识别题型` | 不知道这题考什么，瞎套方法 |
| #2 | `#条件看漏` | 题干关键条件没看到 |
| #3 | `#方法选错` | 会但调用错了方法 |
| #4 | `#陷阱没认出` | 被选项偷换/绝对化/干扰带走 |
| #5 | `#计算落实出错` | 思路对，执行错了 |

## 📋 错题录入模板

```markdown
### [题目编号] [题目简述]

- **日期**：2026-XX-XX
- **来源**：粉笔/华图/真题/...
- **模块**：行测 × 数量关系
- **错误类型**：#3 方法选错
- **我的错误答案**：A
- **正确答案**：C

**题目回顾**：（题干概要）

**我为什么错了**：（分析错误思路）

**正确思路**：（记录正确方法）

**知识点关联**：
- [相关笔记链接](../xingce/shuliang-guanxi.md)
- 考察知识点：XXX

**下次注意**：（一句话提醒自己）
```

## 📅 复习计划

::: tip 艾宾浩斯复习法
- 第 1 天：做完题当天记录错题
- 第 2 天：重做昨天的错题
- 第 7 天：重做一周前的错题
- 第 30 天：重做一个月前的错题
:::
